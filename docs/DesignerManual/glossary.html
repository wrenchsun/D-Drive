用語集

マニュアルや Unity の画面に出てくる言葉の説明です。五十音・アルファベット順。

用語説明
アンカー (Anchor)エフェクトや効果音を「どこに・いつ・どう出すか」の定義。ボーン名やオブジェクト名で基準を決め、そこからのずれ（オフセット）を足します。VFX と SE で共通の仕組み。VFX / SE データの中に埋め込む方法と、単独の Anchor データ（ランダム・ディレイ・確率・入れ子つき）を作って参照する方法があります。Anchor データの作り方 / 埋め込み項目の説明。
アンカーポイント
(AnchorPoint / AnchorRig)		シーンや Prefab に置く「ここに出す」という目印。SceneView でドラッグして位置を決められ、ランダムな散らばりも設定できます。使い方はこちら。
配置セット
(Anchor Group)		格子・円・一列・ランダムなどのパターンで並べた複数の場所に、エフェクトや効果音をまとめて出すためのデータ。使い方はこちら。
アイコン (Icon)Asset Browser の一覧や Inspector に出る小さな画像。Inspector の「シーンから作成」で SceneView の写真から切り取って作れます（トップの「共通の入口」参照）。
アニメーションデータ
(AnimData)		Clip とステート名、そして「何フレーム目で音・エフェクトを出すか」をまとめたデータ。Anim Editor でモデルを動かしながら調整します。使い方はこちら。
アセットゲームで使う素材データのこと。このプロジェクトでは特に「D-Drive に登録された音・エフェクトなどのデータ」を指します。
アセットブラウザ
(Asset Browser)		D-Drive の素材を一覧・検索・登録するウィンドウ。使い方はこちら。
インスペクター
(Inspector)		Unity 画面の右側にある、選択中のものの詳細設定を表示する場所。項目にマウスを乗せると説明が表示されます。
ID（アイディー）アセット1つ1つに付く「番号札」。プログラムはこの番号で音を呼び出すので、中身を差し替えてもプログラム修正は不要になります。番号はツールが自動で管理するため、手で触ることはありません。
識別子アセット登録時に入力する英語の名前（例: SwordSlash）。プログラマーがコードで使う名前になります。英字大文字始まり・英数字のみ。
パーティクルシステム
(ParticleSystem)		Unity 標準の粒子エフェクト機能。火花・煙・光などを小さな粒の集まりで表現します。エフェクトの見た目そのものは Prefab の中のこれで作ります。
ヒエラルキー
(Hierarchy)		Unity 画面の左側にある、シーン内に存在するモノの一覧。
ピッチ (Pitch)音の高さ。1 が元のまま、2 で1オクターブ高く（再生速度も倍に）、0.5 で低く（半分の速さに）なります。
フレーム (Frame)アニメーションの時間の単位。Clip のフレームレート（多くは 30）で 1 秒を割ったもの。「Frame 15」は 30fps なら 0.5 秒目。
プレハブ (Prefab)シーンに何度でも置ける「ひな形」。エフェクトの実体（ParticleSystem など）は Prefab として作り、VFX データから参照します。
プレハブモードPrefab の中身だけを編集する Unity の画面状態。Project で Prefab をダブルクリック、または VFX Editor の「Prefab を開く」で入り、Hierarchy 左上の「←」で抜けます。VFX Editor はこの状態でも再生できます（詳しくはこちら）。
プレビューゲームを実行せずに、エディタ上でその場で再生して確認すること。D-Drive のプレビューは実際のゲームと同じ仕組みで再生されるので、「エディタでは良かったのに実機で違う」が起きにくいのが特長です。
繰り返し (Repeat)アニメーションのイベント（音・エフェクト）を「毎周回」出すか、「1 回」だけか、「再生中は維持」（1 回出してモーションが終わるまで付いていき、終わると消える）か。Anim Editor のイベント一覧で選びます。
モデルデータ
(ModelData)		キャラクターや物体の Prefab に、マテリアルのスロットと最初に再生するアニメーションをまとめたもの。Model Editor で確認します。
ループ (Loop)繰り返し再生のこと。BGM や環境音は基本ループ、通常の効果音は非ループ。
BGM背景音楽。D-Drive では「イントロ→ループ」構成やクロスフェード切替に対応。設定項目はこちら。
Mixer（ミキサー）
(Audio Mixer Group)		音の出力先グループ。「BGM 全体の音量」「SE 全体の音量」をまとめて調整できるようにするための仕組みです。どのグループを設定すべきかはサウンド担当の指示に従ってください。
SE（エスイー）効果音（Sound Effect）。斬撃音・足音・ボタン音など。設定項目はこちら。
Spatial / 3D サウンド音源の位置によって聞こえ方が変わる立体的な音の鳴らし方。遠いと小さく、右にあると右から聞こえます。対義語は 2D（どこでも同じ聞こえ方。UI 音など）。
トリミング音声の前後の不要部分（無音など）を切り落とすこと。D-Drive では元ファイルを変更しない「非破壊」方式です。やり方はこちら。
VFX（ブイエフエックス）エフェクト（Visual Effects）。斬撃・ヒット・炎・オーラなど見た目の演出。設定項目はこちら。
ライトレイヤー
(Light Layer Mask)		「どのライトの影響を受けるか」の設定。通常は Default のままで問題ありません。
Validation（バリデーション）設定ミス（ファイル未設定・矛盾した数値など）を自動チェックする仕組み。警告が出たら該当ページの「よくある警告」を見て直してください。
