はじめての15分（新規メンバー向け）

このページは、D-Drive を初めて触る人が効果音（SE）を1つ登録してゲームに反映させるまでを、実際にかかる時間の目安つきで説明します。トップページの「はじめの一歩」より詳しく、つまずきやすい点も先に案内します。プログラムの知識は不要です。

目標: 「効果音を1つ登録し、鳴らせる状態にする」までをおよそ15分で一巡できます。慣れれば数分で終わる作業ですが、最初は各手順の意味を確認しながら進めてください。

全体の流れ（所要時間の目安）

#手順目安時間
1Unity を開く（前提。すでに開いていれば 0 分）—
2「？ マニュアル」ボタンの場所を確認する1 分
3Asset Browser を開く1 分
4SE を登録する（フォルダに置く、または D&D）3 分
5試聴する1 分
6音量を調整する2 分
7Validation で確認する2 分
8保存する1 分
9（発注に対応している場合）発注ツールで「インポート済」を確認する2 分
合計約 13 分（つまずいても+数分で 15 分以内）

手順2: 「？ マニュアル」ボタンの場所を確認する

Unity 画面上部、再生ボタン（▶）のすぐ右にある「？ マニュアル」ボタンから、このマニュアルをいつでもブラウザで開けます。困ったときはまずここに戻ってきてください。

つまずきポイント: ボタンが最初は隠れています。 見当たらない場合は、画面上部のツールバーの何もない場所を右クリックし、「D-Drive/Manual」にチェックを入れてください（1 回だけで OK。以後は常に表示されます）。メニューの Tools > D-Drive > マニュアルを開く からも同じページを開けます。

手順3: Asset Browser を開く

メニューバーの Tools > D-Drive > Asset Browser を開きます。これが D-Drive のすべての素材の入口です。詳しくは Asset Browser の使い方。

手順4: SE を登録する

やり方は2つあります。どちらでも構いません。

方法手順
A. フォルダに置く（自動検知）Assets/SourceAssets/Se/<カテゴリ>/（例: Assets/SourceAssets/Se/Player/）に音声ファイル（.wav 等）を置くと、数秒後に自動で SeData が作られます。
B. Asset Browser にドラッグ＆ドロップProject ウィンドウの音声ファイルを Asset Browser のウィンドウ上へドラッグ＆ドロップ → ダイアログで表示名・識別子を入力 → 「作成」。
つまずきポイント: 種別フォルダは「SourceAssets の直下1階層目」でなければなりません。 Assets/SourceAssets/Se/Player/Slash.wav は検知されますが、Assets/SourceAssets/Slash.wav（直下に直置き）や Assets/SourceAssets/Check/Se/Slash.wav（Se の上に別フォルダを挟む）は検知されません。フォルダ名の大文字・小文字（Se）も一致させてください。置き方を間違えると Console に案内の警告が出ます。詳しくは Asset Browser の使い方 §方法3。

方法 A で作った場合、表示名は最初はファイル名のままです。Asset Browser の一覧でその SE を選び、Inspector の「Display Name」を分かりやすい日本語名に変えておきましょう（例:「剣の斬撃音」）。

手順5: 試聴する

Asset Browser の一覧でその SE をクリックして選び、下のプレビューバーの▶ 再生を押します。ゲームを実行しなくてもその場で鳴ります。詳しくは SE の設定項目。

手順6: 音量を調整する

Inspector の Volume（0〜1）を変更し、プレビューバーの▶で鳴らし直して確認します。細かく波形を見ながら調整したい場合は Audio Editor を開いたまま作業すると効率的です。

手順7: Validation で確認する

メニューの Tools > D-Drive > Validation > Run All を実行します。この SE に関する赤い表示（Error）が無いことを確認してください。よくあるのは「Mixer が未割当」「Clip が未設定」です。詳しくは Validation の使い方。

自動で直せる項目には「修正」ボタンが出ます。押すだけで直り、Ctrl+Z で戻せます。

手順8: 保存する

Ctrl+S（Unity のシーン保存ではなく、Inspector 上のアセット自体は選択を変えた時点や Unity の自動保存で反映されます。明示的に保存したい場合は Project ウィンドウでそのアセットを選び直すか、メニューの File > Save Project を使っても構いません）。

Inspector の「Version」「Author」「Updated At」欄は、保存のたびに自動更新される予定の項目です（6-3）。現時点で空欄・古い値のままでも、手で入力する必要はありません。気にせず次に進んでください。

手順9（該当する場合）: 発注ツールで「インポート済」になるのを見る

この SE がアセット発注ツールの発注に対応している場合（企画から「このIDで作ってほしい」と発注されていた場合）は、この手順も試してみましょう。

  1. 手順3〜8を終えた状態で、メニューの Tools > D-Drive > 仕様書と同期 を開き「取得」を押す
  2. 発注ツール（ブラウザ）側でその発注の詳細を開く
  3. 状態が「インポート済」に自動で進んでいることを確認する（Validation の Error が無いことが条件。手動で状態を進める操作は無い）

発注に対応していない（自分の練習用に作った）SE の場合は、この手順はスキップして構いません。

お疲れさまでした

これで「ID で管理された効果音を1つ、登録から確認まで一巡させる」という D-Drive の基本フローは完了です。他の種類（VFX・アニメーション・Canvas 等）も、Asset Browser から開く専用エディタで同じような流れ（登録 → 調整 → 試聴/プレビュー → Validation → 保存）になっています。トップページのページ一覧から気になる種類のページへ進んでください。

困ったときは（再掲）

  • ウィンドウが見つからない → Tools > D-Drive の下にすべてまとまっています
  • 赤い表示が出ている → Validation の使い方
  • 言葉が分からない → 用語集
  • Unity 操作以前の疑問（環境構築・リポジトリ構成など、プログラマー/新メンバー向け）→ リポジトリ直下 docs/34_onboarding.md
