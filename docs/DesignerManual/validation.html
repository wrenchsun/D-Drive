Validation（自動チェック）の使い方

Validation は、D-Drive のデータの設定ミス・矛盾・登録漏れを自動で見つける仕組みです。「Prefab が入っていない」「フォーカスの行き先が無い」「カタログに載っていないのでゲームで出てこない」といった問題を、ゲームを実行する前に一覧で教えてくれます。

  • 各専用エディタ（VFX / Anim / Canvas など）の下の方にある「検証」「Validation」欄には、いま開いているデータ 1 件分の結果がその場で出ます
  • プロジェクト全体をまとめて調べるときは、メニューの Tools > D-Drive > Validation > Run All

重要度の見かた

表示意味対応
Error（赤）そのままだと動かない / 出てこない必ず直す
Warning（黄）動くが、意図と違う結果になりやすい内容を読んで判断。意図的ならそのままでよい
Info（青）お知らせ。設定の確認用読んでおくだけでよい

「修正」ボタン

自動で直せる項目には、メッセージの横に「修正」ボタンが出ます。押すとその場で直り、Ctrl+Z で戻せます。すべての項目に付いているわけではなく、付いていないものは各ページの「よくある警告」を見て手で直します。

登録漏れ（全種類共通のチェック）

D-Drive のデータは、「カタログ（管理台帳）」と「Addressables（ゲーム実行時に読み込む仕組み）」の両方に登録されていないと、ゲームでは出てこず、代わりの仮の物（Placeholder）になります。Asset Browser の「新規」で作ったものは自動で登録されますが、Project で複製した・別のフォルダから持ってきた、などのときに漏れることがあります。

表示対処
カタログ未登録: '…'(ID 0x…)がどのカタログにもありません。実行時に解決できず Placeholder になります。「修正」を押す（カタログに追加されます）
Addressables 未登録: '…' がグループに入っていません(カタログの Address '…')。実行時にロードできません。「修正」を押す
Address 不一致: '…' のカタログ '…' と Addressables '…' が違います。実行時にロードできません。「修正」を押す
Addressables の設定(AddressableAssetSettings)がありません。…プログラマーに相談（プロジェクトの初期設定が必要です）
まとめて登録し直したいときは Tools > D-Drive > Generate > Addressables 登録を同期(カタログ → グループ)。実行後の Console に「カタログ未登録の Data N 件」と出たら、続けて Run All で「修正」を押してください。

仕様書(発注ツール)との食い違い(全種類共通のチェック)

仕様書と同期している場合(Tools > D-Drive > 仕様書と同期)、Run All は Web の発注ツールから取り込んだスナップショット(Specs/フォルダ)と実際のデータを見比べて、次のような食い違いも教えてくれます。仕様書同期を使っていないプロジェクトでは「スナップショットが見つかりません」という Info が 1 件出るだけで、他のチェックは行われません。

表示意味重要度
仕様書に発注がありますが D-Drive に Data がありません発注ツールには登録されているが、まだ作られていないInfo
仕様書の状態は「インポート済」ですが '…' はまだ Placeholder のようです発注ツール側では完了扱いだが、中身がまだ入っていないWarning
'…' は仕様書のスナップショットに見つかりません(削除・アーカイブ・リネーム済みの可能性があります)一度は同期したデータが、今の仕様書には無いInfo
調整値 '…' の値が仕様書の範囲 […] の外ですTuningTable の値が、発注ツールで決めた最小〜最大の範囲を超えているError(必ず直す)

よくある使い方

やりたいこと手順
作業の区切りに全体を確認するTools > D-Drive > Validation > Run All → 赤（Error）が 0 になるまで直す
ゲームで出てこない原因を探すRun All で「未登録」「Placeholder」の文字を探す → 「修正」
1 つのデータだけ確認するInspector の「▶ 〜 Editor で開く」→ ウィンドウ下部の「検証」/「Validation」欄

種類ごとのメッセージ

データの種類ごとの具体的なメッセージと直し方は、各ページの「よくある警告」にまとめてあります。

  • SE / BGM
  • VFX / Anchor / 配置セット
  • モデル / アニメーション（3D） / 2D アニメーション
  • マテリアル / テクスチャ
  • Prefab / Canvas
  • Skin / スライダー / UI Tween
  • 演出（Presentation） / 画面の揺れ・振動
