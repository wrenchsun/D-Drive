2D アニメーション(スプライト)の作成と Anim2D Editor

最終更新日: 2026-10-13

2D アニメーションデータ（Anim2DData）は「このパラパラ絵（スプライトの Clip）を、どのステート・レイヤーで、方向ありなら 4 方向 / 8 方向のどれとして再生するか」をまとめた再生単位です。3D のアニメーションデータ（AnimData）の仲間なので、再生の仕組み・Frame/Time イベント・切り替え時の混ざり（CrossFade）はすべて 3D と共通です。

スプライトシート（コマ絵を 1 枚の画像に並べたもの）を渡すと、「スプライトから作成」ウィザードが次をまとめて行います。

  1. スライス: 画像をコマごとに切り分ける（等分割 / 透明部分から自動検出 / 切り分け済みをそのまま使う）
  2. 命名: コマの名前と Clip 名を規約どおりに付ける（Anim_{Name}_{State}、方向ありは末尾に角度）
  3. AnimationClip 生成: コマを順に差し替える Clip（.anim）を保存する。保存先フォルダも自動で作られます
  4. Animator 登録（任意）: 方向ありなら、ステート名と同名の「2D Freeform Directional」BlendTree（向きに応じてコマを切り替える仕組み）に角度ごとの Clip を登録し、無ければ BlendTree を新規作成、向き用の x / y パラメータも自動追加
  5. Anim2DData 作成: ID 発行・ファイル名・カタログ登録・Addressables 登録まで一括

できあがった Anim2DData は Anim2D Editor で見て整えます。

  • やりたいことごとのカード（動かす / 向き / コマ / 合図 / 確認する / 管理情報）に欄が並び、コマ・方向ごとの Clip・イベントは1 件 = 1 行の一覧で、数が多くても見通せます
  • コマの間隔（リタイミング）を整えて Clip に焼き込み、SceneView の確認用シーンで実際の再生経路で動かして確かめます
  • イベント（SE・VFX を出すタイミング）の編集は、タイムライン上でマーカーを動かせる Anim Editor で行います（Anim2D Editor の「Anim Editor で編集」ボタンから開きます）

開き方

  1. メニューバー Tools > D-Drive > Editors > Animation (2D)（ウィンドウ名は「Anim2D Editor」）。Project で Anim2DData を選んでいれば、そのまま編集対象として読み込まれます。何も選んでいないときは、ウィンドウの真ん中の枠にドロップするか、最近使ったものから選びます
  2. 既にある Anim2DData を Project で選び、Inspector の一番上の「▶ Anim2D Editor で開く」を押す
  3. 新しく作るときは、何も選んでいない状態の「＋ 新規作成」か、上部の「＋ スプライトから作成」からウィザードを開く（次節）
  4. Asset Browser の「新規」ボタンで種別に Anim2D (Anim2DData) を選んで空のデータを作ることもできます（Clip は入っていないので、あとからウィザードで作るか手で入れます）。種別フィルタでも Anim2D で絞り込めます
Asset Browser に画像をドラッグ&ドロップしても Anim2DData は作れません（ドラッグ&ドロップで作れるのは音源 → SE だけです）。画像からの作成は必ず「スプライトから作成」ウィザードで行います。

はじめの一歩（4 コマ横並びのシートから待機アニメを作る）

  1. Tools > D-Drive > Editors > Animation (2D) を開き、「＋ 新規作成」（または「＋ スプライトから作成」）を押す。ウィザードが開きます
  2. ページ 1「雛形」で「均等に並んだシート」を選んで「次へ」
  3. ページ 2「素材」で「Texture」に 4 コマ横並びのシートを入れ、「Columns」= 4、「Rows」= 1、「Sprite Count」= 4 にして「次へ」
  4. ページ 3「名前と動き」で「Name」にキャラ名（例: Player）、「State」にステート名（例: Idle）を入れる。プロファイルに登録済みなら「プロファイルから選ぶ」で選ぶだけで両方入ります。「Frame Rate」= 12、「Loop」ON、「Length Mode」= Frames、「Length」= 4 にして「次へ」（12 fps で 4 コマ = 1 周 1/3 秒）
  5. ページ 4「確認と登録」で作る物の一覧を見て「作成」→ Clip Anim_Player_Idle と Anim2DData Player Idle ができ、ウィザードは閉じて Anim2D Editor がその Anim2DData を開きます
  6. 下の固定バーの「▶ 再生」→ プレビュー物が置かれ、SceneView と「確認する」カードの絵でコマが切り替わるのを確認。「確認する」カードの「撤去」でプレビュー物を消せます
  7. 足音や効果音を付けたいときは「合図（イベント）」カードの「Anim Editor で編集」→ Anim Editor のタイムラインで「＋ 現在位置に SE」（手順はそちらのページ）
プログラマーは 3D と同じく Anim.Play(ID, animator) を呼ぶだけです。カタログも 3D と共通（AnimCatalog）です。

「スプライトから作成」ウィザード

Anim2D Editor の「＋ スプライトから作成」（何も選んでいないときは「＋ 新規作成」）で開きます。画像から Clip と Anim2DData を作るためのウィンドウで、1 雛形 → 2 素材 → 3 名前と動き → 4 確認と登録の順に「次へ」で進みます（「戻る」で前のページへ。入力が足りないページは「次へ」が押せず、理由が上に出ます）。

ページ 1: 雛形

要素説明
均等に並んだシートコマの大きさが揃い、縦横にきれいに並んだ 1 枚の画像。Columns × Rows で等分割します（Grid）
バラバラに並んだシートコマの大きさや位置が不揃いな 1 枚の画像。透明な背景からコマの矩形を自動検出します（Automatic）
切ってある画像既に Sprite Editor などで切り分け済みの画像から、そのコマを拾うだけです（Existing）
4 方向 / 8 方向方向ごとの画像（4 方向 = 0 / 90 / 180 / 270 度、8 方向 = 45 度刻み）をまとめて処理し、角度別の Clip と、方向付きの Anim2DData を作ります（Directions = Four / Eight）
命名のプロファイル（任意）名前の候補（Name と State の組み合わせ）と Clip の保存先を持つ設定ファイル（Import Profile）。空にするとプロジェクト内の既定プロファイルを自動で探し、無ければ保存されない組み込みの既定が使われます

ページ 2: 素材

要素説明
Texture切る前の画像（方向なしの雛形）。必須
Columns / Rows / Sprite CountGrid 用。列数・行数と、左上から行順に使うコマ数（Columns × Rows を超えると切り詰め）。既定 4 / 1 / 4。1 未満は 1 になります
Min Sprite Size / ExtrudeAutomatic 用。検出する矩形の最小サイズ（既定 16。小さいゴミを拾わないため）と、矩形の外側に足す余白（既定 0）
検出プレビュー自動検出を実行し、画像の上に結果を重ねて表示します。緑の枠 = 生成に使う矩形、枠の番号 = コマの順番。結果は「検出: N 枚 / 推定 R 行 x C 列(規則的グリッド|不規則)…」のように出ます。表示の縮尺は元画像のサイズ基準なので、Max Size で縮小される大きな画像でも枠はずれません。この時点では画像の設定は書き換わりません
Sprite Editor で手動補正検出した矩形を画像の Importer に書き込んでから Unity の Sprite Editor を開きます（検出前は押せません）。直して Apply したら、雛形は「切ってある画像」に切り替わっているので「次へ」で進めます。2D Sprite パッケージ（com.unity.2d.sprite）が無いと開けません（案内メッセージが出ます）
切り方（方向の雛形）方向ごとの画像すべてに同じ切り方（Grid / Automatic / Existing）を使います。切り方ごとの数値は上の行と同じです
0°〜315°（方向の雛形）方向ごとの画像。空欄の方向は作られません（1 つ以上は必須）

ページ 3: 名前と動き

要素説明
プロファイルから選ぶImport Profile の Entry 一覧。選ぶと「Name」と最初の State が入ります。Entry が無いと「(プロファイルに Entry がありません)」だけが出ます
Name / Stateどちらも必須。Clip 名・Anim2DData の名前・カテゴリ（フォルダ分け）に使われます。空のあいだは「次へ」が押せません
方向(単一クリップ)方向なしの雛形のとき、この 1 本を何度の Clip として扱うか。FromName = 画像名の末尾から自動判定（下の「命名規約」）/ None / Deg0…Deg315。角度があると BlendTree にその角度で登録されます
Frame Rate / Loop1 秒あたりのコマ数（既定 12）とループ再生（既定 ON）
Length Mode / LengthClip の長さ。Frames なら「Length フレーム分」（既定 8 = 8 ÷ Frame Rate 秒）、Seconds なら秒
AnimatorController / Layer（任意）入れると BlendTree 登録まで行います。空のままなら登録は飛ばされ、Clip と Anim2DData だけができます（あとから Controller に手で組み込む前提）

ページ 4: 確認と登録

雛形・素材・切り方・Clip 名・保存先・Anim2DData の名前とカテゴリ・動き・Animator への登録有無を 1 画面で確認します。「作成」で次を行います。

  • 方向なし: スライス → Clip 生成 → 角度があれば BlendTree 登録 → Anim2DData 作成
  • 方向セット: 角度ごとの画像を順に処理し、角度順に Direction Clips を組み立てます（一番小さい角度、通常 0° の Clip が主 Clip になります）
  • 同じ角度に既に Clip が登録されていると「BlendTree 登録」ダイアログ「角度 N には既にクリップが登録されています。上書きしますか?」が出るので「上書き」か「スキップ」を選びます
  • 終わるとウィザードは閉じ、Anim2D Editor がその Anim2DData を開きます。作れなかったときは理由がページ 4 に出ます（詳しくは Console）

カード「動かす」

どのクリップを、どのステートで、どう切り替えて動かすか。

欄説明
再生するクリップ（必須）再生する Clip。長さ・フレームレートはイベント（Frame/Time）と終了判定に使います。Frame Rate は Clip から読まれます（未設定なら 30 扱い）
ステート名 / レイヤーAnimator Controller 上のステート名（CrossFade の対象。方向ありなら BlendTree のステート。空なら Clip の名前）とレイヤー番号
ループ再生ON なら周回ごとに OnLoop が出て、止める指示があるまで続きます
切り替え時間(秒)切り替え時の混ざり秒数（既定 0.1）
アバターマスク / 手足 IK / 表情 BlendShape3D 向けの欄（詳細モード）。2D では通常使いません
動作の取り決めPool 上限・ポーズ時の挙動・ネット配送など（詳細モード）。Loop のときは Pool 上限を設定します

カード「向き（方向セット）」

4 方向 / 8 方向の BlendTree に入れるクリップ。方向なしのデータでは使いません。

欄説明
方向セットNone = 方向なし / Four = 0・90・180・270 / Eight = 45 度刻み。Four / Eight のときは「ステート名」の BlendTree に方向ごとのクリップが登録されている前提で動きます。選ぶと、下の一覧にその数の行が出ます
方向ごとのクリップ1 方向 = 1 行の一覧（# ・角度のチップ・クリップの欄・「24 枚 · 2s · 12fps」の要約）。クリップ欄を直接入れ替えられます（Ctrl+Z で戻せます）。空欄・Missing の行には ⚠ が付きます。一覧の上に絞り込み（検索・「クリップあり / 未設定」）と件数（「8 方向中 クリップあり 8」）。「方向数に合わせて枠を作る」で、足りない枠だけを用意します（既に入っているクリップは動かしません）。Four は 4 本、Eight は 8 本必要です
BlendTree の X / Y パラメータ名向きを渡す Animator のパラメータ名（詳細モード）。既定は x / y（ツールの規約）。方向ありで空だと Error です

カード「コマ（スプライトと間隔）」

Clip のスプライトのキーを見て、コマの間隔を整えます。

欄説明
コマの一覧Clip のスプライトのキーを1 コマ = 1 行で並べます（# ・絵のサムネイル・スプライト名・「0.083s · F1 · 次まで 0.083s」の要約・Project で表示）。20 行を超えると一覧の中でスクロールします。一覧の上に絞り込みと件数（「24 コマ中 絵あり 24」）。Sprite の参照が切れたコマには ⚠ が付きます。Clip を入れ替える・リタイミングを適用すると自動で更新されます
リタイミングのカーブコマの配置の曲線（横 = コマ番号、縦 = 時間）。共通の ValueDef 欄（「モード」「定数」「Parametric種別」「Ease」「Bezier P1 / P2」「From」「To」「カーブ」「Normalized」など）。直線 = 等間隔。ゲーム中には参照されません（Clip のキー時刻に焼き込むためのものです）。初期値は Constant(1)
リタイミングの適用「配置モード」= Uniform（等間隔に戻す）/ Retiming（上のカーブで不均等に配置）を選び、「適用(Clip に焼き込む)」で主 Clip を書き換え、さらに同じコマ数の方向 Clip すべてに同じ配置をまとめて適用します。枚数が違う方向 Clip はスキップされ、結果は「適用 A / スキップ B」と欄の下とログに出ます。Ctrl+Z で戻せます。
リタイミングの初期値では何も起きません。 Retiming の初期値は Constant(1) で、そのまま配置モード=Retiming で「適用」しても警告が出るだけで Clip は変わりません（全コマが最後に潰れるのを防ぐため、0 → 1 に増えていくカーブだけを受け付けます）。「モード」を Parametric にして Ease を選ぶか、カーブを描いてから適用してください。

カード「合図（イベント）」

再生の節目（フレーム / 秒 / ループ）に SE・VFX・配置セットを出す、または値を送るイベントの一覧です。

部品説明
イベントの一覧1 イベント = 1 行の要約（# ・種類のチップ〔SE / VFX / 配置セット / ほか〕・対象の名前・「F4 (0.33s) · 毎周回」のような時刻と繰り返し）。Clip の長さを超えて発火しないイベントには ⚠ が付き、欄の下に検証のエラーが出ます。一覧の上に絞り込み（検索・「対象あり / 対象なし」・種類のチップ）と件数（「12 イベント中 対象あり 12」）。20 行を超えると一覧の中でスクロールします
Anim Editor で編集イベントを足す・時刻をタイムライン上のマーカーのドラッグで動かす・SE / VFX を同時に再生して確かめるときに押します。再生を止め、プレビュー物はシーンに残したまま Anim Editor に引き渡します（絵が消えないようにするため）。Anim Editor でも同じプレビュー物（SpriteRenderer + Animator）が動かす相手になります。戻ってきたあとは一覧が自動で更新されます
一覧を更新SE / VFX アセットを追加・改名したあとに押すと、対象の名前を取り直します

カード「確認する」

部品説明
プレビュー(SceneView)ウィンドウ内には再生中の絵（プレビュー物の SpriteRenderer が持つスプライト。未配置なら Clip の最初のコマ）を映し、シーンには [D-Drive] Anim2D Preview（SpriteRenderer + Animator。シーンには保存されません）を置いて実際の再生経路で動かします。「確認用シーン」= 確認用シーン（VFX と共通）を開き（無ければ生成）プレビュー物を配置 / 「今のシーンに配置」= 開いているシーンやプレハブモードに置く / 「撤去」= プレビュー物を消す。状態は「プレビュー物は未配置」「プレビュー物を配置済み(SceneView を確認)」「● 再生中 N%(周回 N)」「■ 停止」「Anim Editor に引き渡し済み」などと出ます
イベントログ再生で発火したイベントと操作の最近 12 行（「ログを消す」で空にできます）
最初に「確認用シーン」を押してください。 プレビュー物は今開いているシーンの中に出るので、カメラやライトの無いシーンだと何も見えません。確認用シーンはライト・カメラ・床の揃った専用のシーンです。

カード「管理情報」

表示名・カテゴリ（フォルダ分け）・説明・タグ・アイコン・担当者・仕様書 URL・変更メモ。ID・版数・最終更新者・最終更新日時は読み取り専用で一番下に出ます。

検証

問題は、関係する欄の下にその場で出ます（どの欄にも当てはまらないものは一番下の「その他の検証」カード）。自動で直せるものには「修正」ボタンが付きます（例: BlendTree の x / y パラメータ不足）。ヒーローのチップにはエラーと警告の数が出ます。

そのほか（Clip / ステート名 / レイヤー / ループ / 切り替え時間 / イベントなど）は 3D のアニメーションデータと共通です（Anim Editor のページ）。

Import Profile（Anim2D Import Profile）

Project の右クリック Create > D-Drive > Anim > Anim2D Import Profile で作ります（既定ファイル名 Anim2DImportProfile）。プロジェクト内の 1 つが自動で使われます。

項目説明
Entries（Name / States）名称（例: Player）と、その名称で使えるステート一覧（例: Idle, Run, Attack）。ウィザードの「プロファイルから選ぶ」に出ます
Default Clip Folder生成した Clip の保存先（既定 Assets/GameData/Anim2D/Clips）
Default Frame Rate / Default Directionsツールチップ上は「既定」ですが、現状はウィザードの初期値（12 / なし）に反映されません。実際に効くのは Entries と Default Clip Folder です

Anim2DFacing（向きを自動で切り替える部品）

8 方向 BlendTree の向きを移動方向から自動で決めるコンポーネント。キャラの GameObject に付けて使います。Target（向きを書き込む Animator。空なら自身）/ Camera Relative（既定 ON。カメラの向き基準。Camera.main が無ければワールド基準）/ Smoothing（向きの平滑化秒。既定 0.08、0 で即時）/ Param X / Param Y（BlendTree のパラメータ名）/ Initial Direction（開始時の向き。上 = (0,1)）。プログラム側は移動ベクトルを渡すだけです。

命名規約（ツールが自動で付けるもの）

対象規則
Clip 名方向なし: Anim_{Name}_{State} / 方向あり: Anim_{Name}_{State}_{角度}（角度は 0 / 45 / 90 / 135 / 180 / 225 / 270 / 315）
画像名の末尾の角度「方向(単一クリップ)」を FromName にしたとき、画像名が _0 _45 … _315 で終わっていればその角度になります（例: player_run_90.png → 90°）。それ以外は方向なし扱い
Sprite（コマ）の名前{画像名}_{連番}（0 始まり）。Grid / Automatic 共通
コマの順番Grid: 左上から右へ、行ごとに下へ。Automatic: コマの中心の高さで行に分け、行の中は左から右、行は上から下。Existing: Sprite Editor の並び（左上 → 右下）に揃えます
Clip の保存先Import Profile の Default Clip Folder（未設定なら Assets/GameData/Anim2D/Clips）。フォルダが無ければ作られます。同名があると Anim_X_Y 1.anim のように連番が付きます（上書きではありません）
Anim2DData の保存先と名前Assets/GameData/Anim2D/{カテゴリ}/ANIM2D_{カテゴリ}_{識別子}.asset。カテゴリ = Name、識別子 = Name + State を英数字にしたもの、表示名は「{Name} {State}」。ID の頭は ANIM2DID

よくある使い方

やりたいこと設定
4 コマ横並びのシートから待機アニメウィザード: 雛形「均等に並んだシート」、Columns=4 / Rows=1 / Sprite Count=4、Name / State を入力、Frame Rate=12、Loop ON、Length Mode=Frames / Length=4 →「作成」
隙間が不揃いなシートを切る雛形「バラバラに並んだシート」→ Texture を入れて「検出プレビュー」→ 緑枠と番号を確認 →「次へ」…「作成」
自動検出がずれたので手で直す「検出プレビュー」→「Sprite Editor で手動補正」→ Sprite Editor で直して Apply → 雛形が「切ってある画像」になっているので「次へ」…「作成」（2D Sprite パッケージが必要）
8 方向キャラの歩きを一括で作る雛形「8 方向」→「0°」〜「315°」に各画像 → AnimatorController と Layer を指定 →「作成」で 8 本の Clip + BlendTree 登録 + Direction Clips が一度にできます
攻撃の当たるコマで SE / VFX「合図（イベント）」カードの「Anim Editor で編集」→ タイムラインで「＋ 現在位置に SE」（Anim Editor 参照）
ためて素早く振る（コマ間隔を不均等に）「コマ」カード → 配置モード=Retiming → リタイミングのカーブの「モード」を Parametric にして Ease（EaseInOut など）を選ぶ →「適用(Clip に焼き込む)」。方向 Clip も同時に揃います
コマ間隔を等間隔に戻す配置モード=Uniform で「適用(Clip に焼き込む)」
シーンで動きを確認する「確認用シーン」（または「今のシーンに配置」）→ 固定バーの「▶ 再生」。終わったら「撤去」
移動方向に合わせて自動で向きを変えるキャラに Anim2DFacing を付け、Camera Relative / Smoothing を調整。向きの計算はプログラム側が移動ベクトルを渡します

よくある警告

該当する欄の下（または「その他の検証」）に出るもの（3D と共通の警告は Anim Editor のページも参照）。

表示対処
Clip が未生成(または Missing)です。Anim2DEditor で生成してくださいウィザードで作り直すか、Clip を手で入れる
Directions=Four|Eight ですが DirectionClips が N 本です(M 本必要)足りない角度の画像を入れて作り直す、または「方向ごとのクリップ」の行にクリップを入れる（作成時に Console にも「方向クリップが不足しています」と出ます）
DirectionClips[i] が未設定(または Missing)ですその角度の行にクリップを入れ直す
方向付きなのに BlendTree のパラメータ名(ParamXName / ParamYName)が空ですBlendTree の X パラメータ名に x、Y パラメータ名に y を入れる
Directions=None ですが DirectionClips が設定されています(使われません)方向セットにするか、方向ごとのクリップを空にする
Controller に StateName '…' が見つかりません(BlendTree のパラメータ検査をスキップしました)Controller にステートを作るかステート名を合わせる（Controller の配線は任意なので警告止まり）
'…' の BlendTree に x,y パラメータ … がありません「修正」ボタンで Float パラメータが自動追加されます
'…' のスライス済みスプライトの参照が N 件切れています(元テクスチャの再インポート等で消失した可能性があります)元画像を再スライスして Clip を作り直す
Frame イベント(…)が Clip 長(… フレーム)を超えています / Time イベント(…s)が Clip 長(…s)を超えていますAnim Editor でマーカーを Clip の長さより手前に動かす
Loop=false ですが OnLoop イベントがあります(発火しません)ループ再生を ON にするか行を消す
Flags.Load が Preload ではありません(…)「修正」ボタンを押すと直ります（Asset Browser の「Validation > Run All」からも実行できます）。放置すると Anim Editor で SE / VFX を設定しても実行時に一切鳴らない/出ないままになります（見た目のアニメーションだけは動くため気づきにくい）。ウィザードや「＋ 新規」で作ったものはこの設定が自動で入るため対処不要です

Console（ログ）に出る主なもの:

表示対処
[Anim2D] リタイミングのカーブが 0 → 1 へ単調増加していないため適用しませんでした。…Retiming が初期値 Constant(1) のまま。Ease かカーブを設定してから「適用」
[AutomaticSpriteSlicer] 検出された矩形が 0 件です。背景が透明でない / minSpriteSize が大きすぎる可能性があります。背景が透明な画像か確認する。Min Sprite Size を小さくする
[ExistingSpriteCollector] … 内に Sprite が見つかりません。TextureImporter が Sprite/Multiple になっているか確認してください。「切ってある画像」は切り分け済みの画像専用。画像の Inspector で Texture Type = Sprite、Sprite Mode = Multiple にしてスライスしておく
[Anim2DCreateService] 角度 N のスプライト取得に失敗しました。スキップします。その角度の画像の切り方（Grid の数値など）を確認する。その方向だけ飛ばして作られます
[BlendTreeRegistrar] ステート "…" が存在しますが、Motion が BlendTree ではありません。/ BlendTree "…" の BlendType が FreeformDirectional2D ではありません。Controller に同名のステートが別の形で既にあります。ステート名を変えるか、Controller 側を 2D Freeform Directional の BlendTree にする

注意点

  • プレビュー物は「撤去」でしか消えません。 [D-Drive] Anim2D Preview はウィンドウを閉じてもスクリプトの再コンパイルでも残ります（Anim2D Editor と Anim Editor で 1 つを共有）。消えるのは「撤去」を押したときだけです
  • 「Sprite Editor で手動補正」は 2D Sprite パッケージ（com.unity.2d.sprite）が必要です。 無いと案内メッセージが出て開けません（導入は Package Manager から、プログラマーに相談）
  • 作成は画像の Import 設定を書き換えます。 Texture Type = Sprite / Multiple、Mipmap OFF、Filter = Point、圧縮なし、NPOT なしになります。さらに Automatic での作成と「Sprite Editor で手動補正」は Max Size を 16384 に変えたままにします（Grid は Max Size を触りません。「検出プレビュー」だけなら検出後に元に戻ります）
  • 方向 Clip のリタイミングは飛ばされることがあります。 主 Clip と同じコマ数の方向 Clip だけが対象で、枚数が違うものはスキップされ、「適用 A / スキップ B」と件数が出ます
  • 同じ名前で作り直すと Clip が増えます。 上書きではなく Anim_X_Y 1.anim のように連番付きで別に保存されます。古い方は手で消してください
  • BlendTree 登録の前提。 State と同名のステートが対象レイヤーに無ければ 2D Freeform Directional の BlendTree を新規作成します。既にあるが BlendTree でない / 種類が違うとエラー・警告になります。Layer が Controller のレイヤー数を超えているとエラーです
  • Import Profile の Default Frame Rate / Default Directions は初期値に反映されません。 ウィザードは 12 / なし から始まります
  • イベントはデータ共通の Events に持ちます。遷移の確認は Anim Editor の「ブレンド確認」で行います
