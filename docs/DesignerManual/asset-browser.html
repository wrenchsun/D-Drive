Asset Browser の使い方

Asset Browser は D-Drive の入口になるウィンドウです。登録済みの素材（アセット）を一覧で見たり、検索したり、新しく登録したりできます。

開き方

  1. Unity 画面の一番上のメニューバーを見る
  2. Tools をクリック → D-Drive → Asset Browser をクリック

画面の見かた

場所説明
検索欄（左上）文字を入れると、その場で一覧が絞り込まれます。日本語の表示名でも検索できます（例:「斬撃」と入れると「剣の斬撃音」がヒット）。カテゴリ・タグ・説明文も検索対象です。
種別メニュー（検索欄の右）「All」のままなら全部表示。「Se」を選ぶと効果音だけ、「Bgm」を選ぶと BGM だけに絞れます。
「新規」ボタン新しいアセットを登録するダイアログを開きます（下で説明）。
「更新」ボタン一覧を最新の状態に読み直します。（普段は自動で更新されるので、表示がおかしいと感じた時だけ押せばOK）
一覧登録済みのアセットが並びます。クリックすると右の Inspector に詳細が表示され、ダブルクリックすると Project ウィンドウの実ファイルがハイライトされます。
プレビューバー（一番下）選択中の音をその場で試聴できます。▶再生 / ■停止 / ループ / 速度。

検索の詳しい仕様

検索欄は1文字打つたびにその場で絞り込まれます（Enter キーを押す必要はありません）。

検索でヒットする項目

入力した文字は、そのアセットの以下の項目のうちどれか1つにでも含まれていればヒットします（大文字・小文字は区別しません）。

項目説明
表示名「剣の斬撃音」のような、人が入力した名前
ファイル名・保存場所ツールが自動生成したファイル名(例: SE_Player_SwordSlash)や、保存されているフォルダのパス
カテゴリ登録時に入力した分類
説明文Inspector の「Description」に書いた内容
作成者Inspector の「Author」に入力した名前
タグInspector の「Tags」に登録した各キーワード
例: 表示名が「剣の斬撃音」なら「斬撃」と打つだけでヒットします。ファイル名やカテゴリで検索したい時も、同じ検索欄にそのまま打ち込めば大丈夫です。

種別メニューとの組み合わせ

種別メニュー（All/Se/Bgm/…）を絞った状態で検索すると、「その種別に該当する」かつ「検索文字にヒットする」ものだけが表示されます。両方の条件を同時に満たす必要があります。

できないこと（現状の制限）

  • ID(管理番号)そのものを打ち込んでの検索はできません(表示名・ファイル名・カテゴリ・説明・作成者・タグのみが対象)
  • 「これを含み、あれは含まない」といった複雑な絞り込み条件は使えません。1つの言葉での単純な部分一致のみです
  • タイプミスを自動で補正する機能はありません。文字が完全に一致している部分だけがヒットします

新しいアセットを登録する

方法1: 音声ファイルをドラッグ＆ドロップ（おすすめ）

  1. Project ウィンドウにある音声ファイル（.wav / .mp3 / .ogg）を、Asset Browser のウィンドウの上へドラッグ＆ドロップ
  2. 登録ダイアログが開くので、下の表の項目を入力
  3. 「作成」を押す

方法2: 「新規」ボタン

ファイルを後から設定したい場合はこちら。開くダイアログは同じです。

ダイアログの入力項目

項目入力するもの例
種別作りたいアセットの種類。効果音なら「Se」、BGM なら「Bgm」。Se (SeData)
表示名日本語でOK。一覧や検索で使われる名前。後から変えても大丈夫。剣の斬撃音
カテゴリ整理用の分類。空欄でもOK。Player
識別子英語で、先頭大文字・スペースなし。プログラマーがコードから呼ぶときの名前になります。迷ったら英単語をつなげて各単語の頭を大文字に。SwordSlash
ファイル名と保存フォルダは自動で付きます。上の例なら SE_Player_SwordSlash というファイルが Assets/GameData/Audio/SE/Player/ フォルダに自動で作られ、管理台帳への登録もすべてツールがやります。ダイアログの下に「生成先」がプレビュー表示されるので確認できます。
カテゴリを英語で入れておくと（例: Player、Enemy/Attack のように / で階層も可）、カテゴリごとのフォルダに自動で仕分けられるので、Project ウィンドウから直接探すときも見つけやすくなります。
カテゴリを後から変えたら: ファイルの場所と名前がカテゴリと合わなくなりますが、手で動かす必要はありません。メニューの Tools → D-Drive → Generate → GameData をカテゴリ配置に整理 を実行すると、ツールが正しいフォルダへ移動して名前も直してくれます（移動してもゲーム側の参照は壊れない仕組みになっています）。
識別子が赤くなって「作成」が押せない時: 識別子は「英字の大文字で始まり、英数字のみ」というルールがあります。日本語・小文字始まり・記号（アンダーバー含む）・数字始まりは使えません。
NG: sword_slash / 剣斬撃 / 1Slash → OK: SwordSlash

試聴する（プレビューバー）

  1. 一覧で音を1つクリックして選ぶ
  2. 下のプレビューバーの ▶ 再生 を押す（ゲームを実行しなくても鳴ります）
  3. 「ループ」にチェックを入れて再生すると繰り返し再生（データ自体は変更されません）
  4. 「速度」スライダーで再生スピードを変えて聞き比べ（0.1倍〜2倍）

もっと細かく確認したい場合（波形を見る・3D の聞こえ方を確かめる等）は Audio Editor を使います。

よくある質問

  • Q. 表示名を変えたい → 一覧で選んで Inspector の「Display Name」を書き換えれば OK です。
  • Q. 間違えて作ってしまった → すぐ消さず、チームのリーダーに相談してください（プログラム側で既に使われている可能性があるため、削除には手順があります）。
  • Q. 一覧に出てこない → 「更新」ボタンを押してみてください。種別フィルタが絞られたままになっていないかも確認。
