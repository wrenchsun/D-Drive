画面の揺れ・コントローラーの振動

攻撃が当たった・爆発が起きた、といった「手応え」を出す 2 つの仕組みです。どちらも ID(番号札)で管理するデータで、演出(Presentation) の中の 1 トラックとして使うことも、プログラム側から直接鳴らすこともできます。

  • カメラシェイク(Camera Shake): 画面をガクガク揺らす
  • ハプティクス(Haptics): コントローラー(パッド)をブルブル振動させる
専用エディタがあります: Tools > D-Drive > Editors > Shake / Haptics(または Asset Browser でデータを開く)から、波形を見ながらの調整・「実際にカメラを揺らす」「パッドを実際に振動させて試す(Test on Pad)」・プリセット 10 種からの適用ができます。使い方は下の「専用エディタ(Shake / Haptics Editor)の使い方」を参照してください。

カメラシェイクの設定項目(Camera Shake Data)

項目説明
Pattern(波形)Perlin Noise: 手ブレ・地響きのようなランダムな揺れ(既定)。Decay Sine: 一定のリズムで震える揺れ。Impulse: 振動せず、一方向に「グッ」と押される一撃。Custom Curve: 今のところ Impulse と同じ動きです
Pos Amplitude(位置の揺れ幅)上下・左右・前後にどれだけ動くか(メートル)。X/Y/Z を別々に設定できます
Rot Amplitude(回転の揺れ幅)どれだけ傾く・回るか(度)。Z だけ入れると「首をかしげる」ような揺れになります
Frequency(周波数)Perlin Noise / Decay Sine で使う、揺れの速さ(Hz)。数字が大きいほど細かく速く揺れます
Envelope(減衰)揺れの強さが時間とともにどう弱まっていくか。既定は 0.3 秒でスッと収まる設定。用語集にもある「形+速さ」の共通の編集項目(ValueDef)で調整します
Space(基準の向き)Camera Local(既定): カメラ自身の向きを基準に揺れる。World: カメラの向きに関係なく、いつも同じ方向に揺れる。From Source: 発生位置(爆発の場所など)からカメラへ向かって「奥から手前に押される」揺れになる
Trauma Weight(合成の重み)複数のシェイクが同時に起きたときの寄与度。既定 1。大きくすると、他のシェイクと重なったときにより強く効きます
Max Stack(同時再生数の上限)同じシェイクが同時に何個まで積み重なれるか。既定 3。これを超えて呼ばれた分は静かに無視されます(連打しても壊れないための安全弁)
連打しても大丈夫な理由: 複数のシェイクが同時に起きても、単純に足し算はしません(トラウマ方式という合成をしていて、最終的な揺れの強さは 0〜100% の範囲に収まります)。何度連打しても、画面が異常に揺れすぎることはありません。

振動の設定項目(Haptics Data)

項目説明
Low Freq(低周波モーター)「ドスン」という低い振動。強さが時間とともにどう変わるかを ValueDef(形+速さ)で決める。既定は 0.2 秒で収まる設定
High Freq(高周波モーター)「ビリビリ」という高い振動。Low Freq と同じ形式
Priority(優先度)今のところ参考情報のみ(下記「複数の振動が重なったら」を参照)
Local Player Only自分に起きた事象のときだけ振動させるか(既定 ON)。マルチプレイ対応前の現状は常にこの動きです
Extensions(拡張)DualSense のアダプティブトリガー等、機種別の特殊な振動。まだ未対応で、設定しても警告が出るだけです
複数の振動が重なったら: 足し算(2 つ重なると 2 倍の強さ)にはしません。チャンネルごとに一番強い値だけを採用します(Low は Low どうし、High は High どうしで比較)。手元のパッドが振り切れて壊れたように感じることはありません。

プログラムから鳴らす(参考)

デザイナーが直接書く場面は少ないですが、演出(Presentation)を経由しない単発の揺れ・振動はプログラム側がこう書きます。CameraFx.Shake(シェイクの ID) / Haptics.Play(振動の ID)。中身の調整はこのページの手順のとおり、データ側だけで完結します。

演出(Presentation)から使う

演出のページにあるとおり、Tracks の Kind に Camera Shake / Haptic を選び、Asset 欄にこのページで作ったデータの ID を入れるだけで、他の SE・VFX と同じタイミングで揺れ・振動が鳴らせます。剣攻撃デモ(PresentationSkillSlashPreviewScene)では、当たった合図(hit)で画面停止(ヒットストップ)・SE と同時に、画面が揺れてパッドが振動するようになっています。

オプション画面との連動

設定画面の「画面揺れ」「振動」のスライダー(0〜100%)は、コード不要でこの仕組みに直結しています。0% にすると完全に揺れ・振動が止まります(酔いやすい人・振動が苦手な人向けのアクセシビリティ対応)。詳しくは UI Tween のページの標準オプションの節を参照してください。

スライダーのノッチ・端での振動

スライダーの見た目(Skin)にある「Notch Haptic Id」「Limit Haptic Id」にこのページで作った振動データの ID を入れると、目盛りを越えた・端に当たったときにパッドが振動します(2026-09-14 から対応)。

よくある警告と直し方

警告意味と直し方
PosAmplitude / RotAmplitude が両方ゼロですこのままでは何も揺れません。どちらかに値を入れてください
PosAmplitude / RotAmplitude が大きすぎる可能性があります(酔いのリスク)揺れが強すぎるとプレイヤーが酔いやすくなります。数値を小さくするか、本当に必要な演出か見直してください
MaxStack が 0 以下ですこのままでは Shake() を呼んでも常に無視されます。1 以上にしてください
TraumaWeight が 0 以下ですこのままでは合成に一切寄与しません(揺れません)。1 前後にしてください
振動の尺が 2 秒を超えています長すぎる振動は不快に感じやすいです。短くすることを検討してください
Extensions は未実装ですプラットフォーム別の特殊な振動はまだ使えません。基本の 2 モーターカーブだけで表現してください

専用エディタ(Shake / Haptics Editor)の使い方

Tools > D-Drive > Editors > Shake / Haptics で開きます。1 つのウィンドウで Camera Shake Data / Haptics Data の両方を編集でき、上の「対象アセット」欄に開きたいデータを入れると、それぞれの項目が出てきます(Asset Browser や Project ウィンドウで選ぶと自動で追従します)。まだデータが無ければ、ツールバーの「＋ 新規作成」から Camera Shake / Haptics のどちらを作るか選んで、その場で新規作成できます(Asset Browser の使い方参照)。

  • 確認用シーンを開く: ツールバーのボタンで、カメラ・ライト・目印になる箱を置いた専用の確認用シーンを開きます(無ければ自動で作られます)。揺れの確認はこのシーン(または今開いているシーン)の SceneView / Game ビューで行います(ウィンドウの中に絵は出ません)
  • 波形プレビュー: Envelope(減衰)や Low/High の強さが時間とともにどう変わるかを見た目で確認できます(数値を直接編集するのはこのグラフの下にある「パラメータ」欄です)。あくまで参考表示で、実際の揺れ方(ランダムな位相のずれ等)を完全に再現するものではありません
  • Shake 再生(連打可): 押すたびに実際のカメラが揺れます。連打すると、複数のシェイクが重なったときの合成(揺れすぎない仕組み)を確認できます。ウィンドウを閉じる・シーンを保存する・Play ボタンを押す、いずれのタイミングでもカメラは必ず揺れる前の位置に戻ります(揺れたままシーンに保存されることはありません)
  • Test on Pad: パッドを接続した状態で押すと、実際にパッドが振動します。停止ボタンを押す・ウィンドウを閉じる・別の画面に切り替える(フォーカスが外れる)・Play ボタンを押す、いずれの場合も振動は必ず止まります。パッドが未接続のときは波形の確認だけができます
  • プリセット(10種): Pulse(軽い一撃) / Rumble(持続する揺れ) / Heartbeat(心拍のような二拍) / Explosion(爆発) / Hit_Small・Hit_Large(被弾小・大) / Landing(着地) / Earthquake(地震・持続) / Alarm(警報・持続) / Engine(エンジンのアイドリング・持続)。ボタン 1 つで数値一式を書き換えます(Undo で元に戻せます)。数値はたたき台なので、実際のプレイ感に合わせて調整してください
