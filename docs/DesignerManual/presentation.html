演出（Presentation）の設定項目

最終更新日: 2026-09-22

「剣攻撃」のように、アニメ・効果音・エフェクト・カメラ揺れ・振動・画面停止（ヒットストップ）などを 1 つにまとめたものが「演出（PresentationData）」です。プログラマーは Presentation.Play(演出のID, ...) と 1 行書くだけで、中身（何を・いつ・どう鳴らすか）はすべてこのデータで決まります。あとから演出の中身を差し替えても、プログラムの修正は不要です。

専用エディタ: Tools > D-Drive > Presentation Editor（目玉機能につき Tools メニュー最上段）でトラックをタイムライン形式で編集し、実際にアニメ・SE・エフェクト・画面揺れ・振動を同時に再生して確認しながら作れます。使い方は下の「専用エディタの使い方」を参照してください。

基本の考え方: トラック（Tracks）

演出は「トラック」という短い指示の集まりでできています。1 本のトラックは「いつ」「何を」の 2 つを決めます。

項目説明
Trigger（いつ）At Time: 再生開始から何秒後に鳴らすか(Time 欄に秒数)。0 秒は「開始と同時」。
On Signal: プログラム側が「合図（例: 攻撃が当たった）」を送ってきたら鳴らす。Signal Key 欄に合図の名前(例: hit)を入れる。
Kind（何を）下記「トラックの種類」参照。
Asset（何のデータを）Kind に応じた ID(例: Kind=Vfx なら VfxData の ID)。Marker/Signal/HitStop は不要。
Target（基準になる場所）Self: 演出を出した本人(例: 攻撃した本人)。Context Target: 相手(例: 攻撃を受けた敵)。World / Anchor: 場所を固定したい据え置きの演出向け(下の Anchor 欄の位置をそのまま使う)。
AnchorVFX・SE を出す細かい位置(ボーン名や右手・足元など)。Anchor のページと同じ形式。この欄はエフェクト・効果音側のデータ(VfxData/SeData)が持つ Anchor と組み合わさって、次の 3 通りのどれかで実際に出す位置が決まります。
状況実際に出る位置
この欄が未設定、エフェクト・効果音側だけに Anchor が設定されているエフェクト・効果音側の Anchor をそのまま使う
この欄だけ設定されている(エフェクト・効果音側は未設定)この欄の Anchor をそのまま使う
両方に設定されているこの欄の Anchor を基準にして、エフェクト・効果音側の Anchor がそこからの相対位置として上乗せされる(「この欄を親、エフェクト側を子」として組み合わさる)
トラック一覧の「Anchor(VFX/SE の位置)」の見出しに、今どの状況かが 1 行で表示されます。
ParamsKind ごとの追加パラメータ(例: Kind=HitStop なら「何秒止めるか」を 1 つ目に入れる)。Kind=Vfx のときは、そのエフェクト側(VfxData の Params)と同じ並び順(ラベル名の順番=インデックス)の値を上書きします(色を差し替える、など)。Kind=Se の音量上書きにはまだ対応していません(値を入れても音量には反映されません)。他の Kind では今のところ使われません。
Stop On Cancel途中で演出が中断された(Cancel された)とき、このトラックで出した物(VFX・SE 等)も一緒に止めるか。オフなら鳴らし切る。
ScopeKind が HitStop / CameraShake / Haptic のときだけ使います。 Everyone(既定): 通信対戦で相手の画面にもそのまま届き、全員が発火します。Participants Only: 通信対戦で当事者(攻撃した本人・当たった相手)以外には届かず、関係のないプレイヤーの画面停止・画面揺れ・振動は起きません。詳しくは下の「通信対戦（オンライン対戦）での演出」を参照してください。

トラックの種類（Kind）

Kind内容今の対応状況
Anim / Anim2Dアニメーションを再生する対応済み
Se / Bgm効果音 / BGM を鳴らす対応済み
Vfxエフェクトを出す対応済み
CanvasUI 画面(ポップアップ等)を開く対応済み
UiTweenUI の動き(UI Tween)を再生する対応済み
HitStop一瞬だけゲーム全体の時間を止める(「ヒットストップ」演出)。Params の 1 つ目に止める秒数を入れる対応済み

共通項目

項目説明
Total Duration演出全体の長さ(秒)。0 のままにすると、At Time トラックの一番遅い時刻から自動で決まります。「On Signal のトラックだけ」で組んだ演出は、この自動計算だと 0 秒扱いになりすぐ終わってしまうため、必ず秒数を入れてください。0 のままにしている間はタイムライン右上に小さく「⚠ 尺が未設定です」と出ます。共通設定の警告にある「トラックの最後に合わせる」ボタンを押すと、各トラックの終わりの時刻(アニメ・効果音は長さも考慮)に合わせて自動で数値を入れてくれます。
Interruptible途中で中断(Cancel)できるか。オフにすると、プログラム側が止めようとしても無視されます(最後まで再生し切る前提の演出向け)。

専用エディタの使い方（剣攻撃を作る流れ）

Tools > D-Drive > Presentation Editor を開き、対象アセット欄に演出データ（新規なら「＋ 新規作成」）を選びます。

  1. トラックを置く: 画面中央のタイムラインへ、Asset Browser や Project ウィンドウから SE・VFX・アニメ・配置セット等のデータをドラッグ＆ドロップすると、種類に応じたレーン（Anim/Anim2D・Se/Bgm・Vfx/AnchorGroup・CameraShake/Haptic・HitStop/Marker・Signal・Canvas/UiTween）へ自動でトラックが追加されます。時刻は落とした位置がそのまま入ります（後から左右にドラッグして直せます）。手入力したい場合は下の「＋ トラックを追加」から Kind を選んで空のトラックを足せます。Kind を後から変えると Asset 欄は空にリセットされます（別の種類のデータが誤って残らないようにするための安全策です。差し替え後にもう一度 Asset を選んでください）
  2. トラックを直す: タイムラインの色つきマーカーをクリックすると下の一覧でそのトラックが開きます。Trigger（At Time / On Signal）・時刻・Signal Key・Asset・Target・Anchor（出す位置）・Params（上書きパラメータ）・Stop On Cancel を編集できます。「複製」「削除」ボタンも各トラックにあります
  3. モデルを置いて統合プレビュー: 「モデル選択」でモデルを選び「配置」を押すと確認用シーンにモデルが出ます（Animator が無いモデルでも VFX/SE/揺れ/振動の基準点として使えます）。「▶ 再生」を押すと、そのモデルを起点に アニメ・SE・エフェクト・カメラの揺れ・コントローラーの振動が実際に同時に再生されます（SceneView / Game ビューで確認、パッドを接続していれば実機振動も確認できます）
  4. Anchor（出す位置）を SceneView で確認・編集する: Vfx・Se トラックには「出す位置」があり、文字だけでは分かりにくいため SceneView に表示できます。トラック一覧の上にある「SceneView 表示」を ON にすると、位置を持つトラックがシーン上に色つきの点として表示されます（Vfx=マゼンタ、Se=シアン、AnchorGroup=黄緑）。「表示対象」を「すべて」にすると位置を持つ全トラックの点が、「選択中のみ」にすると今トラック一覧で開いている 1 本だけが表示されます。点をクリックするとそのトラックがトラック一覧で選択（展開・スクロール）されます。他のウィンドウ（VFX Editor 等）を触っていて薄く表示されているときでも、点をクリックすればこのウィンドウに切り替わります。移動・回転ハンドルは、位置を持つトラックであれば状況に関わらず常に最終的な出す位置に表示されます（上の表の「この欄だけ設定」「両方に設定」はもちろん、「エフェクト・効果音側だけ設定」の状況でも表示されます）。「エフェクト・効果音側だけ設定」の状況でハンドルを動かすと、その最終位置になるようにトラック側の Anchor が自動で設定され、「両方に設定」の状況に切り替わります（元のエフェクト・効果音側のデータ自体は変わりません）。「両方に設定」の状況でも掴む点は常に最終位置で、動かすとトラック自身の Anchor が自動で計算し直されます。エフェクト・効果音側の Anchor（子）は最終位置までの経路として点線で表示されるだけで、直接は動かせません（子を直したいときは VFX Editor / Audio Editor / Anchor Editor を開いてください）。SceneView 上で移動/回転ツールを切り替えると、ハンドルも移動・回転に切り替わります。AnchorGroup トラックは配置セットの全点を番号付きで表示しますが、点の移動・編集はできません（点の並び・位置を変えたいときはAnchor Group Editorを開いてください）。Anchor（出す位置）を持たない Kind（Anim・CameraShake・Haptic など）は表示されません。ハンドルで動かした結果はそのトラック自身に保存され、次の「▶ 再生」/「⏮ 最初から」から反映されます（再生中の実体はその場では動きません）
  5. 専用エディタを同時に開く: トラック一覧の各行に「専用エディタで開く（一緒に調整）」「単体で確認用シーンに開き直す」の 2 つのボタンがあります（対応する専用エディタがある種類のトラックのみ）。「一緒に調整」は、今の確認用シーン・配置したモデル・再生状態をそのまま維持して専用エディタ（VFX Editor / Anchor Group Editor / Anim Editor など）を開きます。専用エディタの「スポーン先」欄には、このウィンドウで配置したモデル（Self）が自動で入ります。専用エディタ側で調整した内容は、Presentation Editor 側で次に「▶ 再生」/「⏮ 最初から」を押したときに反映されます。Anchor Group Editor を「一緒に調整」で開いて配置セットの点を動かすと、Presentation Editor 側の SceneView の点表示にもすぐに反映されます（2 つのウィンドウを並べて確認できます）。「単体で確認用シーンに開き直す」は、専用エディタのいつもの流れ（そのアセット単体の確認用シーンを開く）で開きます。こちらを選ぶと Presentation Editor 側のプレビューは片付きます。
  6. Signal を手動で送る: 「onHit」のような Trigger=On Signal のトラックを作ると、統合プレビューの中に「Signal レーン(手動発火)」という枠が現れ、Signal Key ごとにボタン（例: 「Signal: onHit」）が並びます。手順は次の 2 段階です。
    1. まず上の「▶ 再生」を押して演出を再生する（ボタンはこの間だけ有効になり、押せる状態になります）
    2. 再生中に「Signal レーン」のボタンを押すと、コード側から「当たった」等の合図が来たのと同じ動きを試せます（ログ欄に「手動発火: Signal("onHit")」と出ます）
    停止中はボタンがグレーアウトして押せません（合図を受け取る演出自体が動いていないため、押しても何も起きないことを分かりやすくするための表示です）。ボタンにカーソルを合わせると同じ説明がツールチップで出ます。On Signal のトラックが 1 つも無い場合は「(On Signal のトラックがありません…)」という案内だけが表示されます
  7. タイムラインを拡大縮小して見る: 演出が短い(または細かく作り込みたい)ときは、タイムライン上部の「－」「＋」ボタンかズームスライダーで拡大縮小できます。タイムライン上でCtrl(Mac は Cmd)+マウスホイールを回すと、カーソルの位置を中心にその場でズームできます。拡大した状態では、ホイールを普通に回す、またはタイムライン下部の横スクロールバー(ミニマップ)をドラッグすると左右に移動できます。目盛りの間隔(1 秒 / 0.5 秒 / 0.1 秒 / フレーム単位)は拡大の度合いに応じて自動で見やすく切り替わります。元に戻したいときは「全体表示」ボタンを押してください(対象アセットを切り替えたときも自動で全体表示に戻ります)
  8. タイムライン上でもシークできる: タイムラインの上段(目盛りの帯)をクリック、またはそのままドラッグすると、その時刻へシークします(下の「シーク」スライダーと同じ動きで、値も連動します)。トラックのマーカー(色つきの四角、目盛りより下)をドラッグする操作とは干渉しません
  9. 再生位置が分かりやすい: 再生中はタイムラインを縦に貫く目立った色の線(再生ヘッド)が今の位置を示し、上部に「現在時刻(秒)」と「フレーム数」が出ます。「再生ヘッドに追従」を ON(既定)にしておくと、拡大していても再生ヘッドが画面外に出ないように表示範囲が自動でスクロールします
  10. 速度・シーク・一時停止・ループ: 「速度」スライダー（0.1x〜2x）でスロー再生、「シーク」で好きな時刻へ飛べます（通過したトラックはまとめて発火）。「⏸ 一時停止」を押した後の「▶ 再生」は、最初からではなく一時停止した位置から再開します(ボタンの表示も「▶ 再開」に変わります)。最初から再生し直したいときは「⏮ 最初から」を押してください。ステータス欄には「⏸ 一時停止中 42% (1.26s)」のように現在時刻も出ます（この表示は「ループ」の下の専用の 1 行に出ます）。「ループ」を ON にすると完了後に自動でもう一度再生します。なお、再生位置を手前に戻す(巻き戻す)と、すでに発火したトラックは再発火しません(ログ欄に 1 回だけ注意書きが出ます)。最初から確認したいときは「⏮ 最初から」を使ってください
  11. 環境切替: 「環境切替」を開くと確認用シーンの既存のライトの強さ・カメラの背景色を調整できます（新しい部屋を作るのではなく、今開いているシーンの見た目を変えるだけです）
  12. 新しく割り当てた SE・VFX などは、次の再生から鳴る / 出る: ウィンドウを開いたまま、トラックに SE や VFX・カメラの揺れなどを新しく作って割り当てたときは、いったん「■ 停止」してから「▶ 再生」（または「⏮ 最初から」）を押してください。再生し直すたびに最新のアセットを読み直します。一時停止からの「▶ 再開」は読み直さないので、割り当てを変えたら再開ではなく「⏮ 最初から」を使います。また再生中にトラックを追加・削除すると挙動が不安定になることがあるため、トラックの編集は停止中に行ってください
  13. 保存すれば即反映: ウィンドウを閉じても配置したモデル・揺れ・振動の後片付けは自動で行われます（シーンには保存されません）。保存すれば コード変更なしで ゲーム内の演出に反映されます

剣攻撃デモで確認する

Assets/GameData/PreviewScenes/PresentationSkillSlashPreviewScene.unity を開いて Play すると、剣攻撃の演出(アニメ相当の代わりに VFX+SE を Self に配置、当たった合図で画面停止+SE+画面揺れ+振動)が自動で再生されます。P キーでもう一度再生、Space キーで「当たった」合図(Signal)、C キーで中断(Cancel)を試せます。

通信対戦（オンライン対戦）での演出

演出データの Flags > Net を Cosmetic(「見た目だけで勝敗には影響しない」の意味)にしておくと、通信対戦時にプログラム側の特別な配線なしで自分が再生した演出が相手の画面にも自動で配られ、同じタイミングで再生されます。既定値は Local(自分の画面だけ)なので、相手にも見せたい演出は Flags.Net を Cosmetic に変える必要があります(通常の攻撃演出などは Cosmetic にしておくのが基本です)。

  • Cosmetic（勝敗に影響しない見た目の演出）: 攻撃を当てた側だけでなく、相手の画面にも同じ演出（アニメ・SE・VFX・カメラ揺れなど）が出ます（用語集: Cosmetic）
  • コントローラーの振動だけは鳴らし分けられます: 振動データの「Local Player Only」が ON（既定）のときは、その事象を起こした本人（当事者）のコントローラーだけが振動します。相手の画面にも見た目・音は出ますが、相手のパッドは振動しません
  • 画面停止・画面揺れ・振動は「参加者だけ」に絞れます: HitStop（画面停止）・CameraShake（画面揺れ）・Haptic（振動）の各トラックには Scope 欄があります。Everyone(既定)のままなら今までどおり全員に届きますが、Participants Only にするとその演出を起こした本人（Self）と対象（Target）以外には届かなくなります。3 人以上が同時にプレイする対戦で、無関係なプレイヤーの画面まで一緒に止まったり揺れたりしないようにしたいときに使います。演出データの「Predict Local」がオンで、行為者本人の画面だけ自分の入力に合わせてひと足先に再生される分は、Scope の設定に関わらず常に再生されます
2026-09-14 時点では、実際のオンライン対戦の配線（NGO）自体は次の開発段階（Phase 6）で接続される予定です。上記の Cosmetic の振り分けの仕組みそのものは既に用意されており（テストで確認済み）、接続が済めばデータ側の設定変更なしでそのまま動く想定です。

よくある警告と直し方

警告意味と直し方
トラック N(Kind)の Asset が未設定ですそのトラックが使う ID(VfxData など)を設定してください。Marker/Signal/HitStop は対象外です。
SignalKey が空ですOn Signal トラック、または Marker/Signal の名前欄が空です。半角英数字などで名前を入れてください。
Time が Total Duration を超過していますそのトラックが鳴る前に演出全体が終わってしまいます。Total Duration を伸ばすか、Time を短くしてください。
Interruptible=false ですが尺が長すぎます10 秒を超える演出を「中断不可」にすると、プレイヤーを長時間拘束してしまいます。本当に中断不可でよいか見直してください。
トラック N(AnchorGroup)の Asset の種別が AnchorGroup ではありませんAsset 欄に配置セット以外のデータ(VfxData など)が入っています。配置セットのデータを選び直してください。
トラックとアセット側の両方に Anchor が設定されているため、親子合成されます警告ではなくお知らせです。トラックの Anchor とエフェクト・効果音側の Anchor を両方設定すると、上の Anchor 欄の説明どおり自動で組み合わさります。意図した組み合わせなら無視してかまいません。
