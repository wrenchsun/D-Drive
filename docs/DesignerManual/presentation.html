演出（Presentation）の設定項目

「剣攻撃」のように、アニメ・効果音・エフェクト・カメラ揺れ・振動・画面停止（ヒットストップ）などを 1 つにまとめたものが「演出（PresentationData）」です。プログラマーは Presentation.Play(演出のID, ...) と 1 行書くだけで、中身（何を・いつ・どう鳴らすか）はすべてこのデータで決まります。あとから演出の中身を差し替えても、プログラムの修正は不要です。

専用エディタ: Tools > D-Drive > Presentation Editor（目玉機能につき Tools メニュー最上段）でトラックをタイムライン形式で編集し、実際にアニメ・SE・エフェクト・画面揺れ・振動を同時に再生して確認しながら作れます。使い方は下の「専用エディタの使い方」を参照してください。

基本の考え方: トラック（Tracks）

演出は「トラック」という短い指示の集まりでできています。1 本のトラックは「いつ」「何を」の 2 つを決めます。

項目説明
Trigger（いつ）At Time: 再生開始から何秒後に鳴らすか(Time 欄に秒数)。0 秒は「開始と同時」。
On Signal: プログラム側が「合図（例: 攻撃が当たった）」を送ってきたら鳴らす。Signal Key 欄に合図の名前(例: hit)を入れる。
Kind（何を）下記「トラックの種類」参照。
Asset（何のデータを）Kind に応じた ID(例: Kind=Vfx なら VfxData の ID)。Marker/Signal/HitStop は不要。
Target（基準になる場所）Self: 演出を出した本人(例: 攻撃した本人)。Context Target: 相手(例: 攻撃を受けた敵)。World / Anchor: 場所を固定したい据え置きの演出向け(下の Anchor 欄の位置をそのまま使う)。
AnchorVFX・SE を出す細かい位置(ボーン名や右手・足元など)。Anchor のページと同じ形式。
ParamsKind ごとの追加パラメータ(例: Kind=HitStop なら「何秒止めるか」を 1 つ目に入れる)。Kind=Vfx のときは、そのエフェクト側(VfxData の Params)と同じ並び順(ラベル名の順番=インデックス)の値を上書きします(色を差し替える、など)。Kind=Se の音量上書きにはまだ対応していません(値を入れても音量には反映されません)。他の Kind では今のところ使われません。
Stop On Cancel途中で演出が中断された(Cancel された)とき、このトラックで出した物(VFX・SE 等)も一緒に止めるか。オフなら鳴らし切る。

トラックの種類（Kind）

Kind内容今の対応状況
Anim / Anim2Dアニメーションを再生する対応済み
Se / Bgm効果音 / BGM を鳴らす対応済み
Vfxエフェクトを出す対応済み
CanvasUI 画面(ポップアップ等)を開く対応済み
UiTweenUI の動き(UI Tween)を再生する対応済み
HitStop一瞬だけゲーム全体の時間を止める(「ヒットストップ」演出)。Params の 1 つ目に止める秒数を入れる対応済み
Markerプログラム側に「ここまで来た」を知らせるだけの目印(見た目には何も起きない)。Signal Key 欄が目印の名前になる対応済み
Signalプログラム側の処理を直接呼び出すための合図(Marker と似ているが、コード側の受け取り方が違う)。Signal Key 欄が合図の名前になる対応済み
CameraShake画面を揺らす。Asset 欄にカメラシェイクのデータの ID を入れる対応済み
Hapticコントローラーを振動させる。Asset 欄に振動データの ID を入れる対応済み
TimelineUnity Timeline を再生する(カットシーン向け)未対応(近日実装予定)

共通項目

項目説明
Total Duration演出全体の長さ(秒)。0 のままにすると、At Time トラックの一番遅い時刻から自動で決まります。「On Signal のトラックだけ」で組んだ演出は、この自動計算だと 0 秒扱いになりすぐ終わってしまうため、必ず秒数を入れてください。0 のままにしている間はタイムライン右上に小さく「⚠ 尺が未設定です」と出ます。共通設定の警告にある「トラックの最後に合わせる」ボタンを押すと、各トラックの終わりの時刻(アニメ・効果音は長さも考慮)に合わせて自動で数値を入れてくれます。
Interruptible途中で中断(Cancel)できるか。オフにすると、プログラム側が止めようとしても無視されます(最後まで再生し切る前提の演出向け)。

専用エディタの使い方（剣攻撃を作る流れ）

Tools > D-Drive > Presentation Editor を開き、対象アセット欄に演出データ（新規なら「＋ 新規作成」）を選びます。

  1. トラックを置く: 画面中央のタイムラインへ、Asset Browser や Project ウィンドウから SE・VFX・アニメ等のデータをドラッグ＆ドロップすると、種類に応じたレーン（Anim/Anim2D・Se/Bgm・Vfx・CameraShake/Haptic・HitStop/Marker・Signal・Canvas/UiTween）へ自動でトラックが追加されます。時刻は落とした位置がそのまま入ります（後から左右にドラッグして直せます）。手入力したい場合は下の「＋ トラックを追加」から Kind を選んで空のトラックを足せます。Kind を後から変えると Asset 欄は空にリセットされます（別の種類のデータが誤って残らないようにするための安全策です。差し替え後にもう一度 Asset を選んでください）
  2. トラックを直す: タイムラインの色つきマーカーをクリックすると下の一覧でそのトラックが開きます。Trigger（At Time / On Signal）・時刻・Signal Key・Asset・Target・Anchor（出す位置）・Params（上書きパラメータ）・Stop On Cancel を編集できます。「複製」「削除」ボタンも各トラックにあります
  3. モデルを置いて統合プレビュー: 「モデル選択」でモデルを選び「配置」を押すと確認用シーンにモデルが出ます（Animator が無いモデルでも VFX/SE/揺れ/振動の基準点として使えます）。「▶ 再生」を押すと、そのモデルを起点に アニメ・SE・エフェクト・カメラの揺れ・コントローラーの振動が実際に同時に再生されます（SceneView / Game ビューで確認、パッドを接続していれば実機振動も確認できます）
  4. Signal を手動で送る: 「onHit」のような Trigger=On Signal のトラックを作ると、統合プレビューの中に「Signal レーン(手動発火)」という枠が現れ、Signal Key ごとにボタン（例: 「Signal: onHit」）が並びます。手順は次の 2 段階です。
    1. まず上の「▶ 再生」を押して演出を再生する（ボタンはこの間だけ有効になり、押せる状態になります）
    2. 再生中に「Signal レーン」のボタンを押すと、コード側から「当たった」等の合図が来たのと同じ動きを試せます（ログ欄に「手動発火: Signal("onHit")」と出ます）
    停止中はボタンがグレーアウトして押せません（合図を受け取る演出自体が動いていないため、押しても何も起きないことを分かりやすくするための表示です）。ボタンにカーソルを合わせると同じ説明がツールチップで出ます。On Signal のトラックが 1 つも無い場合は「(On Signal のトラックがありません…)」という案内だけが表示されます
  5. タイムラインを拡大縮小して見る: 演出が短い(または細かく作り込みたい)ときは、タイムライン上部の「－」「＋」ボタンかズームスライダーで拡大縮小できます。タイムライン上でCtrl(Mac は Cmd)+マウスホイールを回すと、カーソルの位置を中心にその場でズームできます。拡大した状態では、ホイールを普通に回す、またはタイムライン下部の横スクロールバー(ミニマップ)をドラッグすると左右に移動できます。目盛りの間隔(1 秒 / 0.5 秒 / 0.1 秒 / フレーム単位)は拡大の度合いに応じて自動で見やすく切り替わります。元に戻したいときは「全体表示」ボタンを押してください(対象アセットを切り替えたときも自動で全体表示に戻ります)
  6. タイムライン上でもシークできる: タイムラインの上段(目盛りの帯)をクリック、またはそのままドラッグすると、その時刻へシークします(下の「シーク」スライダーと同じ動きで、値も連動します)。トラックのマーカー(色つきの四角、目盛りより下)をドラッグする操作とは干渉しません
  7. 再生位置が分かりやすい: 再生中はタイムラインを縦に貫く目立った色の線(再生ヘッド)が今の位置を示し、上部に「現在時刻(秒)」と「フレーム数」が出ます。「再生ヘッドに追従」を ON(既定)にしておくと、拡大していても再生ヘッドが画面外に出ないように表示範囲が自動でスクロールします
  8. 速度・シーク・一時停止・ループ: 「速度」スライダー（0.1x〜2x）でスロー再生、「シーク」で好きな時刻へ飛べます（通過したトラックはまとめて発火）。「⏸ 一時停止」を押した後の「▶ 再生」は、最初からではなく一時停止した位置から再開します(ボタンの表示も「▶ 再開」に変わります)。最初から再生し直したいときは「⏮ 最初から」を押してください。ステータス欄には「⏸ 一時停止中 42% (1.26s)」のように現在時刻も出ます。「ループ」を ON にすると完了後に自動でもう一度再生します。なお、再生位置を手前に戻す(巻き戻す)と、すでに発火したトラックは再発火しません(ログ欄に 1 回だけ注意書きが出ます)。最初から確認したいときは「⏮ 最初から」を使ってください
  9. 環境切替: 「環境切替」を開くと確認用シーンの既存のライトの強さ・カメラの背景色を調整できます（新しい部屋を作るのではなく、今開いているシーンの見た目を変えるだけです）
  10. 保存すれば即反映: ウィンドウを閉じても配置したモデル・揺れ・振動の後片付けは自動で行われます（シーンには保存されません）。保存すれば コード変更なしで ゲーム内の演出に反映されます

剣攻撃デモで確認する

Assets/GameData/PreviewScenes/PresentationSkillSlashPreviewScene.unity を開いて Play すると、剣攻撃の演出(アニメ相当の代わりに VFX+SE を Self に配置、当たった合図で画面停止+SE+画面揺れ+振動)が自動で再生されます。P キーでもう一度再生、Space キーで「当たった」合図(Signal)、C キーで中断(Cancel)を試せます。

通信対戦（オンライン対戦）での演出

演出データの Flags > Net を Cosmetic(「見た目だけで勝敗には影響しない」の意味)にしておくと、通信対戦時にプログラム側の特別な配線なしで自分が再生した演出が相手の画面にも自動で配られ、同じタイミングで再生されます。既定値は Local(自分の画面だけ)なので、相手にも見せたい演出は Flags.Net を Cosmetic に変える必要があります(通常の攻撃演出などは Cosmetic にしておくのが基本です)。

  • Cosmetic（勝敗に影響しない見た目の演出）: 攻撃を当てた側だけでなく、相手の画面にも同じ演出（アニメ・SE・VFX・カメラ揺れなど）が出ます（用語集: Cosmetic）
  • コントローラーの振動だけは鳴らし分けられます: 振動データの「Local Player Only」が ON（既定）のときは、その事象を起こした本人（当事者）のコントローラーだけが振動します。相手の画面にも見た目・音は出ますが、相手のパッドは振動しません
2026-09-14 時点では、実際のオンライン対戦の配線（NGO）自体は次の開発段階（Phase 6）で接続される予定です。上記の Cosmetic の振り分けの仕組みそのものは既に用意されており（テストで確認済み）、接続が済めばデータ側の設定変更なしでそのまま動く想定です。

よくある警告と直し方

警告意味と直し方
トラック N(Kind)の Asset が未設定ですそのトラックが使う ID(VfxData など)を設定してください。Marker/Signal/HitStop は対象外です。
SignalKey が空ですOn Signal トラック、または Marker/Signal の名前欄が空です。半角英数字などで名前を入れてください。
Time が Total Duration を超過していますそのトラックが鳴る前に演出全体が終わってしまいます。Total Duration を伸ばすか、Time を短くしてください。
Interruptible=false ですが尺が長すぎます10 秒を超える演出を「中断不可」にすると、プレイヤーを長時間拘束してしまいます。本当に中断不可でよいか見直してください。
