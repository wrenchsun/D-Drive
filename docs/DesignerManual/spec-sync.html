仕様書との同期

企画が Google スプレッドシート（仕様書）に「アセット」タブへ 1 行書くだけで、D-Drive 側に Placeholder（空のデータ） が自動でできる機能です。プログラマーはその場でコードから ID を参照できるようになり、デザイナーは後から中身（音・エフェクト・見た目）を作り込みます。

仕様書そのものの作り方（テンプレートのアップロード・タブの書き方）は、テンプレート同梱の README.md（記入ガイド）を参照してください。このページは「D-Drive 側でどう同期するか」の説明です。

できること

  • 仕様書の「アセット」タブに新しい行を書く → 同期すると、その種別・カテゴリ・識別子で ID 付きの空データ が自動的にできる
  • 表示名・カテゴリ・状態・担当・備考・仕様リンクを書き換える → 同期すると、その項目だけが上書きされる（デザイナーが作り込んだ音やエフェクトの中身には触れません）
  • 行を消す → データ自体は消えず、「シートから消えた（Archive 候補）」という一覧に表示されるだけ（実際に消すのは人の判断）
  • 「調整値」タブに書いた数値をプログラムのコードから読める（プログラマー向け）

同期のやりかた

  1. Tools → D-Drive → 仕様書と同期 を開く
  2. 「スプレッドシート URL」に仕様書の URL を貼って「設定を保存」（最初の 1 回だけ）
  3. 「取得」ボタンを押す（少し待つとシートの内容を読み込みます）
  4. 「新規」「変更」に出てきた行を確認する。チェックが付いている行が対象。外したい行はチェックを外す
  5. 「適用」を押す
起動時に自動でチェックされます。 Unity を開いたときに仕様書に変更があると、Asset Browser のツールバーに「仕様書に変更 n 件」というボタンが出ます。押すとこの同期ウィンドウが開きます。自動では作成・上書きはしません（見つけるだけ）。

画面の見かた

区分意味
新規仕様書にあるが D-Drive にまだ無い行。チェックを付けたまま「適用」すると Placeholder が作られる
変更D-Drive に既にあるデータと、表示名・カテゴリ・状態・担当・備考・仕様リンクのいずれかが違う行。「適用」すると違う項目だけ書き換わる
シートから消えた（Archive 候補・表示のみ）以前 D-Drive にあるものとして同期されたのに、今回のシートに見当たらない行。ここに出ても何も自動では起きません。削除するかどうかは人が判断してください
衝突（行番号付き。適用不可）同じ「種別＋識別子」が 2 行ある、識別子が英語 PascalCase になっていない、種別が不明、などの理由で読み込めなかった行。シート側を直してから再度「取得」してください
「衝突」に出た行は絶対に無視しないでください。その行だけ同期されず、コードから参照できるようになりません。よくある原因は「識別子が sword_slash（小文字・アンダーバー）になっている」「同じ識別子を別の行にも書いてしまった」です。

「担当」「状態」はどこに反映される？

同期されたデータの Inspector を見ると、「Assignee（担当）」欄に仕様書の担当がそのまま入ります。「状態」は Tags 欄に State/仮 のような形で入ります（専用の欄ではなく、既存の Tags を使っています）。

仕様書を開くボタン（Inspector）

仕様書の「仕様」列にリンクを書いておくと、同期後そのデータの Inspector 最上部に 「📄 仕様書を開く」 ボタンが出ます。押すとブラウザで該当の仕様書が開きます。リンクが無いデータにはボタンは出ません。

調整値（プログラマー向け）

「調整値」タブに書いた数値（ヒットストップの秒数、影響力の係数など）は、同期すると D-Drive の内部データに取り込まれ、プログラムのコードから次のように読めます。

using DDrive.Generated; // TUNING.キー定数
using DDrive.Runtime.Tuning;

float hitStopSec = Tuning.GetFloat(TUNING.CombatHitStopSec, defaultValue: 0.05f);

企画が「調整値」タブの数字を変えて同期するだけで、次にゲームを実行したときからその値が反映されます（コードの書き換え不要）。キーが仕様書に無い場合は既定値が使われ、ゲームは止まりません。

選択肢・既存アセットをシートに貼る

ボタン用途
選択肢をコピー種別・状態・型の一覧をコピー。シートの「_選択肢」タブに貼るとプルダウンが D-Drive の最新一覧と揃う
既存アセットをコピーすでに D-Drive にある一覧を「アセット」タブと同じ形式でコピー。運用を始める最初に、既存の分をシートへまとめて貼りたいときに使う

よくある質問

  • Q. 中身を作り込んだ後にシートの表示名を変えたら、上書きされて消える？ → 表示名・カテゴリ・状態・担当・備考・仕様リンクだけが書き換わります。音源・カーブ・Prefab など実際の中身は同期では一切触りません。
  • Q. 行を消したら本当に消える？ → 消えません。「シートから消えた」一覧に出るだけで、実際に削除するかは人が判断します。
  • Q. シートの種別を「ControlSkin」にしたのに新規作成されない → ControlSkin は「ボタン用」「スライダー用」の 2 種類があり、どちらを作るかを D-Drive 側で決められないため自動作成をスキップします（Console に警告が出ます）。Asset Browser の「新規」から手動で作成してください。
