アニメーション（3D）の設定と Anim Editor

最終更新日: 2026-10-13

アニメーションデータ（AnimData）は「この Clip を、このステートで、いつ効果音・エフェクトを出しながら再生するか」をまとめたものです。基本の動き（待機・歩き）は Animator Controller に持たせ、攻撃・被弾などのワンショットを D-Drive のアニメーションデータで再生します。

  • Clip に Unity の AnimationEvent を埋め込む必要はありません。「15 フレーム目で斬撃音」のようなイベントはデータ側に持ち、Clip を差し替えても消えません
  • Anim Editor でモデルを動かしながらイベントの位置を決め、効果音・エフェクトも同時に確認できます
  • やりたいことごとのカード（動かす / 合図 / 表情・手足 / 確認する / 管理情報）に欄が並び、イベントや表情は1 件 = 1 行の一覧で数が多くても見通せます

開き方

  1. Asset Browser の「新規」ボタンで種別に Anim を選んで作る（表示名は日本語 OK）
  2. アニメーションデータを Project で選び、Inspector の一番上の「▶ Anim Editor で開く」を押す（効果音・VFX・モデル・Anchor も同じ場所に「〜で開く」があります）
  3. またはメニューバー Tools > D-Drive > Editors > Animation (3D)。Project でアニメーションデータを選ぶと自動で入ります。何も選んでいないときは、ウィンドウの真ん中の枠にドロップするか、最近使ったものから選びます
  4. 演出（Presentation）のトラックの「専用エディタで開く（一緒に調整）」からも開けます。このときは演出の確認用シーンに置かれたモデルが、そのまま「動かす相手」になります
最初に「確認用シーン」を押してください。 動かすモデルは今開いているシーンの中に出るので、カメラやライトの無いシーンだと何も見えません。確認用シーンはライト・カメラ・床の揃った専用のシーンです。

はじめの一歩（攻撃モーションに斬撃音を付ける）

  1. アニメーションデータを作り、「動かす」カードの再生するクリップに攻撃の Clip、ステート名に Controller 上のステート名（Clip と同じ名前なら空でも可）を入れる
  2. 「確認する」カードの確認用のモデルにキャラクターの ModelData を入れ、上の「確認用シーン」を押す → シーンにモデルが置かれ、動かす相手になる
  3. 下の固定バーの ▶ 再生 → SceneView でモデルが攻撃モーションで動く。タイムラインの白い線が進む
  4. タイムラインをクリックして再生ヘッドを 15 フレーム目あたりに置き、「合図（イベント）」カードの「＋ 現在位置に SE」→ 行の ⚙ を開いて Target で斬撃の SE を選ぶ
  5. ▶ 再生 → 15 フレーム目で音が鳴り、「イベントログ」に出る。タイミングを直したいときはタイムラインのマーカーをドラッグ（または行の時刻の数字を直す）
  6. 同じ要領で「＋ VFX」でエフェクトを選ぶと、シーン上のモデルの位置にエフェクトが出ます（エフェクト側の Anchor がボーン指定なら、そのボーンから）
プログラマーは Anim.Play(ANIMID.Attack01, animator) と書くだけです。音やエフェクトのタイミングはデータ側で何度でも直せます。

再生・保存バー（ウィンドウ下部に固定）

操作説明
▶ 再生 / ■ 停止ゲームを実行せずにその場で再生。SceneView を見てください。再生中の ▶ は最初からやり直します。■ 停止はその瞬間のポーズのまま止まり、前に出した音・エフェクト・配置セットは消えます。
リピートON にすると、終わるたびに自動でもう一度再生します（何度も ▶ を押さなくてよい）。
速度再生速度（0.1〜2 倍）。右の「×1.0」を押すと等倍に戻ります。
変更 N 件 / 保存まだ保存していない変更の数。「保存」でアセットに書き込みます（保存のたびに版数が進みます）。ウィンドウを閉じる・別のものに切り替えるときも、未保存なら確認が出ます。
自動保存ON にすると、編集が止まって 1 秒たつと自動で保存します。

Ctrl+Z / Ctrl+Y で戻せます。ウィンドウの値・イベントの並びが一緒に戻ります。

カード「動かす」

どのクリップを、どのステートで、どう切り替えて動かすか。

項目説明
再生するクリップ再生するアニメーションクリップ（必須）。長さとフレームレートはイベントの位置と終了判定に使います。未設定は Error
ステート名Animator Controller 上のステート名。空なら Clip の名前を使います。対象のモデルの Controller に無い名前だと、「確認する」カードに Error が出ます（再生自体は止まらず、イベントだけ動きます）
ループ再生ON で周回し続ける（止める指示があるまで）。周回ごとに OnLoop イベントが出て、Frame / Time のイベントも毎周出ます
切り替え時間（秒）前のモーションからこのモーションへ切り替わるときの混ざり秒数（CrossFade）。0.1 くらいが自然。2 秒を超えると警告
レイヤー / アバターマスク / 動作の取り決め（詳細）レイヤー番号（上半身用などは 1）、上半身だけ等のマスク（情報用。実際の適用は Controller のレイヤー設定）、使い回し・ポーズ・ネットの取り決め

Animator のステートから選ぶ

動かす相手の Controller にあるステートが1 ステート（クリップ）= 1 行で並びます（見出しは「14 ステート・AnimData あり 6」のように件数だけ。押して開きます）。

  • 各行に、クリップ名と対応するアニメーションデータ（あれば名前）が出ます。「選ぶ」でそのアニメーションデータに切り替わり、まだ無い行は「作成」を押すだけで作られます（ID 発行・カタログ・Addressables 登録）
  • 一覧の上の検索と「AnimData あり / なし」で絞り込めます。「再スキャン」で Controller とアニメーションデータの有無を読み直します
  • 方向違いのクリップにも同じ音を付けたいときは、「合図（イベント）」カードの「イベントをほかの AnimData へコピー」の「同じステートの他クリップの AnimData へ一括コピー（無ければ作成）」

カード「合図（イベント）」

再生の節目に、効果音・エフェクト・配置セットを出します。

タイムライン

フレームごとの目盛り（太い目盛りにはフレーム番号）と再生ヘッドが出ます。

  • クリックでその位置にシークして一時停止（絵を止めて確認できます。イベントは鳴りません）
  • イベントのマーカー: 黄 = 効果音・エフェクトなど（PlayAsset）、水色 = それ以外、赤 = Clip の長さを超えている。マーカーの下には「F15 剣の斬撃音」のように時刻と対象の名前が出ます（重なるときは省略されます）
  • マーカーをドラッグすると時刻が変わります（ドラッグ 1 回が Ctrl+Z 1 回で戻ります）。マーカーを押すと、一覧のその行が選ばれます
  • SE は波形が重なって表示されるので、どこまで鳴るかが分かります

イベントの一覧

1 イベント = 1 行です。行は「#番号・種類のチップ（SE / VFX / 配置セット / ほか）・対象の名前・「F12 (0.40s) · 毎周回」の 1 行要約・▶ 試聴・⚙・✕」。⚙ で開くのはその行だけです。一覧の上の「検索」と「対象あり / 対象なし」・種類のチップで絞り込めて、件数（「12 イベント中 対象あり 11」）も出ます。20 行を超えると、一覧の中だけがスクロールします。

  1. タイムラインをクリックして、鳴らしたい位置に白い線（再生ヘッド）を置く
  2. 「＋ 現在位置に SE」（または「＋ VFX」「＋ 配置セット」）を押す → 行が増えて開く。「＋ そのほか」は対象のない空のイベントで、Action を変えて使います
  3. 行の ⚙ の Target で音・エフェクトを選ぶ。行の「▶」でその音だけ試聴できます
  4. 時刻の数字を直すか、タイムラインのマーカーをドラッグして位置を調整（Trigger が Time＝秒指定の行には「= F12」のようにフレーム換算も出ます）
  5. 「繰り返し」を決める: 毎周回 = ループするたびに出す（足音など）/ 1 回 = 再生ごとに 1 回 / 再生中は維持 = 1 回出してモーションが終わるまで付いていき、終わると消える（ダッシュの土煙など、ループするエフェクト向け）。「1 回」「再生中は維持」は OnSpawn や OnLoop のような時刻以外のタイミングにも効き、タイムラインで再生ヘッドを戻してももう一度は出ません
  6. 「専用エディタで開く」でその音・エフェクトの専用エディターが開きます（中身を直したいとき）。「複製」で直後に同じイベントを足せます
Triggerいつ出るか
Frame / TimeClip の何フレーム目 / 何秒
OnSpawn / OnLoop / OnDisable / OnDestroy再生開始 / 周回 / 止まった・中断された / 最後まで再生した
Customプログラムからの合図（CustomKey）

Action は PlayAsset（SE / VFX / 配置セットを出す）のほか、SetParam（値を送る）・SendMessage・Duck（ほかの音を下げる）があります。PlayAsset 以外は「ほか」のチップで一覧に並び、⚙ の Target / Param を設定します。

▶ で最初から再生し直すときと ■ 停止のときは、前に出した音・エフェクトは消えます。
新しく作った SE / VFX をイベントに割り当てたとき: ウィンドウを開いたままで割り当てても、次に「▶ 再生」を押せば鳴る・出ます（再生のたびに最新のアセットを読み直します）。対象の一覧に出てこないときは「一覧を更新」を押してください。
別のアニメーションデータへコピー: 「イベントをほかの AnimData へコピー」を開き、コピー先を選んで「コピー」。コピー先のイベントはまるごと置き換わります（Ctrl+Z で戻せます）。

カード「表情・手足」

項目説明
手足 IK使う手足（左手 / 右手 / 左足 / 右足）にチェックし、ウェイトのカーブ（時間 0〜1 → 強さ 0〜1。空なら常に 1）を決めます。IK の目標位置はプログラム側で設定します
表情（BlendShape）1 シェイプ = 1 行。行の ⚙ で ShapeName と、時間（0〜1）→ ウェイト（0〜100）のカーブを決めます。「＋ BlendShape」で空の行、「＋ モデルのシェイプから」でモデルが持つ名前から選んで追加できます
  • モデルに無い名前の行、名前が空の行には ⚠ が付きます
  • 名前が FC_ / fcs_ で始まるシェイプは外部のツールが管理するため、モデル情報の一覧から隠れ、行に指定すると警告が出ます

カード「確認する」

項目説明
動かす相手（シーン上の Animator）確認用シーン / モデル Prefab を開くと自動で入ります。「選択から取得」で Hierarchy の選択（またはプレハブモードのルート）の Animator を入れることもできます。シーンに置いてある自分のキャラクターを動かしたいときもこれです。「↺ ポーズを戻す」か対象の切り替えで元のポーズに戻ります
確認用のモデルと情報確認用シーンに置くモデル（Animator を持つ ModelData）。「Model Editor で開く」でモデルの設定へ。1 行の要約（Controller 名 / BlendShape の数）と、「モデル情報の詳細」（BlendShape の一覧など）。ステート名・BlendShape 名がモデルに無いときは、ここに警告・エラーで出ます
一時停止・ポーズを戻す・状態⏸ は音・エフェクトも一緒に止まり、もう一度押すと続きから再開します（再生していないときに押すと最初から再生）。「↺ ポーズを戻す」で再生前のポーズに。状態の行に再生位置（フレーム・周回数）が出ます
ブレンド確認（詳細）3 つの確認ができます（下記）。どれもモデルを動かして見るだけで、データは変わりません
イベントログ再生中に発火したイベント・操作の最近 12 行（発火した順）。狙った位置で鳴っているかの確認に

ブレンドを確認する

詳細モードの「ブレンド確認」には、既定で畳まれた 3 つの節があります。

道具使い方見えるもの
遷移シーケンス「＋ Step」で次に再生したいアニメーションを並べ、Step ごとに CrossFade 秒と「前のモーションのどこで切り替えるか（切替位置、0.5 = 半分、1 以上 = 終わってから）」を決めて「▶ シーケンスを再生」。ループを ON にすると繰り返します攻撃 1 → 攻撃 2 → 構え直し、のようなつながりが自然か。CrossFade が短すぎてカクつかないか
レイヤー同時再生「＋ Anim」で上半身用（Layer が 1 のアニメーションデータ）などを入れて「▶ 対象と一緒に再生」。Controller のレイヤーごとにスライダーが出るので、動かしながら見ます走りながら手を振る、などの重ね合わせ。AvatarMask（上半身だけ等）が効いているか
Blend Tree パラメータ横軸・縦軸に Controller のパラメータ（Speed、Direction など）を選び、パッドをドラッグ。1 つずつならスライダー、Bool / Int / Trigger もここで操作できます歩き↔走り、前後左右の混ざり方。境目で足が滑らないか
アニメーションデータの「レイヤー」欄が、どのレイヤーで再生されるかを決めます。同じレイヤーのものを重ねると前のモーションが止まる（中断）ので、上半身用は 1 にしてください。

モデルの Prefab の中で動かす

上の「Prefab で開く」でプレハブモードに入ると、その Prefab のモデルが自動で動かす相手になります。BlendShape や IK の見え方を Prefab を編集しながら確認できます。■ 停止してもポーズはそのまま残るので、止めた絵を見ながら Prefab を直せます。Prefab でもシーンでも、保存（Ctrl+S）の直前に自動で再生前のポーズへ戻してから保存するので、再生中の姿勢が Prefab やシーンに入ることはありません。確認用シーンに置いたモデルは [D-Drive] Anim Preview として Hierarchy に出ますが、シーンには保存されません。

カード「管理情報」

一覧に出る名前・カテゴリ・説明・タグ・担当者・仕様書 URL・変更メモ。ID・版数・最終更新者・最終更新日時は読み取り専用です。

検証

該当する欄の下に、エラー・警告がそのまま出ます（欄に当てはまらないものは「その他の検証」）。「修正」ボタンがあるものはそれで直せます。
