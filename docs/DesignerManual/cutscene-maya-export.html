カットシーン用 FBX を Maya から書き出す

必殺技のカットインやラウンド開始 / 勝利デモのような数秒の短い演出で、Maya で作ったカメラワークとキャラの動きをそのまま Unity で再生するための、Maya 側の書き出し手順です。Maya のスクリプトやプラグインは使いません。標準の FBX 書き出しだけで済みます。Unity 側では、決められたフォルダに FBX を置くだけでカットシーンのデータ（CutsceneData）と Timeline が自動で作られ、そこに効果音・エフェクト・画面揺れなどを足せます。

予告ページです（2026-09-18）。 Unity 側の取り込み機能（Timeline チケット 6-10a〜d）はまだ実装されていません。ただし Maya 側の手順とファイル名のルールは確定済みなので、このページどおりに書き出しておけば、機能ができたときにそのまま取り込めます。機能ができたらこのページの「Unity 側で確認する」以降を実際の画面に合わせて更新します。

先に決めておくこと（プロジェクト共通）

項目決めごと理由
シーンの fpsプロジェクトの既定（30 または 60。どちらかは Unity 側の設定 CutsceneImportProfile で宣言されています。分からなければプログラマーに確認）違う fps でも取り込めますが、Validation に「宣言と違う」というお知らせ（Info）が出ます。同じショットの中でファイルごとに fps が違うのは NG（Warning）
単位・上方向cm・Y-up（Maya の既定のまま）Unity の取り込み既定に合わせ、大きさのずれを防ぐ
キャラリグの名前リグの名前空間（または参照ファイル名）を D-Drive のモデル識別子に揃える（例: モデル識別子が Hero なら名前空間 Hero:）Unity 側で「どのキャラを動かすか」を自動で結び付けるため。違っていても Unity 側で手で結べます
カメラ複数カメラで切り替えて作った場合は、Camera Sequencer の「Ubercam 作成」で 1 台のカメラに焼く1 台にしておくと Unity 側でそのまま 1 本のカメラクリップになる。複数のまま出しても取り込めます（Unity 側でカメラごとにクリップが並ぶ）

ファイル名のルール（これだけ守る）

1 つのショット（= 1 つのカットシーン）は、「カメラ + 小物」の FBX 1 本と、キャラごとの FBX（キャラの数だけ）のセットです。ファイル名で「同じショットか」「どのキャラか」を判別します。

対象ファイル名例Unity 側で起きること
カメラ + 小物<ショット名>.fbxOpening01.fbxカットシーンデータ CUT_<カテゴリ>_Opening01 ができ、カメラはカメラクリップになる
キャラ（1 体ずつ）<ショット名>__<モデル識別子>.fbx（アンダースコア 2 つ）Opening01__Hero.fbx役割 Hero として、モデル Hero に自動で結び付く
同じキャラ 2 体目識別子の末尾に _2、_3 …Opening01__Hero_2.fbx同じモデルを 2 体出す
小物（剣・扉など動く物）ノード名を PRP_<モデル識別子>、または名前空間 = モデル識別子。カメラと同じ FBX に入れるPRP_Swordモデル Sword に結び付く
イベントの目印（任意）ロケーター EVT_<キー>。カメラと同じ FBX に入れるEVT_HitTimeline 上の合図（Signal マーカー cutscene/hit）になる（Unity 側で検証中の機能。無くても Unity の Timeline 上で後から置けます）
@ をファイル名に使わないでください（Hero@Opening01.fbx のような形）。Unity が「同じフォルダの Hero.fbx にアニメを合流させる」古い動きをしてしまうため、区切りは __（アンダースコア 2 つ）にしています。

書き出し手順（1 ショットにつき、1 + キャラ数 回）

なぜキャラごとに分けるのか: Unity は 1 つの FBX に 1 体分の「人型（Humanoid）の骨の定義」しか持てません。2 キャラを 1 つの FBX に入れると片方の動きが正しく移りません。そのため Export Selection をキャラの数だけ行います。手数は増えますが、スクリプト無しの標準機能だけで済みます。
  1. カメラ + 小物: カメラ（Ubercam）・小物（PRP_*）・イベント用ロケーター（EVT_*）だけを選択 → File > Export Selection → 形式 FBX → 名前 <ショット名>.fbx。キャラは選ばない。動かない背景も選ばない（背景は Unity 側のシーンに置きます）
  2. キャラ 1 体目: そのキャラのルートジョイント（骨の一番上）を選択（骨の階層ごと選ばれます。メッシュは選ばない）→ File > Export Selection → 名前 <ショット名>__<モデル識別子>.fbx
  3. キャラ 2 体目以降: 2 を繰り返す（同じキャラが 2 体なら __<識別子>_2）
  4. すべて 同じ保存先に置く: Assets/SourceAssets/Cutscene/<カテゴリ>/（カテゴリは Skill / Round など、Unity 側のフォルダ分け。既にあるフォルダに合わせてください）

書き出しオプション（1〜3 で共通）

項目設定理由
AnimationON—
Bake AnimationON。開始〜終了 = ショットの全フレーム、Step 1IK・コンストレイント・エクスプレッションは Unity に持っていけないので、キーに焼きます。同じショットの全ファイルで開始〜終了フレームを揃える（ずれると Validation Warning）
CamerasONカメラの位置・回転・画角（焦点距離）を持っていく
LightsOFFライトは Unity 側で作ります
Embed MediaOFFテクスチャは不要（見た目は Unity 側のモデル / マテリアルが正）
Include > Input ConnectionsOFFON だと選んでいないノード（コンストレイント先など）まで付いてきます
キャラ FBX のみ: Deformed Models / Skins / Blend ShapesOFF骨のアニメだけを出す（メッシュ・スキンはキャラ本体の FBX 側に既にあります）
Units / Up AxisAutomatic（cm）/ Y—

カメラのピント・絞りも持っていきたいとき（任意）

画角（焦点距離）は標準の書き出しで持っていけます。ピント距離・絞り（f 値）は FBX の標準属性で届くかを Unity 側で検証中です。届かない場合は、Maya のカメラにカスタムアトリビュート dd_focusDistance（ピント距離、cm）と dd_fStop（絞り）を追加してキーを打ってください（標準機能。アトリビュート追加 → キー）。どちらの経路になるかは Unity 側の実装時に決まり、このページを更新します。持っていかなくても、Unity 側でショットごとに手で入れられます。

Unity 側で確認する（機能実装後に有効）

  1. FBX をフォルダに置くと自動で取り込まれ、Asset Browser の「Cutscene」にショットが現れる
  2. Validation の「Run All」で次を確認する:
    • fps が違う（Warning）: 同じショットのファイル間で fps が違う。Maya のシーン fps を揃えて書き出し直す
    • モデルが見つからない（Warning）: ファイル名の識別子と D-Drive のモデル識別子が違う。ファイル名を直すか、Unity 側のバインド表で手で選ぶ
    • Avatar が未設定（Error、モデル側）: キャラ本体のモデルデータに人型（Humanoid）の Avatar が無い。モデル担当に依頼
  3. 確認用シーンで再生して、カメラとキャラの動きが Maya と同じか見る。効果音・エフェクト・画面揺れは Unity の Timeline ウィンドウで足す（演出と同じ ID を置くだけ）

直すとき

  • Maya で直して同じファイル名で上書き書き出し → Unity が再取り込みし、カメラ・キャラの動きだけ差し替わります。Unity 側で足した効果音・エフェクト・カメラの「コマ落ち（ステップ fps）」「ブレンド秒」などの設定はそのまま残ります
  • ファイル名を変えると別のショットとして扱われます（新しいカットシーンデータができる）
  • キャラが増えた / 減った: 増えたら FBX を 1 本足すだけ。減ったら FBX を消しても、Unity 側のトラックは消さずに「ミュート」になります（Unity 側で足した設定を消さないため）

よくある質問

質問答え
1 つの FBX に 2 つのショットを入れてしまったUnity 側でショットごとに「フレーム範囲」を指定して切り出せます（逃げ道）。ただし既定は「1 ショット = 1 FBX セット」なので、できれば分けてください
カメラの動きが「ぬるぬるし過ぎる」。24fps 風にしたいMaya で間引かないでください。Unity 側のカメラクリップに「ステップ fps」の項目があり、ショットごとに Unity 側でコマ落ちの度合いを変えられます（Maya をやり直さなくて済みます）
キャラ本体（メッシュ）も一緒に出してよい？出さないでください。キャラ本体は普段どおりモデルデータとして登録済みのものを使い、カットシーン FBX には骨の動きだけを入れます（同じキャラを何ショットでも使い回すため）
Generic（人型でない）キャラは？剣・扉などの小物は Generic で OK（カメラと同じ FBX に入れる）。キャラは人型（Humanoid）のみ対応です
