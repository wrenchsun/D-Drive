# 31. Phase 5 要判断一覧（ユーザー判断待ち）

> 2026-09-14 の Phase 5 自律実装（5-1〜5-16、レビュー対応 5-R、6-0 NGO 統合）の間に Claude が暫定既定で進めた事項を、
> [28_manual_verification_phase5.md](28_manual_verification_phase5.md) の各節末尾「要判断」、[30_phase5_review_2026-09-14.md](30_phase5_review_2026-09-14.md) の「要判断 / 整理項目」、
> [27_spec_sheet.md](27_spec_sheet.md) §7.1 の暫定既定、[29_network_device_test.md](29_network_device_test.md) の未決から、重複をまとめて一覧化したもの。
> **内容は出典の要約であり、この文書で新しい判断や推測は加えていない。** 出典間で言い回しが食い違う場合はその旨を注記した。
> 各出典で明示的に「→ 対応済み」「解消した」等と書かれているものはこの一覧から除外し、末尾の「対応済み（除外分）」に件数だけまとめた。

優先度の意味:

- **A. 早めに決めたい** — データ形式・シリアライズ・運用ルールに影響する（後から変えるほどコストが増える）
- **B. 使ってみて決める** — 見た目・操作感に関わる（実際に触ってから判断した方がよい）
- **C. 後回しでよい** — Phase 6 以降の課題、または発生頻度が低い/影響が小さいもの
