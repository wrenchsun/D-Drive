## 総評

- **依頼 7 件（DD-1 / 2 / 3 / 7 / 9 / 14 / 15）はすべて設計どおりに入っている**。Editor 専用・追加のみで、Runtime・ネット・公開 API（`DDrive.Foundation` / `DDrive.Runtime`）は触っていない。`CutsceneImportProfile` の欄 5 つは末尾追加で既定値のまま動き、`CutsceneImportProfile` は Compat の対象外（スナップショット無変更）。

- **E-17 (c) の改定は承認どおりの範囲**: 書くのは `CutsceneFbxPostprocessor.cs` / `AnimFbxPreprocessor.cs` の 2 ファイル・`importSettingsMissing`（初回）だけ。静的検査は `preserveHierarchy` を禁止リストから外す代わりに「許可ファイル以外で書いたら赤」の検査（`E17_PreserveHierarchyAndAnimatedProperties_AreWrittenOnlyByAllowedFiles`）を足しており、網は狭まっていない。`SourceAssets/Model/`（Toon の `SK_` モデル）の E-17 (a) テストは不変。
- **設計から変えた 2 点は妥当**: (1) TA-3 で `OnPostprocessGameObjectWithAnimatedUserProperties` の束縛を書き換えず診断ログだけにした（実素材無しで「書き換えが反映されるか」を確かめられない。読み取り側は型を見ないので、Unity が束縛を残しさえすれば動く）。(2) TA-5 の「トリム済みから切り出し」（`TrimClip` は全 float 束縛を写すので結果は同じ。`ddEvent` のカーブもトリムで消えない = TA-3 にも効く）。

- **実 FBX で確かめるまで「動く」と言えないもの**（[1017](../1017_tdrive_anim_requests.md) §5 のとおり）: `ddEvent` が Unity 6 の取り込みで束縛として残るか（残らなければ情報ログ + 従来どおり。設計どおりの縮退）、`EVT_` がカメラ + 小物 FBX の**ルート直下**に来るか（T-Drive は Maya で `tdShot_<Shot>` グループの下に置く。Export Selection で親が落ちればルート直下、落ちなければ `tdShot_*` が小物になる。5-3 に書き足した）。

## 2. 確認した「問題なし」

- **TA-1**: `StripModelFilePrefix` は `SK_` / `SM_`（大文字・`_` 必須）だけ。`Skeleton` / `sk_hero` は対象外（テストあり）。表示名は `rawName` のまま（統合テスト `ProcessPaths_Model_SkPrefix_IsStrippedFromIdentifier_ButNotFromDisplayName`）。既存の取り込み済み Data は `ImportSourceGuid` でスキップされるので名前・ID 定数は不変（生成コードの互換 [42](../42_distribution.md) §5.9）。`FindModelDataByIdentifier` は完全一致を優先し、無ければ `SK` / `SM` + 識別子（テストあり）。
- **TA-6**: `.json` / `.txt` / `.md` は `UnsupportedExtension` の手前で return。取り込み対象（`HandlersByFolder`）には元々入っていないので Data にはならない。`README.md` の既存の除外（`:273`）はそのまま。既存テストの `notes.txt` → `notes.xyz` の変更は妥当（`.txt` が付帯ファイルになったため）。
- **TA-4**: `Extract` が毎回カーブを作り直す（`target.PosX = posX ?? new …`）ので `ApplyCutSteps` を毎回かけてよい。`Quaternion.Angle` は符号の反転（q と −q）を角度 0 と見るので、FBX の四元数カーブの符号反転を誤検出しない。`hasPos` / `hasRot` は `Extract` が空カーブを入れる前提と整合。閾値 0 で無効（テストあり）。変更後の `CutsceneCameraClip` は `.playable` のサブアセットで、呼び元の `SetDirty(timeline)`（`:243`）で保存される。
- **TA-5**: `GetCurveBindings` は float カーブだけを返す（FBX にオブジェクト参照カーブは無い）。`/` 区切りで判定するので `PRP_Micro` は入らない（テストあり）。`frameRate` / `wrapMode` / `legacy` を写す。
- **TA-2**: `importSettingsMissing` は `OnPreprocess*` で使うための公式プロパティ。キャラ FBX（Humanoid）で `preserveHierarchy = true` は筋肉カーブに影響しない。`AnimFbxPreprocessor` は `.fbx` かつ `SourceAssets/Anim/` 配下だけ（`.anim` / Model フォルダは対象外、テストあり）。
- **TA-3**: `Events (FBX)` が無く今回もマーカーが無いときはトラックを作らない（テストあり）。`DeleteMarker` → `CreateMarker` の作り直しで重複しない（テストあり）。`FindRisingEdges` は先頭が 1 なら先頭フレーム（DD-9）、0 に戻って再び 1 で 2 件目（テストあり）。`clip` はトリム済みなのでキー時刻 = マーカー時刻。
