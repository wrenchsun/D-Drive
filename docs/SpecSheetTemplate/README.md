# D-Drive 仕様書テンプレート 記入ガイド(企画向け)

関連: [27_spec_sheet.md](../27_spec_sheet.md)(設計の詳細)

このフォルダの `DDrive_仕様書テンプレート.xlsx` を使うと、企画が書いた仕様から D-Drive(Unity 側のツール)が
必要なアセットの空データ・調整値を自動で作れるようになります(取り込み自体は次のチケット 5-13 で実装します。
このテンプレートはその「入力フォーマット」です)。

## 1. アップロード手順

1. `DDrive_仕様書テンプレート.xlsx` をダウンロードする(このリポジトリの `docs/SpecSheetTemplate/` にあります)
2. 自分の Google ドライブを開き、任意のフォルダに **ドラッグ&ドロップでアップロード**する
3. アップロードしたファイルを **右クリック → アプリで開く → Google スプレッドシート** を選ぶ
   - これで元の .xlsx から Google スプレッドシート形式のコピーが作られます(元の .xlsx ファイルはそのまま残ります。不要なら削除してよい)
4. 開いたスプレッドシートの名前を、機能名やプロジェクト名を含む分かりやすい名前に変更する(例:「〇〇プロジェクト 仕様書」)

## 2. 共有設定(必須)

D-Drive は URL だけでシートの内容を取得します(2026-09-14 時点の既定方針。§5 参照)。そのため、次の設定が**必須**です。

1. 右上の「共有」ボタンを押す
2. 「リンクを取得」→「制限付き」を **「リンクを知っている全員」** に変更する
3. 権限は **「閲覧者」** のままでよい(「編集者」にしない。誤って D-Drive 側や他の人が上書きするのを防ぐため)
4. 「コピーの完了」→ 表示された URL を控える
5. その URL を、D-Drive を担当しているプログラマーに渡す(`DDriveSpecSettings` に設定してもらう)

> 注意: 「リンクを知っている全員が閲覧可」は、URL を知っている人なら誰でも読めるという設定です。
> 社外に見せられない内容(未発表の契約条件など)を書く予定がある場合は、先にプログラマーに相談してください
> (docs/27_spec_sheet.md §7 の未決事項)。

## 3. 各タブの書き方

### README タブ
このガイドの要約が入っています。読むだけで、書き込みは不要です。

### 概要タブ
見出しだけの雛形です。見出しの右側(B列)に自由に書き込んでください。表・画像・改行、何でも使えます。

### 機能_サンプル タブ(→ コピーして増やす)
機能ごとの仕様を書くタブです。**このタブ自体は書き換えず、右クリック→「シートを複製」して**
`機能_<機能名>`(例: `機能_ショップ`)という名前に変えてから、複製したタブに書いてください。

書く内容(サンプルタブに実例が入っています):

- 1 行目: `■ <項目名>` の見出し + 状態(検討中/確定 等、自由記述でよい)・担当・更新日
- イメージ枠: 参考画像や図を貼る(スクリーンショットの貼り付け、Google Drive の画像リンクどちらでも可)
- 仕様要件: 箇条書きで挙動を書く。「〇〇したら△△する」の形式を推奨
- 関連アセット: **「アセット」タブに書いた識別子を列挙するだけ**。ここに音量や色などの値を直接書かない
  (「アセット」タブに無い識別子を書いても D-Drive は認識しません。先に「アセット」タブに行を追加してください)
- 調整値: **「調整値」タブに書いたキーを列挙するだけ**。ここにも値を直接書かない

### アセット タブ(ツールが読む・重要)

作ってほしいアセットを 1 行 1 件で列挙します。列の意味:

| 列 | 書くこと |
|---|---|
| 種別 | プルダウンから選ぶ(Se=効果音, Bgm=音楽, Vfx=エフェクト, Anim=3Dアニメ, Anim2D=2Dアニメ, Material=マテリアル, Texture=テクスチャ, Canvas=UI画面, Prefab=配置物, Presentation=演出まとめ, Shake=振動演出, Haptics=コントローラー振動, UiTween=UIの動き, Model=3Dモデル, Anchor=位置定義, AnchorGroup=位置セット, ControlSkin=UIパーツの見た目) |
| カテゴリ | `Player/Attack` のように `大分類/小分類` で書く(自由入力。後で D-Drive 側の分類と揃えます) |
| 識別子 | **英語の PascalCase** のみ(例: `Slash`, `HitSpark`)。日本語・記号・数字始まりは不可 |
| 表示名 | 日本語で OK(例: 剣の斬撃音) |
| 状態 | プルダウンから選ぶ(未着手 / 仮 / 本番 / 保留) |
| 担当 | 自由記述(空欄でもよい) |
| 仕様 | このアセットの詳細を書いた「機能_〇〇」タブのセルへのリンク(任意) |
| 備考 | 自由記述 |

**書いてはいけないこと**: 音量・色・長さ・座標などの細かいパラメータ。これらは D-Drive の専用エディタで
デザイナーが直接作ります。ここに書いても反映されず、シートとツールの内容が食い違う原因になります。

行頭が `#` の行(メモ)と、完全に空の行は無視されます。区切りやコメントに自由に使ってください。

### 調整値 タブ(ツールが読む・重要)

ゲームバランス等の「後から数値だけ変えたい値」を列挙します。

| 列 | 書くこと |
|---|---|
| キー | `<機能名>/<名前>` の書式(例: `Combat/HitStopSec`) |
| 値 | 初期値 |
| 型 | プルダウンから選ぶ(float / int / bool / string) |
| 最小 / 最大 | 数値型のときの範囲(任意) |
| 単位 | 秒・%・倍 など(任意) |
| 説明 | この値が何に効くか |

### _選択肢 タブ
非表示になっています。プルダウンの選択肢の元データなので、通常は触りません。
D-Drive 側の種別・状態が増えたときは、プログラマーから最新の一覧をもらって貼り直してください。

## 4. よくある間違い

- **「アセット」「調整値」タブに見出し行以外の結合セルを作ってしまう** → 読み取りがずれるので、結合を解除してください
- **識別子を日本語や `Player_Slash`(アンダースコア)で書いてしまう** → 英語 PascalCase(`PlayerSlash` のように単語をつなげる)に直してください
- **同じ種別+識別子の組を 2 行に書いてしまう**(コピペミス) → どちらか一方に統一してください
- **細かいパラメータ(音量・色・カーブ等)まで仕様書に書き込んでしまう** → 挙動・意図だけ書き、数値の中身は D-Drive の専用エディタに任せてください
- **共有設定を「リンクを知っている全員」にしないまま URL を渡してしまう** → D-Drive 側が読み取れません。§2 の手順を確認してください
- **「機能_サンプル」タブに直接書き込んでしまう** → 複製してタブ名を変えてから書いてください(サンプルは今後の参照用に残します)

## 5. 現状の制約(2026-09-14 時点)

- シートの内容は URL 経由で取得します。取り込み(5-13)が実装されるまでは、このシートは**書き方の合意**として使ってください
- D-Drive → シートへの書き込みは行いません(一方向)。シートから消した行があっても D-Drive 側の既存データは自動削除されません
- 詳しい設計は [docs/27_spec_sheet.md](../27_spec_sheet.md) を参照してください
