Model / Animation API

このページでは、モデル（見た目差し替え可能なキャラクター等）・汎用 Prefab・3D アニメーション・2D アニメーション・マテリアルの、5 つの静的ファサードをまとめて扱います。データの作り方は デザイナーマニュアル: Model Editor の使い方 / Anim Editor / Anim2D Editor / Material の設定項目 / Material Editor / Prefab の設定項目を参照してください。

未 Bind でも例外にならない: ここに載せたクラスはすべて、起動配線が済む前や未 Bind の状態で呼んでも、無効な Handle（または null / false / 0）を返す no-op として継続します。

Models（見た目差し替え可能なモデル）

実装: Assets/DDrive/Runtime/Model/Models.cs:9。ModelData は Prefab に加えて Slot/Avatar 等の「見た目差し替え」を持つ点が、下記の Prefabs（汎用 Prefab）と異なります。

static Handle<ModelMarker> Spawn(ModelId id, Vector3 pos, Quaternion rot) static Handle<ModelMarker> Spawn(ModelId id, Transform parent) static void Despawn(Handle<ModelMarker> h) static void SetMaterial(Handle<ModelMarker> h, int slotIndex, AssetId<MaterialMarker> materialId) static void SetLayer(Handle<ModelMarker> h, int layer) static GameObject GetGameObject(Handle<ModelMarker> h) static Handle<AnimMarker> PlayAnim(Handle<ModelMarker> h, AssetId<AnimMarker> animId) static Handle<AnimMarker> PlayAnim(Handle<ModelMarker> h, AssetId<AnimMarker> animId, float fade)
  • Spawn(id, pos, rot) / Spawn(id, parent) の 2 通り。SetMaterial はモデルの指定スロットのマテリアルを MaterialId で差し替える
  • PlayAnim は内部で AnimManager に委譲するため、下記の Anim と同じ再生系に乗ります。ModelsManager に AnimManager が接続されていない構成（テスト等）では no-op になります
  • fade 省略時（既定 -1f）は AnimData.DefaultCrossFade が使われます（下記 Anim の Play と同じ仕様）
var h = Models.Spawn(MODELID.Enemy01, spawnPoint.position, spawnPoint.rotation);
Models.SetMaterial(h, 0, MATID.EnemyDamaged);
Models.PlayAnim(h, ANIMID.Idle);

Prefabs（汎用 Prefab）

実装: Assets/DDrive/Runtime/Prefab/Prefabs.cs:9。見た目差し替えを持たない、種類・タグ・コリジョンレイヤーだけを管理する汎用 Prefab です（PrefabData、Assets/DDrive/Runtime/Prefab/PrefabData.cs:28）。

static Handle<PrefabMarker> Spawn(PrefabAssetId id, Vector3 pos, Quaternion rot) static Handle<PrefabMarker> Spawn(PrefabAssetId id, Transform parent) static void Despawn(Handle<PrefabMarker> h) static void Preload(params PrefabAssetId[] ids) static UniTask PreloadAsync(params PrefabAssetId[] ids) static GameObject GetGameObject(Handle<PrefabMarker> h) static bool HasTag(Handle<PrefabMarker> h, string tag) static void Move(Handle<PrefabMarker> h, Vector3 pos, Quaternion rot)

HasTag は PrefabData.GameplayTags（発注ツール等でタイポ検査される文字列タグ）との完全一致（大文字小文字を区別）を調べます。

ドット記法（PrefabHandleExtensions）

var h = Prefabs.Spawn(PREFABID.Barrel, pos, rot);
h.GetComponent<Rigidbody>().AddExplosionForce(500f, pos, 5f);
if (h.HasTag("Destructible")) { /* ... */ }
h.Move(newPos, newRot);
h.Despawn();

h.Go()（GetGameObject と同じ）、h.GetComponent<T>()、h.Move(pos, rot)、h.HasTag(tag)、h.Despawn()、h.IsValid()（GetGameObject(h) != null）が使えます。

Pool の挙動

PrefabData.Flags.Pool（AssetFlags.Pool、型 PoolPolicy）が Kind == PoolPolicyKind.Pooled のときだけ、この Prefab は使い回されます（既定の Kind == None は毎回 Instantiate/Destroy 相当の Discard 扱い）。

フィールド意味
KindNone（プールしない）/ Pooled（使い回す）
InitialCountPrewarm（Preload / PreloadAsync 実行時、または起動時のカタログ Preload 時）で事前に生成しておく数
MaxCount同時に存在できる上限。超過すると Pool が最も優先度の低いものを強制回収する
Preload は同期解決できる ID しか Prewarm できません。 Addressables のカタログ登録がまだ完了していない（lazy な）ID に対して Preload を呼ぶと、開発ビルドで警告ログが出て素通りします。確実に Prewarm したい場合は PreloadAsync（UniTask を返す非同期版）を使ってください。

Anim（3D アニメーション）

実装: Assets/DDrive/Runtime/Anim/Anim.cs:9。再生対象は Animator を渡す設計です（Controller 自体の状態遷移はゲーム側 / Animator Controller の責務のまま）。

static Handle<AnimMarker> Play(AnimId id, Animator target) static Handle<AnimMarker> Play(AnimId id, Animator target, float fade) static void Stop(Handle<AnimMarker> h, float fade = 0f) static bool IsPlaying(Handle<AnimMarker> h) static float NormalizedTime(Handle<AnimMarker> h) static void SetSpeed(Handle<AnimMarker> h, float speed) static void SetTrigger(Animator target, string param) static void SetLayerWeight(Animator target, int layer, float weight)
  • Play(id, target) は内部で fade = -1f として呼ばれ、AnimData.DefaultCrossFade（データ側の既定クロスフェード時間）を使います。Play(id, target, fade) で秒数を明示指定すればその回だけ上書きできます
  • NormalizedTime は Handle が無効（再生していない）なら -1 を返します（0〜1 の正規化時間ではなく「未再生」を表す番兵値）
  • SetTrigger は target が null、または param が空文字/null のとき no-op（Animator 自体の SetTrigger はここでは行われない）
  • SetLayerWeight は weight を Mathf.Clamp01 し、layer が target.layerCount の範囲外なら no-op
  • 同じ Animator の同じレイヤーで既に再生中のものがあれば、新しい Play によって自動的に中断（Interrupt）されます

ドット記法（AnimHandleExtensions）: h.IsPlaying() / h.Stop(fade) / h.SetSpeed(speed) / h.NormalizedTime()。

Anim2D（2D スプライトアニメーション）

実装: Assets/DDrive/Runtime/Anim2D/Anim2D.cs:12。再生実体は 3D と同じ AnimManager（Anim2DData は AnimData の派生）で、Handle も共通の Handle<AnimMarker> です。Anim2D 固有の機能は、方向 BlendTree のパラメータ設定です。

static void Bind(AnimManager anim, IAssetRegistry registry) static Handle<AnimMarker> Play(Anim2DId id, Animator target) static Handle<AnimMarker> Play(Anim2DId id, Animator target, Vector2 dir) static Handle<AnimMarker> PlayData(AnimData data, Animator target) static void SetDirection(Animator target, Vector2 dir, string paramX = "x", string paramY = "y") static void SetDirection(Animator target, Vector2 dir, int paramXHash, int paramYHash) static int ResolveFloatParameterHash(Animator target, string name) static void SetSpeed(Handle<AnimMarker> h, float speed) static void FreezeAtFirstFrame(Handle<AnimMarker> h) static void Unfreeze(Handle<AnimMarker> h, float speed = 1f) static void Stop(Handle<AnimMarker> h) static bool IsPlaying(Handle<AnimMarker> h)
  • Play(id, target, dir): dir は BlendTree の x, y（正規化不要。Vector2.zero なら方向を変えずに再生だけする）。Data が Anim2DData で HasDirections が true のときだけ方向が設定される
  • SetDirection（文字列版）は再生中でも方向だけ変えられる。毎フレーム呼ぶ経路では文字列版は使わないこと。 animator.parameters（配列 alloc）を毎回走査するため、定常経路（Tick 等）では ResolveFloatParameterHash で事前にハッシュを 1 回求め、ハッシュ版の SetDirection を使う
  • FreezeAtFirstFrame: 先頭フレームで止めて保持する（チャージ中の構えなど）。内部で Seek(h, 0f) + SetSpeed(h, 0f) を行う。Unfreeze（既定 speed = 1f）で速度を戻す
var hash = Anim2D.ResolveFloatParameterHash(animator, "x"); // 対象が決まった時に1回だけ
// ... Tick 内 ...
Anim2D.SetDirection(animator, moveDir, hash, hashY);

Mats（マテリアル）

実装: Assets/DDrive/Runtime/Material/Mats.cs:10。

static UnityEngine.Material Get(MaterialId id) static void Apply(Renderer r, int slot, MaterialId id) static int Replace(MaterialId from, MaterialId to) static Handle<MaterialMarker> FadeTo(Renderer r, MaterialId to, float sec) static Handle<MaterialMarker> FadeTo(Renderer r, int slot, MaterialId to, float sec) static void SetGlobalParam(string name, ParamValue v) static bool IsFading(Handle<MaterialMarker> h) static void Stop(Handle<MaterialMarker> h)
  • Get(id) は Data ごとに 1 つの共有インスタンスを返す（呼ぶたびに新規生成しない）
  • Apply(r, slot, id) は Renderer の指定スロットへそのまま差し替える
  • Replace(from, to) はシーン内を走査して from を使っている箇所を to に一括差し替えし、差し替えた Renderer スロット数を返す
  • FadeTo(r, to, sec) はスロット 0 に対する「溶け替え」の短縮形。スロットを指定したい場合は FadeTo(r, slot, to, sec)
  • SetGlobalParam はシェーダーのグローバルパラメータを設定する

ドット記法（MaterialHandleExtensions）: h.IsFading() / h.Stop()。
