Audio / BGM API

効果音（SE）は静的ファサード DDrive.Runtime.Audio.Audio、BGM も同じ Audio クラスにまとめられています（実体は AudioManager と BgmManager の 2 つで、Audio はその両方への薄い窓口です）。実装: Assets/DDrive/Runtime/Audio/Audio.cs:11。

データの作り方（音量・ピッチ・ループ点・フェード時間などパラメータの意味）は デザイナーマニュアル: SE の設定項目 / BGM の設定項目 / Audio Editor の使い方 / シーン内の音（環境音）を参照してください。このページはコードからどう呼ぶかだけを扱います。

未 Bind でも例外にならない: DDriveRuntimeBootstrap が起動する前（起動配線参照）に Audio.PlaySe(...) を呼んでも、内部の _seInstance / _bgmInstance が null のため何も鳴らさず、無効な Handle<SeMarker>（Handle<SeMarker>.Invalid）を返すだけで処理が継続します。

SE（効果音）

Bind / IsBound

static void Bind(AudioManager instance) static void Bind(BgmManager instance) static bool IsBound // SE 側・BGM 側の両方が Bind 済みのとき true

通常は DDriveRuntimeBootstrap が自動で Bind するため、ゲームコードから呼ぶことはありません。

PlaySe — 4 通りの呼び方

static Handle<SeMarker> PlaySe(SeId id) static Handle<SeMarker> PlaySe(SeId id, Vector3 pos) static Handle<SeMarker> PlaySe(SeId id, Transform contextRoot) static Handle<SeMarker> PlaySe(SeId id, AnchorId anchor) static Handle<SeMarker> PlaySe(SeId id, AnchorId anchor, Transform contextRoot)
オーバーロード用途
PlaySe(id)位置に依存しない SE（UI クリック音、非 3D 音など）を再生する
PlaySe(id, pos)ワールド座標 pos で 3D 再生する
PlaySe(id, contextRoot)contextRoot（発生源の Transform）に追従させて再生する。Anchor が Data 側に設定されていれば、その Anchor を contextRoot 基準で解決する
PlaySe(id, anchor) / PlaySe(id, anchor, contextRoot)再生する Anchor アセットをコード側から明示する
Audio.PlaySe(SEID.PlayerSlash);
Audio.PlaySe(SEID.PlayerSlash, transform.position);
Audio.PlaySe(SEID.FootStep, transform);
AnchorId オーバーロードは優先度が最も高い: PlaySe(id, anchor) / PlaySe(id, anchor, contextRoot) でコード側から渡した Anchor は、SeData に設定された AnchorId や埋め込み Anchor より優先して使われます（デザイナーマニュアル: Anchor参照）。データ側の既定 Anchor をコードから一時的に上書きしたいときに使います。

Stop

static void Stop(Handle<SeMarker> h, float fade = 0f)

fade は 0 なら即時停止、0 より大きい値なら、その秒数でフェードアウトしてから Pool に返却されます（再生中でない Handle には無害）。

BGM

PlayBgm

static void PlayBgm(BgmId id, float fadeIn = -1f)

fadeIn を省略（既定値 -1f）すると、BgmData 側に設定された FadeIn カーブがそのまま使われます。0 以上の値を渡すと、その秒数の線形フェードでその回だけ上書きします。すでに何か再生中の状態でこれを呼ぶと、内部的にクロスフェードで切り替わります。

Audio.PlayBgm(BGMID.TitleTheme);          // BgmData の FadeIn を使う
Audio.PlayBgm(BGMID.BattleTheme, 0.5f);   // 0.5 秒でフェードインしてこの回だけ上書き

StopBgm

static void StopBgm(float fadeOut = -1f)

fadeOut の意味は fadeIn と同じ考え方で、省略時（-1f）は現在再生中のトラックの BgmData.FadeOut を使います。

CrossFade

static void CrossFade(BgmId next, float duration)

次のトラック next へ、フェードイン・フェードアウトとも duration 秒で明示的に切り替えます（PlayBgm と違い、データ側の FadeIn/FadeOut は使わず必ず duration が優先されます）。

Intro（イントロ付き BGM）はクロスフェードでは使われません。 BgmData.Intro は「無音から再生を始める最初の 1 回」専用です。何か再生中の状態から PlayBgm / CrossFade で切り替えると、Intro を飛ばしてループ本体（LoopBody）から始まります（2 チャンネル構成のため、フェードアウト中の旧トラック・新トラックの Intro・新トラックの Loop の 3 系統を同時には扱えない設計上の制約です）。

Handle の扱い

PlaySe は再生インスタンスを指す Handle<SeMarker> を返します。BGM 側（PlayBgm / StopBgm / CrossFade）は内部で 2 チャンネルを使い回す設計のため、個別の Handle は返しません。Handle の一般的な扱い方（無効化・世代管理）は handle.html を参照してください。
