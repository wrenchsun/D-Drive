VFX API

エフェクトの生成・停止は静的ファサード DDrive.Runtime.Vfx.Vfx（実装: Assets/DDrive/Runtime/Vfx/Vfx.cs:11）から行います。画面の揺れは DDrive.Runtime.CameraShake.CameraFx、コントローラー振動は DDrive.Runtime.Haptics.Haptics が別クラスですが、設計・使い勝手はどちらも同じです。データの作り方は デザイナーマニュアル: VFX の設定項目 / VFX Editor の使い方 / 画面の揺れ・コントローラー振動の設定項目を参照してください。

未 Bind でも例外にならない: 起動配線が済む前に呼んでも、無効な Handle<VfxMarker>（Handle<VfxMarker>.Invalid）を返して no-op になります（Vfx / CameraFx / Haptics 共通）。

VFX（DDrive.Runtime.Vfx.Vfx）

Spawn — 5 通りの呼び方

static Handle<VfxMarker> Spawn(VfxId id) static Handle<VfxMarker> Spawn(VfxId id, Vector3 pos, Quaternion rot) static Handle<VfxMarker> Spawn(VfxId id, Transform attach) static Handle<VfxMarker> Spawn(VfxId id, AnchorId anchor) static Handle<VfxMarker> Spawn(VfxId id, AnchorId anchor, Transform attach)
オーバーロード用途
Spawn(id)原点付近に依存しないエフェクト（画面全体を覆う演出など）
Spawn(id, pos, rot)ワールド座標 pos / 回転 rot で生成する
Spawn(id, attach)attach の Transform に追従させて生成する（Data 側の Anchor があればそれを attach 基準で解決する）
Spawn(id, anchor) / Spawn(id, anchor, attach)生成する Anchor アセットをコード側から明示する。SE と同じく Data 側の Anchor より優先される
var h = Vfx.Spawn(VFXID.HitSpark, hitPoint, Quaternion.identity);
h.SetParam("MainColor", Color.red);

Stop と Kill の違い

static void Stop(Handle<VfxMarker> h) static void Kill(Handle<VfxMarker> h)
メソッド挙動
Stop放出（エミッション）を止めた上で、VfxData.FadeOutSec が 0 より大きい場合はその秒数だけ既存パーティクルの消失を待ってから Pool に返却する。残っているパーティクルが自然に消えるのを見せたいとき（通常の停止）はこちらを使う
Killフェードアウトを待たず即座に Pool へ返却する（残留パーティクルの消失を待たない）。シーン遷移や緊急停止など、見た目より確実な停止を優先したいときに使う

Preload

static void Preload(params VfxId[] ids)

指定した VFX の Prefab を事前に Pool へ用意しておきます（初回 Spawn 時のスパイクを避けたいときに使う）。

Handle 操作

static bool IsPlaying(Handle<VfxMarker> h) static void Move(Handle<VfxMarker> h, Vector3 position) static void Attach(Handle<VfxMarker> h, Transform target) static void Detach(Handle<VfxMarker> h) static void SetSpeed(Handle<VfxMarker> h, float speed) static void SetParam(Handle<VfxMarker> h, string label, ParamValue value) static void SetParam(Handle<VfxMarker> h, string label, float value) static void SetParam(Handle<VfxMarker> h, string label, Color value)

SetParam は VFX Graph の Exposed Property を、ラベル（表示名。VfxData 側で定義）で指定して書き換えます。float / Color の overload はそれぞれ ParamValue.Of(value) に変換してから同じ実装に委譲します。

ドット記法（VfxHandleExtensions）

Assets/DDrive/Runtime/Vfx/Vfx.cs:62-83 の VfxHandleExtensions により、Handle<VfxMarker> に対して h.Stop() のようにドットで書けます。中身は上記の Vfx.xxx(h, ...) への委譲です。

var h = Vfx.Spawn(VFXID.HitSpark, hitPoint, Quaternion.identity);
h.SetSpeed(1.5f);
h.Move(newPos);
h.Stop();          // Vfx.Stop(h) と同じ

画面の揺れ（DDrive.Runtime.CameraShake.CameraFx）

実装: Assets/DDrive/Runtime/Camera/CameraFx.cs:9。

static Handle<ShakeMarker> Shake(ShakeId id) static Handle<ShakeMarker> Shake(ShakeId id, Vector3 sourcePos) static Handle<ShakeMarker> Shake(ShakeId id, float strengthScale) static void Stop(Handle<ShakeMarker> h, float fade = 0.1f) static void SetStrength(Handle<ShakeMarker> h, float strength) static bool IsPlaying(Handle<ShakeMarker> h) static void StopAll(float fadeOut = 0.1f) static void SetGlobalScale(float scale)
オーバーロード / メンバー用途
Shake(id, sourcePos)発生位置 sourcePos から「奥から手前に押される」方向のシェイクを計算する（爆発の発生源など）
Shake(id, strengthScale)距離減衰など外部要因で強さを一律スケールしたいときの係数
SetGlobalScale(scale)オプション画面の「画面揺れ 0〜100%」に対応する全体スケール。0 にすると完全に無揺れになる（アクセシビリティ要件）

Handle<ShakeMarker> にも h.Stop(fade) / h.SetStrength(strength) / h.IsPlaying() のドット記法（ShakeHandleExtensions）があります。

コントローラー振動（DDrive.Runtime.Haptics.Haptics）

実装: Assets/DDrive/Runtime/Haptics/Haptics.cs:8。

static Handle<HapticMarker> Play(HapticId id) static Handle<HapticMarker> Play(HapticId id, float strengthScale) static void Stop(Handle<HapticMarker> h) static bool IsPlaying(Handle<HapticMarker> h) static void StopAll() static void SetGlobalScale(float scale)

SetGlobalScale はオプション画面の「振動 0〜100% / OFF」に対応します。Handle<HapticMarker> にも h.Stop() / h.IsPlaying() のドット記法（HapticHandleExtensions）があります。

アプリ終了・フォーカス喪失時は自動でモーターが 0 に戻ります（DDriveRuntimeBootstrap.OnApplicationQuit / OnApplicationFocus）。ゲームコード側で明示的に Haptics.StopAll() を呼ぶ必要は通常ありません。
