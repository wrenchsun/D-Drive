## 2. GitHub リリースノートの下書き（v1.10.0）

```
## D-Drive v1.10.0 — 外部拡張（プラグイン）基盤

MINOR・追加のみ（`AssetType` の末尾に `Extension`、`CatalogEntry.KindKey`、公開 API と Editor 契約の追加。既存の種別・データ・API の挙動は変更なし）。

持ち込み先が D-Drive の更新を待たずに、新しい種別（Data + Manager + ファサード + Validator + 専用エディター + サンプル + 確認用シーン + マニュアル）を自分のアセンブリだけで作れるようにしました。

- 種別の外部定義: `AssetType.Extension` + `[AssetIdDefinition(..., KindKey = "...")]` + `IAssetKindProvider`（接頭辞 / フォルダ / カタログ名 / 既定 Load）。AssetBrowser・＋ 新規作成・命名・ID 生成（`XXXID.Name`）・Validation の集計・MCP（`ddrive_asset_*` の `type`、`ddrive_validate` の `scope=type:<KindKey>`）が種別キーを受けます。
- 起動配線の口: `IDDriveModule`（`CreateManagers` / `Bind` / `Unbind`、Order 順、例外で止めない）+ `DDriveBootstrapContext`。`DDriveRuntimeBootstrap` が組み込みの後に呼びます。
- 専用エディター基盤の公開: `UxEditorWindow<T>` / `FieldGuide` / `UxCard` / `UxRow` / `TuneKnobs` / `DurationBar` / `AnchorPad` / `DataSwitcher` / `UxTheme` などが public に。確認用シーンの再生基底 `UxPreviewDriverBase` と、Edit Mode で module の Manager を動かす `EditorModuleHost`。
- サンプル・確認用シーン・マニュアルの口: `ISampleProvider` / `IPreviewSceneProvider` / `IManualPageProvider`。
- 雛形 `Samples~/ExtensionTemplate`（Package Manager の Samples「Extension Template」からも取り出せます）: コピーして名前を付け替えれば動く最小のプラグイン 1 式 + README（昇格の手順つき）。手順書は ProgrammerManual の extending、持ち込み先向けは consumer guide の extend。
- 外部拡張の契約 E-25〜E-29 をテストで固定。
詳細: CHANGELOG 1.10.0、docs/1014。
```
