## 2. GitHub リリースノートの下書き（v1.6.0）

```
## D-Drive v1.6.0 — isuzu MCP の導入を更新ウィンドウに統合

MINOR・追加のみ（データ形式・公開 API・ネットメッセージに変更なし）。

- 更新ウィンドウ（Tools > D-Drive > Update）の「パッケージ」に「Unity MCP（isuzu）」の行を追加。
  未導入なら「導入」ボタンで jp.shiranui-isuzu.unity-mcp を推奨版 v4.4.2 のタグ固定で manifest に追加。
  導入後の案内（解決待ち・登録スクリプトの実行・書き込みツールの設定）も同じ画面に表示。
  セットアップウィザードにも「AI 連携（MCP、任意）」を追加（既定 OFF）。
- 他の MCP（CoplayDev 版など）が入っているときは導入前に確認（両方残す / 外して続行 / キャンセル）。
- Validation（Info）: DD-MCP-MULTIPLE（MCP が 2 つ以上）/ DD-MCP-ISUZU-OUTDATED（isuzu が推奨より古い）。
  ddrive_status.mcp に otherMcp / isuzuVersion を追加。
- 推奨 isuzu を v4.4.2 に更新。MCP の max_chars の上限を 16000 に（isuzu v4.3.0 以降の返り値サイズ上限に合わせた）。
- 修正: ddrive_asset_create の preview が返すパスを実作成と同じ大小文字にそろえた。
詳細: CHANGELOG 1.6.0、docs/1002 §11。
```
