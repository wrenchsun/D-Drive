## 2. GitHub リリースノートの下書き（v1.8.0）

```
## D-Drive v1.8.0 — 専用エディターの新デザイン

MINOR・追加のみ（公開 API・シリアライズ形式・ネットメッセージは追加のみ。Editor の契約に 3 点の変更あり、下記）。

- 全種別の専用エディターを新デザインにした（VFX / SE・BGM / Canvas / Presentation / Anim / Anim2D / Material・Texture /
  Model / Prefab / Shake・Haptics / Anchor / Anchor Group / UI Tween / Button Skin / Slider Skin・Slider / Tuning）。
  - 共通基盤 `UxEditorWindow`: やりたいことごとの「目的別カード」、かんたん / 標準 / 詳細の 3 モード、設定の検索、
    未調整の欄の折りたたみ、固定バー（▶ ■ 保存）、調整つまみ、Data の切り替え、自動保存。一覧は 1 件 = 1 行で絞り込みと件数つき。
  - Tuning の自動保存は既定 ON（他のエディターは OFF）。
- 旧エディターは `Tools > D-Drive > Archive` に残した（ウィンドウ題は「(旧) 〜」）。Inspector の「エディターで開く」は
  新エディターが主ボタン、旧エディターは折りたたみ「旧エディター」に入れた。
- 空状態に「サンプルを作る」（Anim2D を除く全種別。Assets/GameData/<種別>/Sample/ に作る）。
- 修正（C-1）: 全画面・解像度の変更で HUD が追従しない不具合。UiManager のレイヤールートに CanvasScaler を付けた。
  Prefab に CanvasScaler があればその設定を写し、無ければ 1920x1080 / Match 0.5（Project Settings > D-Drive > Canvas）。
- 互換性: 公開 API は追加のみ（ValidationResult.Field / WithField、UiCanvasScalerDefaults 等）。Editor 契約の変更は
  「DDriveMenu.Archive の追加」「[DataEditor] 対応表の追加（旧の行はラベル・Order が変わる）」「Editors/ のメニューが新エディターを指す」の 3 点。
詳細: CHANGELOG 1.8.0、docs/1010。
```

## 3. 持ち込み先（MS2026）へ渡す文面

```
D-Drive v1.8.0 を出しました（MINOR・追加のみ）。専用エディターが全種別で新デザインになりました。

更新: Tools > D-Drive > Update > 更新ウィンドウ で #v1.8.0 を適用してください。

変わること / お願い:
- Tools > D-Drive > Editors のメニューは新エディターを開きます。旧エディターは Tools > D-Drive > Archive にあります
  （Inspector の「旧エディター」折りたたみからも開けます）。使い方はデザイナーマニュアルの各エディターのページを更新済みです。
- 全画面・解像度変更で HUD が追従しない不具合を直しました（docs/1001 の C-1 の行）。実機で全画面にして確認してください。
- Tuning ウィンドウの自動保存が既定 ON になりました（値を変えるとすぐ保存されます）。
- 注意: CanvasScaler を持たない Prefab は、既定の 1920x1080 / Match 0.5 で拡縮されるようになりました（従来は等倍）。
  変えたいときは Project Settings > D-Drive > Canvas の既定、または Prefab に CanvasScaler を付けてください。
- データ形式・ネットメッセージ・公開 API に破壊的な変更はありません。
```
