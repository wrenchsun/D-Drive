## 2. GitHub リリースノートの下書き（v1.12.1）

```
## D-Drive v1.12.1 — 開いた画面が左下に小さく寄る不具合の修正

PATCH・破壊なし（公開 API・データ形式の変更なし）。

- 起動時のウィンドウが Canvas の基準解像度（1920x1080 など）と違うと、`Ui.Open` で開いた画面が左下に小さく寄って表示されていた（960x540 なら 1/4）のを直しました。Canvas を持つ画面の Prefab のルートは、開くときに常に「親全面・倍率 1・余白 0」になり、開閉の演出もこの値を基準にします。`Ui.OpenInto` も同じです。
- Canvas を持たないルートの配置は Prefab のままです。
- 意図した変化: Prefab のルート（Canvas がある所）に独自の位置・倍率を付けていた画面は、その値が開くときに上書きされます。子の RectTransform で付けてください。
詳細: CHANGELOG 1.12.1。
```
