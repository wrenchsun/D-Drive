## 2. GitHub リリースノートの下書き（v1.11.0）

```
## D-Drive v1.11.0 — Maya（T-Drive アニメーション作業台）からの取り込み対応

MINOR・追加のみ（Editor 専用の取り込み経路。ランタイム・ネット・データ形式・公開 API の変更なし。`CutsceneImportProfile` に設定 5 欄を追加）。

T-Drive のアニメーション作業台が出す `SK_<ModelId>.fbx` / `<Shot>__<ModelId>.fbx` / `EVT_` ロケーターを、D-Drive の取り込みがそのまま受けられるようにしました。

- Model の取り込み: ファイル名の `SK_` / `SM_` を識別子から外す（`SK_Hero.fbx` → `MODEL_<cat>_Hero`、表示名は `SK_Hero`）。カットシーンの `<Shot>__Hero.fbx` が自動でこのモデルに結び付く。`SK` 付きで取り込み済みの旧データも見つける。
- Cutscene の取り込み: `EVT_<キー>` ロケーターを小物にせず、カスタムアトリビュート `ddEvent` が 1 になったフレームを Signal トラック `Events (FBX)` のマーカー `cutscene/<キー>` にする（再取り込みで作り直し。手で置くマーカーは別トラックに）。Ubercam のカメラの切り替わり（位置 1 m / 回転 60° 超の飛び）を自動でステップにする。小物のトラックにはそのノード以下のカーブだけを道筋を付け替えて渡す。
- FBX の初回取り込み設定: `SourceAssets/Cutscene/` と `SourceAssets/Anim/` の FBX は初回だけ `Preserve Hierarchy` ON（カメラ + 小物 FBX は `Animated Custom Properties` も）。2 回目以降は Inspector の値を上書きしない。契約 E-17 (c) にこの 2 プロパティを明記。
- `.json` / `.txt` / `.md` の付帯ファイルを `SourceAssets/` に置いても案内ログを出さない。
- 未検証: `ddEvent` が Unity 6 の FBX 取り込みで束縛として届くかは実 Maya 素材での確認待ち（届かなければ情報ログを出して従来どおり）。
詳細: CHANGELOG 1.11.0、docs/1017。
```
