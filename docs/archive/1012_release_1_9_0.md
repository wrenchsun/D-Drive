## 2. GitHub リリースノートの下書き（v1.9.0）

```
## D-Drive v1.9.0 — Canvas を RenderTexture に描く / Cutscene を指定カメラで再生

MINOR・追加のみ（公開 API の追加だけ。シリアライズ形式・enum・ネットメッセージ・Editor の契約は変更なし）。MS2026 の街のディスプレイ（LED 平面・3D パネル）向け。

- `Ui.OpenInto(id, renderTexture, size)` / `OpenDataInto` / `OpenIntoAsync`: UI スタックの外で、Canvas を RenderTexture に描いて開く。
  専用の正射影カメラ + ScreenSpaceCamera の Canvas を遠方（Y = -10000 - 100n）に置いて隔離する。ElementFx（出現 / 常時 / 消滅）・SE・
  Open/Close の遷移・埋め込み Canvas・Signal は通常の Open と同じ。スタック / modal / 入力 / PauseGameWhileOpen の対象外。
  `Ui.PlayDisappear(handle)` / `PlayDisappearAsync` で消滅だけ先に再生できる（閉じない。あとで Close しても二重に鳴らない）。
- `Cutscene.Play / PlayData(id or data, ctx, CutscenePlayOptions)`: `Camera.main` 以外のカメラ（RT を持つスタジオカメラ）で Cutscene を流す。
  `CutscenePlayOptions(camera, ignoreInputLock)`。カメラの所有は「カメラごと」（別カメラなら同時再生できる）、G-5 の判定と MainCamera バインドも
  指定カメラで行う。options はローカル専用でネットには送らない。`PlayContext` は変更なし。
詳細: CHANGELOG 1.9.0、docs/07 A-3（2026-10-15）、docs/26 §4.6.6。
```

```
D-Drive v1.9.0 を出しました（MINOR・追加のみ）。街のディスプレイ向けに依頼のあった API 2 件です（Docs/Spec/09_CityDisplayAuthoring.md §8 の D-1 / D-2）。

更新: Tools > D-Drive > Update > 更新ウィンドウ で #v1.9.0 を適用してください。

使い方 / 置き換え先:
- D-1: `Ui.OpenInto(CANVASID.xxx, rt, Vector2Int.zero)` で、UI スタックの外で Canvas を RT に描いて開けます（size は RT の中で描く画素の大きさ。
  zero なら RT 全面。ページの基準解像度は Prefab の CanvasScaler から写すので、1920x1080 で作ったページが 1024x512 の RT に収まります）。
  ElementFx・SE・埋め込みは通常の Open と同じ。`Ui.PlayDisappear(handle)` で消滅だけ先に出せます。終わったら `Ui.Close(handle)`。
  → CityDisplayRegistry.Canvas.cs の回避策（Prefab 直接 Instantiate・ElementFx なし）を置き換えてください。
  注意: 隔離は Layer ではなく遠方配置（Y = -10000 以下）です。far clip が大きい遠景カメラがそこまで届く場合は避けてください。
- D-2: `Cutscene.PlayData(data, ctx, new CutscenePlayOptions(camera: studioCamera, ignoreInputLock: true))` で、スタジオの専用カメラ

  → CityVisionStudio.Event.cs の PlayableDirector 直接再生を置き換えてください。ネットには送られません（ローカル再生）。
- 回避策を消したら、Docs/Notes の type: landmine の行も消してください。

```
