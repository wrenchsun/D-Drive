## 2. GitHub リリースノートの下書き（v1.12.0）

```
## D-Drive v1.12.0 — 専用エディター土台の軽量化

MINOR・追加のみ（Editor 専用。ランタイム・ネット・データ形式の変更なし。公開 API は `UxEditorWindow<TData>.TickIntervalMs`（protected virtual）の追加だけ）。

`UxEditorWindow` 派生の全エディター（D-Drive の各種別と、持ち込み先が `Editor/Ux` で作ったエディター）が軽くなります。行が多い種別（MS2026 の Floor Fx Editor 3 層 219 行など）で効きます。

- 変化の無い 150 ms ごとの更新は、全行の状態更新・描き直しを飛ばす（Data の dirty 数・表示モード・検索・絞り込みが前回と同じとき。7 回に 1 回は必ず通す）。
- 窓の表示・タブ切替・フォーカス移動で UI Toolkit の結びつけが出す「値が変わっていない」変更通知を捨てる（`OnPropertyEdited` / 検証 / 全行の更新を走らせない）。種別側がこの通知で再生やプレビューを起動し直していた場合、それが止まります。
- 0.3 秒以内に続く編集（ドラッグ・タイプ）は、検証 + 全行の更新を最後の編集から 200 ms 後の 1 回にまとめる（`OnPropertyEdited` は毎回届く）。
- `TickIntervalMs` で定期更新の間隔を種別から変えられる（既定 150、50 未満は 50）。
- 意図した挙動の変化: 同じ値の再入力は「編集」として扱われなくなった（`ApplyModifiedProperties` が dirty を進めないため）。
詳細: CHANGELOG 1.12.0、docs/1020。
```
