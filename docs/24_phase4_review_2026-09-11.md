## P1 — 通常使用で誤動作 / リーク

1. **プール再利用した Canvas が閉じ遷移の終端状態のまま再表示される** — `Runtime/Canvas/UiManager.cs:320-321` が生きている Transform から `BaseAnchoredPosition` / `BaseScale` を取り、`ApplyTransitionFrame`（456-485）は Close 完了後に `localScale=0`（Scale）/ `alpha=0`（Fade）/ `pos=Base+SlideOffset`（Slide）を残す。`PoolService.Return/Rent` は何も戻さず Canvas は `IPoolable` を実装していない。CloseTransition=Scale → 次の Open で `BaseScale=0` を取り込み、以降ずっと不可視。修正: `OpenData` で基準値を取る前に中立状態へ戻す（alpha=1 / scale=1 / 初回レンタル時に記録した位置）か、`IPoolable.OnReturn` で戻す。
2. **`UiSlider` のパッドリピートが EventSystem 経由だと止まらない** — `UiSlider.cs:784`（`OnMove` → `Move`）が `_padActive=true` にするが、`MoveRelease()`（320）のランタイム呼び出しが無い（テストのみ）。1 回押すと `TickPadRepeat`（469-491）が永久に `StepPad` を呼び続け、端まで動いて `OnCommit` / `SetOption` を出し続ける。修正: `Move` で `Time.frameCount` を記録し、`Advance` で「前フレームに `OnMove` が来ていない」なら解放。
3. **対称 PingPong プリセットが静止位置でなく端で止まる** — `UiPresetFactory.cs:280,284`（Shake / ShakeHard: From=cur-dist, To=cur+dist, PingPong, loopCount 6/10）。`ValueDef.ResolvePingPongT`（92-96）は偶数周で 0 に戻るため最終値が `From=cur-8px`（ShakeHard は -16px）。412（Tada の回転、loopCount 4）も -6° で止まる。修正: 終端が静止位置になる From/To とループ数にするか、cur へ戻す settle トラックを追加。
4. **`OptionStore` は Load されるが Save されない** — `DDriveRuntimeBootstrap.cs:162` で Load のみ。`OptionStore.Save` の呼び出しはテストにしか無く、設定画面の値は終了で消える。修正: `OnDestroy` / `OnApplicationQuit` で Save（+ `OnChanged` でのスロットル保存）。
5. **`UiInteractable` がプール再利用をまたいでポインタ / フォーカス / 状態を持ち越す** — `UiInteractable.cs:48-53,66` の `_pointerDown / _pointerOver / _focused / State / _cooldownRemaining / _stateTween` がリセットされず、`OnDisable` も `IPoolable` も無い。ポインタを乗せたまま Canvas を閉じると、再利用時に `State==Hover` で戻り `OnEnable`（109）が Hover スキンを再適用、`OnPointerExit` は来ないので固定。修正: `OnDisable` でこれらをリセット（UiButton は `_isHeld` 等も）。
6. **プリセットギャラリーの「選択中のシーン要素で再生」がユーザーのオブジェクトを Undo 無しで書き換える** — `UiPresetGalleryWindow.cs:440-470` は `Selection.activeTransform` に直接再生、スナップショット・復元無し、`StopPreview`（472-480）は `complete` 無しで途中停止。`*Out` / Fade 系で alpha 0 / scale 0 / 画面外のまま残り、`UiTweenManager.ResolveComponents`（510-517）が `CanvasGroup` を追加する（Undo 無しの構造変更）。修正: 再生前に位置 / スケール / 回転 / alpha（CanvasGroup の有無）をスナップショットして停止時に復元、または DontSave のプレビュー複製に対してだけ再生。

## P2 — エッジケース / 規約違反 / パフォーマンス

7. `UiTweenManager.Stop(handle, complete:true)`（330-336）が破棄済みターゲットを参照する（`ApplyTrack` が `inst.Target.anchoredPosition` を読む）。`UiManager.StopAllElementFx`（1417,1419）が `complete:true` を使い、`OnSceneUnload` で UI が破棄済みのとき `MissingReferenceException`。修正: `if (complete && inst.Target != null)`。
8. `UiFx.cs:38` と `UiManager.cs:1435` が Play 経路で毎回 `new TweenTrack[8]`（1 要素 ≈ 1KB）。[12] §3 違反。修正: `static readonly TweenTrack[] Scratch`（`PlayTracks` は即座に `OwnedTracks` へコピーするので再利用可）。
9. `UiTweenEditorWindow.cs:141` が `CreateGUI` で `EditorApplication.update` を購読し、解除は `OnDestroy`（144-146）のみ。ドメインリロードごとに多重購読され N 倍速に。修正: `OnEnable` / `OnDisable` へ。
10. `UiManager.CloseAsync`（373-382, 527-537）: `CloseTransition.Kind==None` のとき `TransitionState` が無く即 return するが、`TryFinalizeClose` は `PendingDisappearCount>0` で待つため、await 後も消滅 FX が走っている。修正: `CanvasInstance` に close 完了の `UniTaskCompletionSource` を持たせ `FinalizeClose` で解決。
11. ギャラリーのカードが IMGUI の再描画ごとに GameObject を生成・破棄（`UiPresetGalleryWindow.cs:285, 313-324`）。修正: カード生成時に一度サンプリングしてキャッシュ。
12. `UiSlider.SignFor`（505-518）が `Direction`（RightToLeft / TopToBottom）を無視。ポインタ（795-805）は Direction を見るのでパッドと食い違う。修正: 反転方向では符号を反転（値の意味: 右 / 上キーは常に値を増やす、ハンドルの動きは Direction に従う）。
13. `CanvasEditorWindow.cs:816-820` の Validation「修正」が `Undo.RecordObject` 無しで Data を書く。
14. `UiTweenManager.PlayTracks(tracks, count, target)`（147-148）が `count` を `tracks.Length` でクランプせず `Array.Copy` が例外になり得る。
15. `SliderEditorWindow.cs:697-703` が対象フィールドの実シーン Slider にも `Advance()` を呼び、`UpdateVisuals` がシーンの anchors を Undo 無しで書き換える。修正: DontSave のプレビュー配下だけ駆動する。

## 整理項目（バグではない）

1. `UiFx.Play`（29-51）と `UiManager.PlayPreset`（1428-1448）が同じ「プリセット展開 → 再生」の重複。`UiTweenManager` 側の共通ヘルパーへ。
2. `UiManager.MoveFocusFrom`（773-848）は呼び出しごとにイテレータ・`GetComponentsInChildren` 配列 ×2・`new Vector3[4]` を割り当てる（現状はエディタのシミュレーション専用だが公開ランタイム API）。
3. `Options.OnChanged`（`OptionStore.cs:187-191`）は `_instance==null` のとき購読を黙って捨てる。
4. `TweenSequence.Append`（`UiFx.cs:176-180`）は開始済み Handle を受けるため、実際には同時再生して待ち合わせだけ順番になる（名前と挙動が不一致）。
5. `UiSlider.TickFollow`（450-464）は毎フレーム `UpdateVisuals` → `InverseResponse`（16 回の二分探索）。表示値が変わらないときはスキップする。
6. `GetRelativePath` が `UiManager.cs:933-950` と `CanvasEditorWindow.cs:700-715` で重複。`UiTweenManager.PlaceholderWarned`（63）が static の `HashSet<UiTweenData>` で ScriptableObject を保持し続ける（UiManager 側はインスタンス単位）。

**対応(2026-09-14)**: 1〜6 すべて対応済み。
1. `UiTweenManager.PlayPreset(in UiPresetRef, RectTransform)` に集約し、`UiFx.Play` と `UiManager.PlayPreset` はそれを呼ぶだけにした(スクラッチも 1 つに)。
2. `MoveFocusFrom` は候補集めに使い回しの `List` を使い(`GetComponentsInChildren(true, list)`)、角の取得も共有バッファにした(イテレータ・配列の割り当て無し)。
3. `Options` は未 Bind の購読も覚えておき、`Bind` のたびに今のインスタンスへ付け替える。
4. `TweenSequence` に Func 版 `Append(() => …)` / `Join(() => …)` を追加(区間が来たときに再生を始める = 本当の順番再生)。Handle 版は「完了の待ち合わせだけ順番」と明記([15] B-5)。
5. `UiSlider.TickFollow` は表示値・向き・つなぐ部品が前回と同じなら描き直さない。
6. 相対パス計算は `TransformPath.GetRelative`(Runtime/Canvas)に集約(実際には 7 か所に重複していた)。`PlaceholderWarned` はインスタンス単位に。
