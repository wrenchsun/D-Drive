Canvas(UI 画面)データの設定項目

最終更新日: 2026-09-17

Canvas データ(CanvasData)は「UI の 1 画面」を 1 個のデータにまとめたものです。タイトル画面・ポーズメニュー・確認ダイアログ・音量設定など、画面 1 枚につき 1 個作ります。1 枚の Canvas データで次のことが全部決まります。

  • どの Canvas Prefab を開くか(Prefab)
  • どの表示レイヤーに、どの重ね順で出すか(Layer / SortOffset)
  • 開く / 閉じるときの演出(OpenTransition / CloseTransition)
  • 「戻る」で閉じるか、背後の操作を止めるか、開いている間ゲームを止めるか(CloseOnBack / ModalBlocksInput / PauseGameWhileOpen)
  • 十字キー / スティックでフォーカスがどう移るか、最初にどこにフォーカスするか(Navigation / FirstSelected)
  • ボタンやスライダーを操作したら何が起きるか(Buttons / Sliders)
  • 要素ごとの出現 / 常時 / 消滅の演出(ElementEffects)
プログラマーは Ui.Open(CANVASID.Title) の 1 行で画面を開きます(ダイアログは Ui.Popup(...)、戻るは Ui.CloseTop())。「設定画面 → サウンド設定」のような画面どうしの行き来は、ボタンの配線(Buttons)だけでデザイナーが組めます。コードに知らせたい操作(購入など)だけ SendSignal で通知します。

作り方

Assets/GameData/Canvas フォルダはまだ空で、標準の UI Prefab もありません。最初の 1 枚は自分で作ります。

1. Canvas Prefab を作る(最小構成)

  1. ルートは RectTransform を持つオブジェクト(Canvas コンポーネントは無くても構いません。あれば重ね順に SortOffset が加算されます)
  2. ボタンはどちらか: uGUI の Button(Unity 標準)、または D-Drive の UiButton(Image を付けたオブジェクトに UiButton を追加し、TargetGraphic にその Image を入れる。色・音・演出を Skin でまとめて当てられます → Button Skin)
  3. スライダーは D-Drive の UiSlider(Image + UiSlider。Fill / Handle を子に置いて FillRect / HandleRect に入れる)
  4. Prefab として保存する。要素の名前が「相対パス」(例: Panel/StartButton)として配線に使われるので、分かりやすい名前に

2. Canvas データを作る

  1. Asset Browser の「新規」→ 種別 Canvas (CanvasData)、表示名・識別子を入れて「作成」(生成先 Assets/GameData/Canvas/カテゴリ/、ファイル名 CANVAS_…)。.prefab を Asset Browser にドラッグしても作れません
  2. Inspector の「Canvas Editor で開く」→ Prefab に 1 で作った Prefab を入れる。以降の配線は Canvas Editor で

3. UiLayerSettings(レイヤーごとの既定)を作って割り当てる

  1. Project で右クリック → Create > D-Drive > Ui > Ui Layer Settings(ファイル名 UI_LayerSettings)。プロジェクトに 1 個で十分。Asset Browser には出ません
  2. 起動用オブジェクトの DDriveRuntimeBootstrap の LayerSettings 欄に Inspector で直接入れる(未設定でも動きますが、レイヤー既定の Skin・SE・演出は効きません)
このプロジェクトの入力は Input System パッケージです。シーンの EventSystem には InputSystemUIInputModule が必要です。EventSystem 自体が無いと Play 中に「シーンに EventSystem がありません。UI の入力(選択/ナビゲーション)が動作しません。」と警告が出て、ボタンもフォーカスも動きません。

設定項目

項目説明
Prefab開く実体。未設定でも <Placeholder:CANVAS> という空の RectTransform で開き、1 回だけ警告が出ます
Layer表示レイヤー。手前から Loading(ロード画面)/ Overlay(最前面の演出)/ Popup(確認ダイアログ)/ Menu(メニュー画面)/ HUD(体力・ミニマップなど常時表示)。並び順がそのまま前後関係です
SortOffset同じレイヤー内での重ね順の微調整。Prefab に Canvas コンポーネントがあれば sortingOrder に加算、無ければ兄弟の並び順に使われます
OpenTransition / CloseTransition画面全体の開閉演出。Kind: None(即時)/ Fade(透明度)/ Slide(位置)/ Scale(拡縮)/ Anim(AnimData を再生)。Duration(秒)、Ease(動きの緩急)、SlideOffset(Slide の開始位置のずれ)、Anim(Kind=Anim のときだけ)
CloseOnBack(既定 ON)「戻る」操作(CloseTop)で閉じる対象に含めるか。HUD のように戻るで消えてほしくない画面は OFF
ModalBlocksInputモーダル(= この画面を閉じるまで後ろの画面を触らせない)として開いたとき、背後の入力を止めるか。効くのは Ui.Popup で開いたときだけ。Ui.Open で開くとモーダルになりません
PauseGameWhileOpen開いている間ゲームを一時停止するか(ポーズメニュー用)
Navigation十字キー / スティックでのフォーカス移動の配線。1 行 = Element(対象の相対パス)+ Up / Down / Left / Right(各方向の移動先パス)。4 方向とも空なら Unity の自動ナビゲーションのまま。1 方向でも入れると明示扱いになり、空の方向は「行き先なし」になります。普段は Canvas Editor のグラフで編集します
FirstSelected開いたときに最初にフォーカスする要素の相対パス。パッド操作の画面では必ず決めてください
Buttonsボタンの配線(下記「Buttons(ButtonWire)」)
Slidersスライダーの配線(下記「Sliders(SliderWire)」)
ElementEffects要素ごとの演出(下記「ElementEffects」)

Buttons(ButtonWire)— 「この要素のこの操作で、これをする」

項目説明
ButtonPathPrefab ルートからの相対パス(例 Panel/StartButton)
TriggerClick(押した)/ DoubleClick(2 回押し)/ LongPress(長押し。UiButton の LongPressSec が必要)/ Repeat(押しっぱなしの連射)
ActionNone(何もしない)/ OpenCanvas(Target の画面を開く)/ CloseSelf(この画面を閉じる)/ CloseTop(「戻る」= 一番上の閉じられる画面を閉じる)/ SendSignal(SignalKey でプログラマーに通知)/ PlayPresentation(未実装。Phase 5 予定。押すと「ButtonWire.Action=PlayPresentation は Phase 5 で実装予定です」と警告が出るだけ)/ SetOption(スライダー専用)
TargetAction=OpenCanvas のときに開く Canvas データ
SignalKeyAction=SendSignal のときの通知名(例 shop/buy)。プログラマーと名前を決めておきます
ClickSe押したときの効果音。空ならレイヤー既定の SE / Skin の SE が使われます

Sliders(SliderWire)

項目説明
ElementPath対象 UiSlider の相対パス
TriggerChanged(値が動くたび)/ Commit(離した・確定)/ NotchPassed(目盛りを跨いだ)/ LimitReached(端に到達)
Actionスライダーで意味があるのは SetOption(標準オプションに書き込む)/ SendSignal(現在値付きで通知)/ PlayPresentation(未実装)
SignalKeySendSignal の通知名。スライダーの現在値が一緒に届きます
OptionSetOption の書き込み先。MasterVolume(いま効く: 全体音量)/ UiSpeedScale(いま効く: UI 演出の速さ)/ BgmVolume・SeVolume・VoiceVolume(値を保存するだけ。バス別音量は Phase 5 待ち)/ ShakeScale・HapticScale(値を保存するだけ。Phase 6 待ち)。開いたときに保存値でスライダーが初期化され、動かすと書き戻ります。保存は自動です
ThrottleSecTrigger=Changed の通知を間引く秒数。UiSlider 側の ChangeThrottleSec との大きい方が使われます

ElementEffects(ElementFx)— 要素ごとの出現 / 常時 / 消滅

項目説明
ElementPath対象要素の相対パス(ルート自身は空 = Canvas Editor では「(ルート)」)
AppearPreset / IdlePreset / DisappearPreset組み込みプリセットの指定。Preset(種類)/ Duration(0 = 既定の秒数)/ Distance(Slide の移動量や Shake の強さ。0 = 既定)/ EaseOverride(緩急の上書き)/ Se(同時に鳴らす SE)
Appear / Idle / DisappearUI Tween データの直接指定。設定があればプリセットより優先(UI Tween)
AppearDelay開き始めからこの秒数だけ遅らせて Appear を始める。項目を順番に出す「スタッガー」(段差)演出に使います
AppearSe / DisappearSe出現時 / 消滅時に鳴らす SE

どれが使われるか(解決順): UI Tween の直接指定(Appear など)→ プリセット(AppearPreset など)→ レイヤー既定(UiLayerSettings の DefaultAppear / DefaultDisappear。Idle にレイヤー既定はありません)。3 つとも無ければその区間は何もせず即完了です。

プリセットの種類:

  • 出現: FadeIn, SlideInLeft / Right / Top / Bottom, ScaleIn, PopIn, BounceIn, ElasticIn, FlipInX / Y, RotateIn, ZoomInFade, SlideFadeInLeft / Right / Top / Bottom, ExpandWidth, ExpandHeight, TypeFillIn
  • 消滅: FadeOut, SlideOutLeft / Right / Top / Bottom, ScaleOut, PopOut, BounceOut, ElasticOut, FlipOutX / Y, RotateOut, ZoomOutFade, SlideFadeOutLeft / Right / Top / Bottom, CollapseWidth, CollapseHeight
  • 常時(ループ): Pulse, Blink, Float, Sway, Breathe, RotateLoop, ShimmerAlpha, RainbowTint, WobbleLoop — Idle にはこの 9 種から選びます
  • 強調(単発): PunchScale, PunchRotation, Shake, ShakeHard, Flash, ColorFlash, HeartBeat, Jelly, Tada, RubberBand, AttentionJump

UiLayerSettings(レイヤーごとの既定)

項目説明
Layer対象レイヤー(HUD / Menu / Popup / Overlay / Loading)。Layers 配列に 1 レイヤー 1 行
DefaultButtonSkinSkinId が未設定のボタン・スライダーに当てる既定の Skin
DefaultClickSe / DefaultHoverSe / DefaultDeniedSe決定音 / カーソル音 / 拒否音の既定。開いたときに Prefab 内の全ボタンに配られます
DefaultAppear / DefaultDisappearElementFx の Appear / Disappear が両方未設定のときの既定演出

実行時の挙動

  • レイヤー: 初回に [D-Drive] UI Root が作られ、その下に HUD / Menu / Popup / Overlay / Loading の 5 枚の Canvas が並びます。重ね順はレイヤー番号 × 100(+ SortOffset)
  • スタック: 開いた画面はレイヤーに関係なく 1 本の「積み重ね」に順番に積まれます。「戻る」(CloseTop)は上から順に、CloseOnBack が ON で閉じ処理中でない画面を 1 つ閉じます
  • モーダル: Ui.Popup で開いた ModalBlocksInput=ON の画面より下にある画面は、すべて操作できなくなります
  • 入力ゲート: 要素の Appear が全部終わるまで、その画面は入力を受け付けません(モーダルとは無関係)。AppearDelay を大きくしすぎると、その分だけ操作できない時間が延びます
  • Close の完了: CloseTransition が終わり、かつ全要素の Disappear が終わったとき。Disappear にループ演出を入れると閉じ終わりません
  • フォーカス移動: 十字キー / スティックで、uGUI の Button も D-Drive の UiButton / UiSlider も同じようにフォーカスが移ります。順番は Navigation の明示リンクが優先、無ければ開いている画面の中でその方向に一番近い要素へ。スライダーは十字キーが値の操作になり(右・上で増、左・下で減)、端まで行ったときだけ隣へ抜けます(EscapeOnLimit ON のとき)

よくある使い方

やりたいこと設定
タイトル画面Prefab を設定、Layer=Menu。Canvas Editor で「Selectable を自動収集」→ グラフで上下リンク → 右クリック「FirstSelected にする」→「確認用シーンで開く」
ボタンで別の画面へ(コード 0 行)Buttons に 1 行: ButtonPath、Trigger=Click、Action=OpenCanvas、Target=遷移先。UiButton の CooldownSec を 0.2 秒ほど入れて連打対策
確認ダイアログ(モーダル)Layer=Popup、ModalBlocksInput=ON、CloseOnBack=ON。プログラマーは Ui.Popup で開く。「はい」は Action=SendSignal + SignalKey confirm/yes、「いいえ」は Action=CloseSelf
ポーズメニューLayer=Menu、PauseGameWhileOpen=ON、CloseOnBack=ON
音量設定画面(コード 0 行)Prefab に UiSlider → Sliders に 1 行: Trigger=Commit、Action=SetOption、Option=MasterVolume。保存 / 復元は自動
項目を順番に出す(スタッガー)Canvas Editor の「要素を自動収集」→ 各行の Appear に SlideFadeInLeft など → AppearDelay を 0.05 / 0.10 / 0.15 … と段差を付ける
全ボタンに同じ出現演出Canvas Editor の「プリセット」で PopIn を選び「一括適用: 全ボタンに反映」。またはプリセットギャラリーの「Canvas 内一括適用(全ボタン)」
レイヤーごとの既定演出・既定 SEUI_LayerSettings を 1 個作り、DDriveRuntimeBootstrap の LayerSettings に割り当て

よくある警告

表示場所は Canvas Editor の「Validation」と Tools > D-Drive > Validation > Run All です(Validation の見方)。

表示対処
Prefab が未設定(または Missing)ですPrefab を設定する。これが出ている間はパスに関する検査は全部止まります
Navigation[i] の Element '…' が Prefab 内の Selectable として見つかりませんパスを直すか行を消す(グラフでは黄土色の枠)
Navigation[i] の Up/Down/Left/Right '…' が Prefab 内の Selectable として見つかりません移動先のパスを直す
Navigation[i] '…': 左右 NavNode が設定されていますが EscapeOnLimit=false です(フォーカスが抜けられません)対象 UiSlider の EscapeOnLimit を ON にするか、左右リンクを外す
Selectable '…' は Navigation のどこからも到達できませんどこかからリンクを張る(グラフの赤枠)
Navigation が設定されていますが FirstSelected が未設定ですグラフの右クリック「FirstSelected にする」
FirstSelected '…' が Prefab 内で見つかりませんパスを直す
ButtonWire[i] の ButtonPath '…' が Prefab 内で見つかりませんパスを直す
ButtonWire[i] '…': Action=OpenCanvas なのに Target が未設定です開く先の Canvas データを Target に
ButtonWire[i] '…': Action=SendSignal なのに SignalKey が未設定です通知名を入れる
ButtonWire[i] '…' の Trigger=… が重複しています片方を消す
ButtonWire[i] '…': Trigger=LongPress なのに対象 UiButton の LongPressSec が 0 以下ですUiButton の LongPressSec に秒数を入れる
ButtonWire[i] '…': CooldownSec=0 の状態で OpenCanvas に配線されています(連打で多重遷移するおそれがあります)UiButton の CooldownSec を 0.2 秒程度に
SliderWire[i] の ElementPath '…' が Prefab 内で見つかりませんパスを直す
SliderWire[i] '…': Action=SetOption なのに Option が未設定(None)です書き込み先を選ぶ
SliderWire[i] '…': Trigger=Changed かつ ThrottleSec=0 のまま重処理(PlayPresentation)に配線されていますThrottleSec を入れて間引く
ElementFx[i] の ElementPath '…' が Prefab 内で見つかりませんパスを直すか行を消す
ElementFx[i] '…' の ElementPath が重複しています1 行にまとめる
ElementFx[i] '…': AppearDelay が負数です0 以上に
ElementFx[i] '…': 出現なし(Appear/AppearPreset が未設定です)意図的なら無視可(Info)
ElementFx[i] '…': Idle には常時系プリセットを推奨します(Pulse/Blink/Float/Sway/Breathe/RotateLoop/ShimmerAlpha/RainbowTint/WobbleLoop)常時系に変える
Layer=Popup ですが ModalBlocksInput が OFF です(背後の入力がブロックされません)ダイアログなら ON に(Info)

このほか、Prefab 内の UiSlider の設定(Min / Max / Step / Notches など)の検査結果も混ざって出ます(Slider Editor)。実行時には「CanvasData '…' の ElementFx[i] '…' が Prefab 内(RectTransform)で見つかりません。この行はスキップします。」がコンソールに出ることがあります(パスを直してください)。

注意点

  • Action=PlayPresentation は未実装(Phase 5 予定)。押しても警告が出るだけです
  • Navigation の 4 方向はむやみに全部埋めない。全部空なら Unity の自動ナビゲーションのままで、レイアウト変更にも追従します
  • ModalBlocksInput は Ui.Popup で開いたときだけ効きます。Layer=Popup でも OFF なら背後は操作できます
  • Idle にレイヤー既定はありません。単発プリセットを Idle に入れると警告になります
  • Disappear に無限ループの演出を入れると画面が閉じ終わりません
  • Option の BgmVolume / SeVolume / VoiceVolume / ShakeScale / HapticScale は値を保存するだけで、まだ効きません(コンソールに 1 回「Audio バス別音量 … は Phase 5 で実装予定のため、値は保持のみです」と出ますが仕様です)
  • 十字キーのフォーカス移動には、シーンに EventSystem(InputSystemUIInputModule 付き)が必要です
