カットシーン（Timeline）: Maya から書き出して Unity で演出を足す

最終更新日: 2026-09-19

必殺技のカットインやラウンド開始 / 勝利デモのような数秒の短い演出で、Maya で作ったカメラワークとキャラの動きをそのまま Unity で再生するための、Maya 側の書き出し手順です。Maya のスクリプトやプラグインは使いません。標準の FBX 書き出しだけで済みます。Unity 側では、決められたフォルダに FBX を置くだけでカットシーンのデータ（CutsceneData）と Timeline が自動で作られ、そこに効果音・エフェクト・画面揺れなどを足せます。

2026-09-18 に Unity 側の取り込み機能(Timeline チケット 6-10a〜d)を実装しました。 このページの手順とファイル名のルールで、そのまま取り込めます。ただし この環境には実際の Maya 書き出し FBX が無いため、カメラの画角以外(ピント距離・絞り・イベント用ロケーター)は実 Maya 素材での確認がまだ済んでいません(下の各節に記載)。実際に書き出して試したときに画面と食い違う点があれば都度このページを直してください。

先に決めておくこと（プロジェクト共通）

項目決めごと理由
シーンの fpsプロジェクトの既定（30 または 60。どちらかは Unity 側の設定 CutsceneImportProfile で宣言されています。分からなければプログラマーに確認）違う fps でも取り込めますが、Validation に「宣言と違う」というお知らせ（Info）が出ます。同じショットの中でファイルごとに fps が違うのは NG（Warning）
単位・上方向cm・Y-up（Maya の既定のまま）Unity の取り込み既定に合わせ、大きさのずれを防ぐ
キャラリグの名前リグの名前空間（または参照ファイル名）を D-Drive のモデル識別子に揃える（例: モデル識別子が Hero なら名前空間 Hero:）Unity 側で「どのキャラを動かすか」を自動で結び付けるため。違っていても Unity 側で手で結べます
カメラ複数カメラで切り替えて作った場合は、Camera Sequencer の「Ubercam 作成」で 1 台のカメラに焼く1 台にしておくと Unity 側でそのまま 1 本のカメラクリップになる。複数のまま出しても取り込めます（Unity 側でカメラごとにクリップが並ぶ）

ファイル名のルール（これだけ守る）

1 つのショット（= 1 つのカットシーン）は、「カメラ + 小物」の FBX 1 本と、キャラごとの FBX（キャラの数だけ）のセットです。ファイル名で「同じショットか」「どのキャラか」を判別します。

対象ファイル名例Unity 側で起きること
カメラ + 小物<ショット名>.fbxOpening01.fbxカットシーンデータ CUT_<カテゴリ>_Opening01 ができ、カメラはカメラクリップになる
キャラ（1 体ずつ）<ショット名>__<モデル識別子>.fbx（アンダースコア 2 つ）Opening01__Hero.fbx役割 Hero として、モデル Hero に自動で結び付く
同じキャラ 2 体目識別子の末尾に _2、_3 …Opening01__Hero_2.fbx同じモデルを 2 体出す
小物（剣・扉など動く物）ノード名を PRP_<モデル識別子>、または名前空間 = モデル識別子。カメラと同じ FBX に入れるPRP_Swordモデル Sword に結び付く
イベントの目印（任意）ロケーター EVT_<キー>EVT_Hit今回は未対応です（実 Maya 素材が無く安全に検証できなかったため、6-10c では取り込みを実装していません）。Unity の Timeline ウィンドウで手動で D-Drive Signal マーカーを置いてください
@ をファイル名に使わないでください（Hero@Opening01.fbx のような形）。Unity が「同じフォルダの Hero.fbx にアニメを合流させる」古い動きをしてしまうため、区切りは __（アンダースコア 2 つ）にしています。

書き出し手順（1 ショットにつき、1 + キャラ数 回）

なぜキャラごとに分けるのか: Unity は 1 つの FBX に 1 体分の「人型（Humanoid）の骨の定義」しか持てません。2 キャラを 1 つの FBX に入れると片方の動きが正しく移りません。そのため Export Selection をキャラの数だけ行います。手数は増えますが、スクリプト無しの標準機能だけで済みます。
  1. カメラ + 小物: カメラ（Ubercam）・小物（PRP_*）・イベント用ロケーター（EVT_*）だけを選択 → File > Export Selection → 形式 FBX → 名前 <ショット名>.fbx。キャラは選ばない。動かない背景も選ばない（背景は Unity 側のシーンに置きます）
  2. キャラ 1 体目: そのキャラのルートジョイント（骨の一番上）を選択（骨の階層ごと選ばれます。メッシュは選ばない）→ File > Export Selection → 名前 <ショット名>__<モデル識別子>.fbx
  3. キャラ 2 体目以降: 2 を繰り返す（同じキャラが 2 体なら __<識別子>_2）
  4. すべて 同じ保存先に置く: Assets/SourceAssets/Cutscene/<カテゴリ>/（カテゴリは Skill / Round など、Unity 側のフォルダ分け。既にあるフォルダに合わせてください）

書き出しオプション（1〜3 で共通）

項目設定理由
AnimationON—
Bake AnimationON。開始〜終了 = ショットの全フレーム、Step 1IK・コンストレイント・エクスプレッションは Unity に持っていけないので、キーに焼きます。同じショットの全ファイルで開始〜終了フレームを揃える（ずれると Validation Warning）
CamerasONカメラの位置・回転・画角（焦点距離）を持っていく

Embed MediaOFFテクスチャは不要（見た目は Unity 側のモデル / マテリアルが正）

カメラのピント・絞りも持っていきたいとき（任意）

画角（焦点距離）は標準の書き出しで持っていけます（Unity の Animation ウィンドウの既知の束縛名 field of view から取得する実装です)。ピント距離・絞り（f 値）は FBX の標準属性(FocusDistance/FStop)から複数の候補名で取得を試みる防御的な実装になっていますが、実 Maya 素材での確認はまだ済んでいません(この環境に実 FBX が無いため)。取得できなければ空のまま(ピントは書き込まれません)。うまく届かない場合は Maya のカメラにカスタムアトリビュート dd_focusDistance（ピント距離、cm）と dd_fStop（絞り）を追加してキーを打つ経路も設計上は用意していますが、こちらも今回は取り込みを実装していません(イベント用ロケーターと同じ理由)。持っていかなくても、Unity 側でショットごとに手で入れられます。

2026-09-20 追記: 焦点距離・ピント距離・絞りのいずれか 1 つでも取得できた新規ショットは、Camera クリップの「Focus」設定が自動的に Volume（ピントを URP の被写界深度に反映する）になります。1 つも取得できなかった場合は自動的に Off になり、ピントは一切効きません(以前は無条件で Volume になっていたため、ピントが取得できないショットで画面全体がボケてしまう不具合がありましたが解消しました)。「Focus」は Timeline ウィンドウでいつでも手で切り替えられ、一度手で変えた設定は同じ FBX を再取り込みしても保持されます。

Unity 側で確認する

  1. FBX をフォルダに置くと自動で取り込まれ、Asset Browser の「Cutscene」にショットが現れる
  2. Validation の「Run All」で次を確認する:
    • fps が違う（Warning）: 同じショットのファイル間で fps が違う。Maya のシーン fps を揃えて書き出し直す
    • モデルが見つからない（Warning）: ファイル名の識別子と D-Drive のモデル識別子が違う。ファイル名を直すか、Unity 側のバインド表で手で選ぶ
    • Avatar が未設定（Error、モデル側）: キャラ本体のモデルデータに人型（Humanoid）の Avatar が無い。モデル担当に依頼
  3. Asset Browser でショットの CutsceneData を選ぶと、Inspector 上部に「Timeline ウィンドウで開く」「Cutscene確認用シーンを開く」ボタンとバインド検査(役割名⇔Timeline のトラック名の食い違い)が出ます。効果音・エフェクト・画面揺れは Timeline ウィンドウで足す（演出と同じ ID を置くだけ）
  4. 「Timeline ウィンドウで開く」を押すと、確認用シーンにプレビュー用のカメラ・キャラ位置が自動で用意され、標準 Timeline ウィンドウが開きます。再生ボタンを押すだけでカメラの動き・効果音・エフェクト・画面揺れ・コントローラー振動・イベントがその場で確認できます(Play Mode に入る必要はありません)。ドラッグしてスクラブしている間は音・エフェクトは鳴らず、カメラだけ現在位置に追従します
  5. 通信対戦での見え方や「入力をロックする」通知、途中で飛ばす(Skip)機能まで含めて確認したいときは、「Cutscene確認用シーンを開く」で確認用シーンを開き、Play ボタンを押して(Play Mode に入って)から CutsceneData の Inspector の「● 再生(Play Mode)」ボタンを押してください

Unity の Timeline ウィンドウで演出を足す

FBX を置くと自動で作られる Timeline に、効果音・エフェクト・画面揺れなどを足して仕上げます。編集画面は Unity 標準の Timeline ウィンドウです（D-Drive 専用の画面は作っていません）。

カットシーンと「演出（Presentation）」の使い分け

質問選ぶもの
Maya で作ったカメラやキャラの動き（FBX）を使う？ / 演出中カメラをゲームから奪って別のカメラワークにする？カットシーン（このページ）
ヒット判定など「ゲームの結果を待ってから」続きを出したい？ / 既存の SE・VFX・揺れ・HitStop を時間で並べるだけ？演出（Presentation）
Maya カメラも使うし、ヒットも待ちたい演出を親にして、Timeline トラックでカットシーンを呼ぶ

一言でいうと「Maya の FBX を使うならカットシーン、使わないなら演出」です。

開き方と流れ

  1. Asset Browser で「Cutscene」のショット（CUT_…）を選ぶ
  2. Inspector 上部の「▶ Timeline ウィンドウで開く」を押す(確認用シーンにプレビュー用のカメラ・キャラ位置が自動で用意されます)
  3. Timeline ウィンドウでトラックを足し、効果音・エフェクトなどを演出と同じ ID(名前で選べます)で置く
  4. そのまま Timeline ウィンドウの再生ボタンを押すと、置いた SE/VFX/UI/AnchorGroup/Camera/Shake/Haptic/Event/Signal がその場で確認できます。合わなければ止めて調整し、また再生ボタンを押すだけです
  5. 通信対戦・入力ロック・Skip まで確認したいときは、Inspector の「▶ Cutscene確認用シーンを開く」で確認用シーンを開き、Play ボタンで Play Mode に入ってから「● 再生(Play Mode)」を押して見る(Cancel / Skip ボタンも試せます)

足せるトラック

トラック / マーカー使い方
Camera（黄色）Maya のカメラを取り込むと自動で作られます。ステップ fps（0 = そのまま。数字を入れると、その fps のコマ落ち風に見せます。24fps 風にしたいとき）、ブレンド秒（ゲームのカメラから Timeline のカメラへ滑らかに繋ぐ長さ。前後それぞれ）、ピントの設定を、ショットごとに調整します
SE / VFX / AnchorGroupクリップを置くと、その時刻から鳴る / 出ます。クリップの長さが、ループする SE や VFX を鳴らし続ける時間になります（1 回だけ鳴る SE は開始点だけ使われます）
UI / Presentation区間のあいだだけ Canvas（字幕・レターボックス等）を開く / 演出を再生します。演出の中に「合図待ち（On Signal）」のトラックがあるものは、カットシーンから合図を送れないので検証に警告が出ます
Event / Shake / Haptic（マーカー）置いた時刻にイベント（SE や VFX を鳴らす等）・画面揺れ・コントローラー振動を 1 回出します
Signal（マーカー）文字列のキー（cutscene/xxx の形）を置くと、プログラム側がその時刻を受け取れます。「ここで画面を切り替える」等の連携用です

キャラや小物の動きは、Unity 標準の Animation トラックのままです（人型のリターゲットなどをそのまま使うため）。トラックを追加するときは Timeline ウィンドウの「トラックを追加」メニューから D-Drive のトラックを選びます（メニューに出る正確な表記は、実機ではまだ確認していません）。

カットシーンデータ（Inspector）の主な設定

項目意味
Origin（原点）Maya の座標をゲームのどこに置くか。Self（使う人の位置と向き。必殺技のカットインなど・既定）/ World（Maya の座標そのまま。ステージ固定のデモ）/ AnchorPoint（名前を付けた目印の位置）
Frame RateMaya のシーンの fps。取り込みで自動で入ります（30 か 60）
Skip途中で飛ばせるか。不可 / 即終了 / 指定した Signal マーカーまで飛ばす
Lock InputON にすると、再生中は「入力をロックする」という状態がゲームに通知されます。実際に操作を止めるのはゲーム側の実装で、D-Drive は通知するだけです
Flags > NetLocal = 自分の画面だけ / Cosmetic = 通信対戦で相手の画面にも同じ演出を出す（見た目だけで勝敗に影響しないもの）。演出と同じ考え方です
確認の注意: Timeline ウィンドウの再生ボタンで Camera/SE/VFX/UI/AnchorGroup/Shake/Haptic/Event/Signal は Edit Mode のまま確認できます(Play Mode に入る必要はありません)。ドラッグしてスクラブしている間は音・エフェクトは鳴りません(連打防止)。Presentation クリップ・通信対戦(Cosmetic)・入力ロックの通知・Skip だけは Play Mode でないと確認できません(確認用シーンを開いて Play ボタンを押してから CutsceneData の Inspector の「● 再生(Play Mode)」を使ってください)。

直すとき

  • Maya で直して同じファイル名で上書き書き出し → Unity が再取り込みし、カメラ・キャラの動きだけ差し替わります。Unity 側で足した効果音・エフェクト・カメラの「コマ落ち（ステップ fps）」「ブレンド秒」などの設定はそのまま残ります
  • ファイル名を変えると別のショットとして扱われます（新しいカットシーンデータができる）
  • キャラが増えた / 減った: 増えたら FBX を 1 本足すだけ。減ったら FBX を消しても、Unity 側のトラックは消さずに「ミュート」になります（Unity 側で足した設定を消さないため）

よくある質問

質問答え
1 つの FBX に 2 つのショットを入れてしまったUnity 側でショットごとに「フレーム範囲」を指定して切り出せます（逃げ道）。ただし既定は「1 ショット = 1 FBX セット」なので、できれば分けてください
カメラの動きが「ぬるぬるし過ぎる」。24fps 風にしたいMaya で間引かないでください。Unity 側のカメラクリップに「ステップ fps」の項目があり、ショットごとに Unity 側でコマ落ちの度合いを変えられます（Maya をやり直さなくて済みます）
キャラ本体（メッシュ）も一緒に出してよい？出さないでください。キャラ本体は普段どおりモデルデータとして登録済みのものを使い、カットシーン FBX には骨の動きだけを入れます（同じキャラを何ショットでも使い回すため）
Generic（人型でない）キャラは？剣・扉などの小物は Generic で OK（カメラと同じ FBX に入れる）。キャラは人型（Humanoid）のみ対応です
