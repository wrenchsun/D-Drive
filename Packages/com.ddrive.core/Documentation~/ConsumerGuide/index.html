D-Drive 持ち込み先ガイド（持ち込み先向け）

最終更新日: 2026-09-20

このガイドは、D-Drive（com.ddrive.core）を UPM パッケージとして導入したプロジェクト（MS2026 等）で初めて D-Drive に触れるプログラマー向けに、「導入手順」「更新方法」「運用方法」を 1 ページずつに分けたものです。D-Drive というシステム自体の仕組み（Data/Instance/Handle、Presentation 等）や、Unity 上でのアセットの作り方は扱いません。それらは プログラマーマニュアル・デザイナーマニュアルを参照してください。

読み分け: 「D-Drive というパッケージをどう入れる・上げる・保守するか」を知りたいときは本ガイド。「D-Drive の API をどう呼ぶか」「専用エディタのボタンは何をするか」を知りたいときはプログラマー/デザイナーマニュアルを使ってください。

ページ一覧

  • 導入手順

    依存パッケージの確認、manifest.json への追加、セットアップウィザードの実行、SE を 1 件登録して Play Mode で確認するまで。初めての人はこちらから。

  • 更新方法

    更新チェック → manifest.json の版上げ → 更新を適用 → Validation の順で進める手順、ロールバック、MAJOR 更新時の移行ガイドの読み方。

  • 運用方法

    日常の Validation、ID/調整値の再生成、Addressables 同期、CI テンプレの組み込み、命名規則との付き合い方、テストの有効化、AI エージェント向けスキル、困ったときの見方。

まず読む順番

  1. 導入手順 — 初めてこのプロジェクトに D-Drive を入れるとき
  2. 運用方法 — 導入が終わり、日々の開発で D-Drive を使い始めるとき
  3. 更新方法 — D-Drive の新しい版が出たとき（都度参照でよい）
