# 更新チェックリスト

D-Drive のバージョンを進めるときに、順番どおりに進めるためのチェックリスト。詳細は `SKILL.md` §4、開発リポジトリの `docs/42_distribution.md` §4.2 を参照。

1. [ ] 作業ツリーをクリーンにし、更新用のブランチを切る
2. [ ] 対象版までの `CHANGELOG.md` の「互換性」節を読む。「破壊あり」があれば `docs/migrations/` の移行ガイドを先に読む
3. [ ] `Packages/manifest.json` の `#vX.Y.Z` タグを新しい版に書き換える（`packages-lock.json` も変わる）
4. [ ] Unity を開き直し、コンパイルエラーが無いことを確認する
5. [ ] `Tools > D-Drive > Update > 更新ウィンドウ` を開き、「1. 版と CHANGELOG」の表示を確認する
6. [ ] 「2. マイグレーション（プレビュー）」で対象件数を確認する
7. [ ] 「3. 更新を適用」を実行し、途中で失敗せず最後まで完了することを確認する
8. [ ] `Validation > Run All` で Error が 0 件であることを確認する
9. [ ] EditMode/PlayMode 相当のテスト（このプロジェクトで用意しているもの）を実行する
10. [ ] NGO を使っている場合は、Host/Client を同じ版で起動し、接続時のバージョン照合（`ProtocolVersion`）でエラーが出ないことを確認する
11. [ ] manifest / lock / 更新で変わった `.asset` / 生成コードを 1 コミットにまとめる
12. [ ] このプロジェクトの CI（`Tools~/CI/` のテンプレを組み込んでいる場合はそのワークフロー）が green であることを確認する

途中で問題が起きた場合は、更新コミットを `git revert` してロールバックできます（同一メジャーバージョン内であれば、旧フィールドが残っているため旧版でも読めます）。詳細はパッケージ `README.md` の「ロールバック」節を参照してください。
