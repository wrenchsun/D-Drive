用語集

マニュアルや Unity の画面に出てくる言葉の説明です。五十音・アルファベット順。

共通・全般

用語説明
アイコン (Icon)Inspector のアイコン行に出る小さな画像。Asset Browser の一覧行の先頭や、Project ウィンドウをグリッド表示にしたときのサムネイルにも同じ画像が出ます。作り方は 3 通り: 「自動生成」（Prefab・画像を持つ種類やマテリアルは、その見た目から自動で作られる）/「フォルダから選択」/「シーンから作成」（SceneView の写真から切り取る）。画像は Assets/GameData/Icons/ に保存されます（トップの「共通の入口」参照）。
Addressables（アドレッサブル）ゲーム実行時にアセットを名前（アドレス）で読み込む Unity の仕組み。D-Drive のデータはここにも登録されていないとゲームで出てきません。Asset Browser で作れば自動で登録されます。漏れは Validation の「修正」で直せます。
アセットゲームで使う素材データのこと。このプロジェクトでは特に「D-Drive に登録された音・エフェクトなどのデータ」を指します。
アセットブラウザ
(Asset Browser)		D-Drive の素材を一覧・検索・登録するウィンドウ。使い方はこちら。
インスペクター
(Inspector)		Unity 画面の右側にある、選択中のものの詳細設定を表示する場所。項目にマウスを乗せると説明が表示されます。
ID（アイディー）アセット1つ1つに付く「番号札」。プログラムはこの番号で音を呼び出すので、中身を差し替えてもプログラム修正は不要になります。番号はツールが自動で管理するため、手で触ることはありません。
Placeholder（プレースホルダー）まだ中身（音・見た目）が入っていない、ID だけ確保された空のデータ。プログラマーは中身が無くてもこの ID でコードを書き進められます。仕様書と同期で新規行から自動的に作られるのもこれです。デザイナーが後から中身を作り込むと Placeholder ではなくなります。
Archive（アーカイブ）/ Archived タグ「もう使っていないかもしれない」印を付けるだけの操作で、削除ではありません。ファイルはそのまま残ります。Asset Browser の「未使用...」一覧から一括で付けられます。実際に消すかどうかは人が別途「削除...」で判断します。
カタログ (AssetCatalog)どの ID がどのアセットかを書いた管理台帳。Asset Browser で作れば自動で載るので、普段は意識しません。
確認用シーンライト・カメラ・床がそろった、見た目チェック専用のシーン。各エディタの「確認用シーンを開く」で開きます（無ければ自動で作られます）。D-Drive のエディタはウィンドウの中に絵を出さず、必ずシーンに置いて SceneView / Game ビューで確認します。
識別子アセット登録時に入力する英語の名前（例: SwordSlash）。プログラマーがコードで使う名前になります。英字大文字始まり・英数字のみ。
修正ボタン (FixAction)Validation の警告の横に出る、その場で自動修正するボタン。付いていない警告は手で直します。
Spawn / Despawn
（スポーン / デスポーン）		シーンに出すこと / 消すこと。モデル・Prefab・VFX で使う言葉。
プール (Pool)出したものを捨てずに取っておいて使い回す仕組み。連射する弾やエフェクトを軽くするために使います。データの Flags の Pool で「使い回す（Pooled）」か「毎回捨てる（None、既定）」かを選びます。Pooled のときは同時に出せる上限（MaxCount）と、上限を超えたときにどれを回収するかの優先度（Priority）が効きます。
Preload（プリロード）/ Preload リストシーンを開く前に、そのシーンで使う音・エフェクトなどを先読みしておく仕組み。シーンが参照している ID を自動で集めた一覧（ScenePreloadList）を Tools > D-Drive > Generate > Preload リストを再集計 で作り、ロード画面（SceneLoadingScreen）が進捗を見せながら読み込みます。デザイナーが個別に何か設定する項目はなく、シーンに新しい ID 参照を増やしたら、プログラマーに「Preload リストを再集計してほしい」と伝えるのが唯一の注意点です（Prefab の Pool の「温め」(Prefabs.PreloadAsync) とは別の仕組みです。あちらは同時に出せる個体をあらかじめ用意しておくもの）。
ポーズ時の扱い (Pause)ゲームを一時停止したとき、この音・エフェクトも一緒に止まるかどうかの設定（Flags の中）。PauseWithGame = 一緒に止まる / IgnorePause = 止まらない / UIOnly = UI 操作系だけ追従。
ハンドル (Handle)「いま再生しているこの 1 本」を指す一時的な番号。プログラム側が使うもので、デザイナーが直接触ることはありません。
ヒエラルキー
(Hierarchy)		Unity 画面の左側にある、シーン内に存在するモノの一覧。
プレハブ (Prefab)シーンに何度でも置ける「ひな形」。エフェクトの実体（ParticleSystem など）は Prefab として作り、VFX データから参照します。
プレハブモードPrefab の中身だけを編集する Unity の画面状態。Project で Prefab をダブルクリック、または VFX Editor / Model Editor / Anim Editor の「Prefab を開く」で入り、Hierarchy 左上の「←」で抜けます。エディタはこの状態でも再生できます（詳しくはこちら）。
プレビューゲームを実行せずに、エディタ上でその場で再生して確認すること。D-Drive のプレビューは実際のゲームと同じ仕組みで再生されるので、「エディタでは良かったのに実機で違う」が起きにくいのが特長です。
繰り返し (Repeat)イベント（音・エフェクト）を「毎周回」出すか、「1 回」だけか、「再生中は維持」（1 回出してモーションが終わるまで付いていき、終わると消える）か。フレーム指定だけでなく、再生開始（OnSpawn）や周回（OnLoop）のタイミングにも効きます。タイムラインで再生ヘッドを戻しても「1 回」「再生中は維持」はもう一度は出ません。Anim Editor のイベント一覧で選びます。
Validation（バリデーション）設定ミス（ファイル未設定・矛盾した数値など）や登録漏れを自動チェックする仕組み。Tools > D-Drive > Validation > Run All でプロジェクト全体を調べられ、自動で直せるものには「修正」ボタンが出ます。使い方はこちら。
ValueDef（値定義）「数値がどう変化するか」を決める共通の入力欄。定数（変わらない）/ 曲線（イージング名かベジェ）/ カーブ（自分で描く）の 3 モードと、時間（秒 / 速さ / 1 秒あたりの回数）、ループ（1 回 / 繰り返し / 行って戻る）を持ちます。UI の動き・マテリアルのアニメ・スライダーの応答曲線・2D アニメのコマ間隔などで共通して使われます。

音

用語説明
BGM背景音楽。D-Drive では「イントロ→ループ」構成やクロスフェード切替に対応。設定項目はこちら。
Mixer（ミキサー）
(Audio Mixer Group)		音の出力先グループ。「BGM 全体の音量」「SE 全体の音量」をまとめて調整できるようにするための仕組みです。どのグループを設定すべきかはサウンド担当の指示に従ってください。
SE（エスイー）効果音（Sound Effect）。斬撃音・足音・ボタン音など。設定項目はこちら。
Spatial / 3D サウンド音源の位置によって聞こえ方が変わる立体的な音の鳴らし方。遠いと小さく、右にあると右から聞こえます。対義語は 2D（どこでも同じ聞こえ方。UI 音など）。
トリミング音声の前後の不要部分（無音など）を切り落とすこと。D-Drive では元ファイルを変更しない「非破壊」方式です。やり方はこちら。
ピッチ (Pitch)音の高さ。1 が元のまま、2 で1オクターブ高く（再生速度も倍に）、0.5 で低く（半分の速さに）なります。
ループ (Loop)繰り返し再生のこと。BGM や環境音は基本ループ、通常の効果音は非ループ。

エフェクト・位置

用語説明
アンカー (Anchor)エフェクトや効果音を「どこに・いつ・どう出すか」の定義。ボーン名やオブジェクト名で基準を決め、そこからのずれ（オフセット）を足します。VFX と SE で共通の仕組み。VFX / SE データの中に埋め込む方法と、単独の Anchor データ（ランダム・ディレイ・確率・入れ子つき）を作って参照する方法があります。Anchor データの作り方 / 埋め込み項目の説明。
アンカーポイント
(AnchorPoint / AnchorRig)		シーンや Prefab に置く「ここに出す」という目印。SceneView でドラッグして位置を決められ、ランダムな散らばりも設定できます。使い方はこちら。
配置セット
(Anchor Group)		格子・円・一列・ランダムなどのパターンで並べた複数の場所に、エフェクトや効果音をまとめて出すためのデータ。使い方はこちら。
パーティクルシステム
(ParticleSystem)		Unity 標準の粒子エフェクト機能。火花・煙・光などを小さな粒の集まりで表現します。エフェクトの見た目そのものは Prefab の中のこれで作ります。
VFX（ブイエフエックス）エフェクト（Visual Effects）。斬撃・ヒット・炎・オーラなど見た目の演出。設定項目はこちら。
ライトレイヤー
(Light Layer Mask)		「どのライトの影響を受けるか」の設定。通常は Default のままで問題ありません。

モデル・アニメーション

用語説明
アニメーションデータ
(AnimData)		Clip とステート名、そして「何フレーム目で音・エフェクトを出すか」をまとめたデータ。Anim Editor でモデルを動かしながら調整します。使い方はこちら。
2D アニメーション
(Anim2D)		何枚もの絵（スプライト）をパラパラ漫画のように切り替えて動かすアニメーション。1 枚のスプライトシートから自動で切り分けて作れます。使い方はこちら。
スプライト / スプライトシート2D の 1 枚絵 / それをコマごとに格子状に並べた 1 枚の大きな画像。
検出プレビュースプライトシートの中の絵を自動で見つけて、緑の枠と番号（コマ順）で見せる Anim2D Editor の機能。
方向セット (Four / Eight)上下左右（4 方向）や斜めを含む 8 方向など、キャラの向きごとに別のコマアニメを持たせる仕組み。向きに応じて自動で切り替わります。
リタイミング各コマの表示時間をあとから一括で変える操作。「ためて速く振る」のような緩急を付けられます。
BlendTree（ブレンドツリー）向きや速度の値に応じて複数のアニメを混ぜて再生する Animator の仕組み。8 方向アニメの登録先。
フレーム (Frame)アニメーションの時間の単位。Clip のフレームレート（多くは 30）で 1 秒を割ったもの。「Frame 15」は 30fps なら 0.5 秒目。
モデルデータ
(ModelData)		キャラクターや物体の Prefab に、マテリアルのスロットと最初に再生するアニメーションをまとめたもの。スロットのマテリアルはゲーム実行時に実際に差し替わります。Model Editor で確認します。

マテリアル・テクスチャ

用語説明
マテリアル (MaterialData)モデルの「表面の質感」（色・金属っぽさ・ツヤ・透明度・発光など）をまとめたデータ。設定項目はこちら。
テクスチャ (TextureData)マテリアルに貼る画像そのものを管理するデータ。用途（モデル / UI）とチャンネル（色・法線・マスク・発光）を持ち、ファイル名のルールで設定が自動で決まります。
シェーダー表面をどう計算して描くかのプログラム。D-Drive では DDrive/Lit（光を受ける）と DDrive/Unlit（受けない）が標準。乗り換えは Material Editor の「シェーダー変換」で。
共通チャンネルAlbedo（素の色）・Normal（凹凸）・Mask（金属感 / ザラつき）・Emission（発光）など、シェーダーが違っても同じ意味で使える共通の入力欄。
Specific（固有プロパティ）共通チャンネルに収まらない、そのシェーダーだけの設定。「シェーダーから固有を同期」で自動的に並びます。
法線マップ (Normal)実際には平らな面に凹凸があるように見せる画像。ファイル名を _N や _Normal で終えると自動設定されます。
マスクマップ (Mask)金属っぽさ・遮蔽・ツヤなどを 1 枚の画像の色チャンネルにまとめたもの。ファイル名は _M / _MaskMap。
9-slice（スライスボーダー）UI 画像を引き伸ばしても角が歪まないように、四辺の余白（L,B,R,T）を指定する設定。
ターンテーブル置いたモデル / 球を自動でぐるぐる回して見せる確認機能（Model Editor / Material Editor）。

Prefab・UI

用語説明
Prefab データ (PrefabData)ゲーム中に出したり消したりする一般の Prefab（弾・小物・ギミック）を ID で管理するデータ。設定項目はこちら。
Canvas データ (CanvasData)メニューやダイアログなど、UI 画面 1 枚分の設定をまとめたデータ。設定項目はこちら。
レイヤー (UI レイヤー)UI の重なりの階層。HUD（常時表示）/ Menu（メニュー）/ Popup（ダイアログ）/ Overlay（最前面の演出）/ Loading（ロード画面）の順に手前になります。レイヤーごとに既定の Skin・音・演出を決められます。
Skin（スキン）ボタンやスライダーの「見た目と音の着せ替え」。通常・ホバー・押下・選択・無効・ロックの状態ごとに色・大きさ・画像・音を持ちます。使い方はこちら。
Tween（トゥイーン）位置・大きさ・色・透明度などを時間をかけて滑らかに変化させる演出。使い方はこちら。
イージング (Easing)変化の緩急の付け方（最初ゆっくり最後速く、行き過ぎて戻る、など）。名前で選べます（OutBack、InOutSine …）。
プリセット (Preset)よく使う演出の設定をひとまとめにした「ひな形」。出現・常時・消滅・強調の 59 種類があり、プリセットギャラリーから選んで当てます。
ElementFx（要素演出）UI 画面の要素ごとに「出現（Appear）・常時（Idle）・消滅（Disappear）」の 3 場面へ演出を割り当てる仕組み。
スタッガー複数の要素を少しずつ時間をずらして順番に動かすこと。ElementFx の AppearDelay で作ります。
Signal（シグナル）ボタンが押されたことを「shop/buy」のような合言葉でプログラムへ伝える仕組み。画面遷移はデータだけで組み、プログラムに知らせたい操作だけ Signal にします。
Navigation（ナビゲーション）パッドの十字キー / スティックで、UI のどこからどこへフォーカスが移るかのつながり。Canvas Editor のグラフで線を引いて決めます。
Popup / モーダル手前に開く小窓 / その裏側への操作を受け付けない状態。確認ダイアログに使います。
ノッチ / SnapThresholdスライダーの目盛り / そこへ吸い付く距離。「カチカチ」と段階的に動くスライダーを作るときに使います。

演出・カメラ・振動・仕様書連携

用語説明
演出 (Presentation / PresentationData)「剣攻撃」のようにアニメ・SE・VFX・カメラ揺れ・振動・画面停止(ヒットストップ)などを 1 つにまとめたデータ。プログラマーは Presentation.Play(…) の 1 行で呼び出せます。設定項目・専用エディタの使い方はこちら。
HitStop（ヒットストップ）一瞬だけゲーム全体の時間を止めて「打撃が重い」感触を出す演出。演出（Presentation）の Kind の 1 つで、Params の 1 つ目に止める秒数を入れます。
Total Duration（演出全体の長さ）演出（Presentation）1 つ分の長さ(秒)。0 のままだと At Time トラックの一番遅い時刻から自動で決まりますが、On Signal のトラックだけで組んだ演出は 0 秒扱いになりすぐ終わってしまうため、忘れずに秒数を入れる必要があります。
トラウマ (Trauma) 方式画面の揺れ（カメラシェイク）を複数同時に鳴らしたときの合成方法。単純な足し算にせず、最終的な揺れの強さを 0〜100% の範囲に収める仕組みで、連打しても画面が異常に揺れすぎることがありません。振動（ハプティクス）は別方式（チャンネルごとに一番強い値だけを採用）で、こちらも加算で振り切れないようにしています。
Cosmetic（コズメティック）通信対戦で「見た目だけの演出で、勝敗や当たり判定そのものには影響しない」再生の扱い。演出の Flags.Net が Cosmetic だと、当たった側だけでなく両方の画面に自動で同じ演出が出ます（振動はコントローラーを持つ本人だけ、というように鳴らし分けられるものもあります）。デザイナーが演出データを作るときの操作は通信対戦でもシングルプレイと同じで、特別な設定は基本的に不要です。
発注（アセット発注ツール）「誰が・何を・いつまでに作るか」を1件まとめたもの。アセット発注ツール（ブラウザで動く Web アプリ）に登録すると、D-Drive 側にPlaceholder（空のデータ）が自動でできます。状態は発注済/納品済/インポート済の3段階。
発注者 / 受注者アセット発注ツールにおける 2 つの役割。発注者は依頼する側（企画など）、受注者は実際に中身を作る側（デザイナーなど）。どちらもガントの担当者マスタから取り込んだ表記（例:「山口(PRG)」）で選びます。
Presentation 発注グループ演出（Presentation）1 つを親にして、その演出に必要な SE・VFX・カメラ揺れなどの発注を子としてまとめる仕組み。親を持たない発注は「単体」として扱われます。アセット発注ツールの「発注ツリー」画面で確認できます。
発注の状態（発注済 / 納品済 / インポート済）発注が進む3段階。発注済→納品済は受注者が手動で進めますが、納品済→インポート済は手動では選べず、D-Drive 側で Placeholder が解消された(Validation の Error が無い)ことが同期で確認できたときに自動で進みます。詳しくは仕様書との同期のページ。
アーカイブ（発注ツール）Archive と同じ「削除ではない」考え方を、アセット発注ツール側の発注・Presentation 発注グループにも適用したもの。一覧の「アーカイブ済みを表示」で再表示でき、詳細画面の「元に戻す」でいつでも戻せます。
Markdown（マークダウン）見出し・太字・箇条書き・リンクなどを簡単な記号（##・**太字**・- 項目・[文言](URL) 等）で書ける文書形式。アセット発注ツールの発注メモ（リファレンス）で使われ、専用の書式ボタン(Ctrl+B・Ctrl+K のショートカットつき)で記号を覚えなくても入力できます。
仕様書同期企画がアセット発注ツール（ブラウザで動く Web アプリ）に登録した発注を、D-Drive のPlaceholder（空のデータ）に変換する機能。Tools > D-Drive > 仕様書と同期で行う。詳しくは仕様書との同期のページ。
