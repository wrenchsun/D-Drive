マテリアル / テクスチャの設定項目

マテリアルデータ（MaterialData）は、Unity の Material の代わりに D-Drive で編集する「素材」のデータです。色・テクスチャ・光り方・透け方をここに書いておくと、Unity の Material 実体は D-Drive が自動で作って共有します。デザイナーが Unity の Material を直接作る必要はありません。

  • シェーダーごとにバラバラなプロパティ名（_BaseMap と _MainTex など）を意識せず、「アルベド」「ノーマル」「マスク」「エミッション」「ブレンド」という共通チャンネルで編集できます。どのシェーダーに流し込むかは D-Drive が自動で探します
  • シェーダーを乗り換えても共通チャンネルはそのまま残り、シェーダー固有の設定（Specific）だけを付け替えます（Material Editor の「シェーダー変換」）
  • Maya の FBX や Substance Painter のテクスチャは、決まったフォルダに置くだけでマテリアルデータ・テクスチャデータが自動で作られます
  • 一覧では球のサムネイルが自動でアイコンになるので、見分けやすくなります

テクスチャデータ（TextureData）は、1 枚の画像に「用途（UI 用 / モデル用）」と「チャンネル（アルベド / ノーマル / マスク / エミッション / その他）」のラベルを付けるデータです。マテリアルデータは画像を直接参照せず、このテクスチャデータの ID で参照します。用途とチャンネルを決めると、Unity 側の画像の読み込み設定（Texture Type / sRGB / Sprite / 9-slice）が自動で追従します。

用語: アルベド = 素の色（ベースカラー）/ ノーマル = 凹凸の向きを記録した画像（法線マップ）/ マスク = 金属っぽさ・遮蔽・なめらかさを 1 枚にまとめた画像 / エミッション = 自分で光る色 / ブレンド = 不透明・アルファ抜き・半透明のどれか。詳しくは 用語集。

作り方

  1. Project の右クリック: Create > D-Drive > Material > Material Data（ファイル名 MAT_NewMaterial）/ Create > D-Drive > Material > Texture Data（TEX_NewTexture）
  2. Asset Browser: ツールバーの「新規」で種別に Material または Texture を選ぶ。ID の発行・カタログ登録・Addressables 登録・初期アイコンの生成まで自動で行われ、Assets/GameData/Material/<カテゴリ>/MAT_<カテゴリ>_<識別子>.asset（テクスチャは Assets/GameData/Texture/…/TEX_….asset）に置かれます
  3. Maya の FBX から自動生成: FBX を Assets/SourceAssets/<カテゴリ>/ に置くだけ（下の「Maya からの受け渡し」）
  4. 既存の Unity Material から変換: Material（または Renderer を持つ Prefab / モデル）を Project で選んで Tools > D-Drive > Generate > 選択した Material を D-Drive/Lit・Unlit の MaterialData に変換
Asset Browser へのドラッグ&ドロップは現状 AudioClip だけに対応しています。画像や .mat をドロップしてもマテリアルデータ / テクスチャデータは作られません。上の 1〜4 のどれかで作ってください。

設定項目（マテリアルデータ）

項目説明
Shader使うシェーダー。未設定なら D-Drive がプロジェクト既定の Lit（URP Lit）で生成しますが、DDrive/Lit ではないので、明示的に設定しておくのが安全です（未設定は検証で Warning）。通常は DDrive/Lit（陰影あり）か DDrive/Unlit（陰影なし、そのままの色）
Commonどのシェーダーでも意味が共通するチャンネル。下の「共通チャンネル（Common）」を参照
Specificシェーダー固有のパラメータ。Common に無いものだけを入れます。要素は Property（シェーダープロパティ名。例 _SpecColor）と Value（値。Float / Int / Bool / Color / Vector / Object（テクスチャ等）のうち型に合うものを使う）。手で埋める必要はほとんどありません — Shader を設定すると Material Editor が自動で既定値を登録します
RenderQueueOffset描画順のずらし量。Blend から決まる基準（Opaque=2000 / Cutout=2450 / Transparent=3000）に足されます。普段は 0 のまま
RenderingLayerMaskRendering Layer Mask。0 なら Renderer 側の設定を変えません。ライトレイヤーは Renderer 単位の設定なので、モデル側の LightLayerMask（モデルの設定）も参照
Anims常時アニメ（UV スクロール等）。D-Drive が共有 Material に対して一括で動かします。下の「Anims の使い方」を参照
SourceMaterialMaya FBX 自動生成の由来（どの FBX のどのマテリアルから作られたか）。再インポート時の同定に使います。手動で作ったデータは空。手で編集しない項目です

共通チャンネル（Common）

項目説明
Albedoベースカラー（アルベド = 素の色）テクスチャの TextureData ID。未設定は検証で Warning（Tint だけで塗るなら無視して構いません）
AlbedoTintアルベドに掛ける色（既定: 白 = そのまま）。半透明にするときはここのアルファも使います
Normalノーマルマップの TextureData ID
NormalScaleノーマルの強度（既定 1）。凹凸を強くしたいときに上げる
Maskマスクテクスチャ（R: Metallic、G: Occlusion、B: Detail、A: Smoothness）の TextureData ID
MetallicMask が無いときの金属っぽさ（0〜1、既定 0）
SmoothnessMask が無いときのなめらかさ（0〜1、既定 0.5）。上げるとツヤが出ます
Emissionエミッション（自分で光る）テクスチャの TextureData ID
EmissionColorエミッションの色（既定: 黒）。EmissionIntensity を掛けた色で光ります
EmissionIntensityエミッションの強さ（0 で無効、既定 0）。Emission テクスチャも EmissionColor（黒以外）も無いと光らないので、検証で Warning
BlendOpaque（不透明）/ Cutout（アルファ抜き。Cutoff を使う）/ Transparent（半透明）。既定 Opaque
CutoffCutout のときのアルファしきい値（0〜1、既定 0.5）。これより薄い部分が抜けます
DoubleSidedON で裏面も描画（Cull Off）。布や葉など

Anims の使い方（常時アニメ）

Anims の 1 要素は「どのプロパティ（Property）を、どう動かすか（Channel）を、どんな形で（Value）」の 3 つです。

項目説明
Property対象のシェーダープロパティ名。Channel が Float なら数値プロパティ、OffsetU / OffsetV ならテクスチャプロパティ（例 _BaseMap）
ChannelFloat = 数値をそのまま動かす / OffsetU = テクスチャの UV オフセット X（横スクロール）/ OffsetV = UV オフセット Y（縦スクロール）
Value形とスピード（ValueDef）。Mode（Parametric / Curve）、Parametric（Ease の種類）、Curve、From / To、Time、Loop、LoopCount。Mode が Constant だと動かないので検証で Warning
  • UV スクロール: Channel = OffsetU、Parametric（Linear）、From 0 → To 1、Time = Rate、Loop = Loop
  • サイン波で揺らす: Channel = Float、Parametric（InOutSine）+ PingPong
  • 好きな波形: Channel = Float、Curve

設定項目（テクスチャデータ）

項目説明
Texture実体の画像（Texture2D）。未設定は検証で Error
UsageModel（3D モデル用、既定）/ UI（UI 用）。UI にすると Texture Type が Sprite になり、Sprite が未設定なら自動で割り当てられます
SpriteUsage = UI のときの Sprite。自動で入るので通常は触りません
AllowScale拡縮してよいか。ON なのに 9-slice（SliceBorder）が未設定だと検証で Warning
SliceBorder9-slice のボーダー（L, B, R, T の順、単位は元画像のピクセル）。切り抜き（トリミング）ではなく、伸ばしても崩れない「枠」の幅です。そのまま Unity の Sprite Border に書き込まれます
Channelこの画像をマテリアルのどの共通チャンネルに使うか。Albedo（素の色。sRGB on）/ Normal（Texture Type が NormalMap になる）/ Mask（sRGB off）/ Emission（sRGB on）/ Other（設定を変えない。Mask に詰め直す前の単チャンネル画像など、共通チャンネルに直接載せないもの）
9-slice とは: ボタンやウィンドウ枠のように、大きさを変えても角と縁が伸びてほしくない画像を、9 分割して「四隅は固定・辺は一方向だけ伸ばす・中央だけ両方向に伸ばす」仕組みです。SliceBorder に四隅の幅を入れるだけで、Unity 側の設定が自動で追従します。

テクスチャのファイル名規約（自動設定）

Assets/SourceAssets か Assets/GameData の下に画像を置くと、ファイル名の末尾を見て Unity の読み込み設定と、テクスチャデータを作るときのチャンネル / 用途が自動で決まります。大文字小文字は区別しません。上から順に最初に一致したルールだけが使われます。

ファイル名の末尾自動で決まる設定Channel / Usage
_Normal_DirectXNormalMap、緑（Y）を反転（DirectX 形式 → Unity 形式）Normal / Model
_Normal_OpenGL / _NormalMap / _Normal / _NNormalMapNormal / Model
_MaskMap / _MDefault、sRGB off、高品質圧縮Mask / Model
_MetallicSmoothness / _SpecularSmoothnessDefault、sRGB off、高品質圧縮Other / Model（Mask ではありません。下の注意点）
_Metallic / _Roughness / _Smoothness / _AmbientOcclusion / _Ambient_occlusion / _Occlusion / _AO / _Height / _OpacityDefault、sRGB offOther / Model
_BaseMap / _BaseColor / _Base_Color / _AlbedoTransparency / _Albedo / _DiffuseDefault、sRGB onAlbedo / Model
_Emission / _Emissive / _EDefault、sRGB onEmission / Model
_UISprite（FullRect）、sRGB on、Mipmap offOther / UI
T_ で始まる（先頭）Default、sRGB onAlbedo / Model

Model 用はすべて Mipmap on。UI 用だけ Mipmap off です。_Normal は _N より前に判定されるので、Xxx_Normal.png は Substance 用のルールに当たります。

ルールはプロジェクトの Texture Import Profile（Create > D-Drive > Material > Texture Import Profile）で変えられます。各ルールは「Name（ルール名）/ Match（末尾・先頭・部分一致）/ Pattern（照合する文字列）/ Type / SRgb / Mipmaps / Compression / MaxSize / SpriteFullRect / Channel / Usage / FlipGreenChannel」。プロファイル全体には Enabled、IncludePathContains（対象フォルダ）、ModelMaxSize（既定 2048。超えると検証で Warning）があります。既にプロファイルを作ってある場合、後から組み込みに追加されたルールは自動では入りません（Rules を作り直す必要があります）。

Substance Painter からの受け渡し

  1. 書き出し先を Assets/SourceAssets/<キャラ名>/ にする
  2. テンプレートは Unity URP / HDRP（_BaseMap / _MaskMap / _Normal / _Emission）が最も素直。Unity 5（_AlbedoTransparency / _MetallicSmoothness / _SpecularSmoothness）や PBR Metal Rough（_BaseColor / _Roughness / _Metallic / _Emissive / _Height / _AO）の標準名もそのまま上の表に当たります
  3. 法線は OpenGL 形式で書き出す。DirectX 形式で出すなら _Normal_DirectX の名前にすれば緑反転が自動でかかります
  4. インポートするだけで Texture Type・sRGB・圧縮が決まります。あとはテクスチャデータを作って（またはマテリアルデータの自動生成で）チャンネルに載せます
_MetallicSmoothness / _SpecularSmoothness（Unity 5 テンプレート）は Mask ではなく Other になります。この 2 枚は G（遮蔽）が 0 なので、そのまま Mask として使うと遮蔽 0 = 間接光が消えてしまいます。Mask として使うときは R: Metallic、G: Occlusion、B: Detail、A: Smoothness に詰め直した 1 枚を _MaskMap か _M の名前で用意してください。

Maya からの受け渡し（FBX → 自動生成）

  1. FBX を Assets/SourceAssets/<カテゴリ>/ に置く。カテゴリは FBX の親フォルダ名になります（例: SourceAssets/Player/Body.fbx → Player）
  2. インポートが終わると自動で走り、Console に [DDrive] Maya インポート: <パス> のレポートが出ます（末尾に「MaterialData 新規 N / 更新 N / 変更なし N、TextureData 新規 N」）。生成物は Assets/GameData/Material/<カテゴリ>/ と Assets/GameData/Texture/<カテゴリ>/
  3. 手動でやり直すときは FBX を選んで Tools > D-Drive > Generate > 選択したモデルから MaterialData を生成（FBX 以外を選んでいると「[DDrive] モデル(FBX 等)を Project で選択してから実行してください。」）
  4. Material Editor で Specific（Coat / Sheen 等）を調整。以後 FBX を差し替えても Common だけ更新され、Specific / Anims / Render 設定は保持されます（Console に「更新: <名前>(Common: …。Specific / Anims / Render は保持)」）
  • 写される内容: テクスチャは _BaseMap / _MainTex → Albedo、_BumpMap → Normal、_MetallicGlossMap / _MaskMap / _OcclusionMap → Mask、_EmissionMap → Emission。決まらないものはファイル名規約で分類。色は AlbedoTint、Metallic / Smoothness、EmissionColor、Cutoff、両面、半透明 / アルファ抜きも写されます。チャンネルが決まらない画像は「 スキップ: …(チャンネル未対応)」
  • シェーダーの決まり方: Maya Import Profile の TargetShader → 元が DDrive/ ならそのまま → それ以外は DDrive/Lit
  • aiStandardSurface（Arnold）を割り当てた FBX は、そのまま DDrive/AiStandardSurface のマテリアルデータになり、Coat / SpecularIOR などの固有も写されます。lambert / phong は DDrive/Lit。シェーダーが未インポートのときに FBX が入ると警告が出ますが、シェーダーが入った時点で自動再インポートされます
  • Maya Import Profile（Create > D-Drive > Material > Maya Import Profile）で AutoImport（OFF で自動生成しない）、IncludePathContains、TargetShader、CategoryFromFolder / FixedCategory（既定 Imported）、PropertyChannels、ClassifyByTextureName、PreserveSpecificOnReimport を変えられます

既存の Unity Material を D-Drive 化する

  1. Project で Material（または Renderer を持つ Prefab / モデル。複数選択可）を選ぶ
  2. Tools > D-Drive > Generate > 選択した Material を D-Drive/Lit・Unlit の MaterialData に変換
  3. Console に「[DDrive] Unity Material → D-Drive MaterialData: N 件」と出て、最後の 1 件が Project で選択されます
  • URP Lit / Simple Lit / Complex Lit / Baked Lit / Standard / Standard (Specular setup) → DDrive/Lit。URP Unlit / Unlit/Texture / Unlit/Color / Unlit/Transparent / Unlit/Transparent Cutout → DDrive/Unlit。それ以外は「警告: … 未対応のため DDrive/Lit として変換します」
  • カテゴリはアセットの親フォルダ名（取れなければ Migrated）。元 Material に同名の固有プロパティがあれば値もコピーされます
  • もう一度実行しても増えず、Common だけ更新されます（固有の調整は残る）。別フォルダの同名 .mat は別々のマテリアルデータになります

よくある使い方

やりたいこと設定
新しいマテリアルを 1 から作るCreate メニューで Material Data → Inspector の「Material Editor で開く」→ Shader に DDrive/Lit → Common の Albedo にテクスチャデータの ID、Metallic / Smoothness を調整 → サムネイルで確認
半透明にするCommon の Blend を Transparent。必要なら AlbedoTint のアルファを下げる。RenderQueueOffset は 0 のまま（基準 3000 が自動）
アルファ抜き（葉・フェンス）Blend を Cutout、Cutoff で抜ける濃さを調整。裏も見せるなら DoubleSided ON
光らせるEmissionColor を黒以外にして EmissionIntensity を 1 以上に。模様で光らせるなら Emission に _E のテクスチャデータ

UI 用の 9-slice 画像を登録する画像を Xxx_UI.png の名前で Assets/SourceAssets に置く → Texture Data を作って Texture を設定 → Usage = UI、AllowScale = ON、SliceBorder に L, B, R, T を入力。Sprite Border と Sprite が自動で追従
Substance の出力を取り込むUnity URP テンプレートで Assets/SourceAssets/<キャラ名>/ に書き出す。Unity 5 テンプレートなら Mask を詰め直した _MaskMap を別途用意

テクスチャデータの警告です。「修正」ボタンが付くものは押すだけで直ります。

表示対処
Texture が未設定(または Missing)ですTexture を設定（Error。これ以降の検査は打ち切り）
Usage=UI ですが Sprite が未生成です「修正」あり: Sprite(Single) にして再インポートし、Sprite を割り当て
AllowScale=true ですが SliceBorder(9-slice)が未設定ですSliceBorder を入れるか、AllowScale を OFF に（修正ボタンなし）
Channel=Normal ですが Texture Type が NormalMap になっていません「修正」あり: NormalMap にして再インポート
Channel=Mask ですが sRGB が on になっています「修正」あり: sRGB off にして再インポート
サイズが 2 のべき乗ではありません(…)元画像を 512 / 1024 / 2048 などのサイズに直す（Model 用のみ。修正ボタンなし）

Console に「[DDrive] TextureData '…': Usage/Channel から求まる Texture Type(…)がファイル名規約 '…'(…)と食い違うため適用しません。ファイル名か Data のどちらかを合わせてください」と出たら、ファイル名の規約とテクスチャデータの設定が矛盾しています。この状態ではデータ側の設定は書き込まれません（次のインポートで規約に戻されて打ち消し合うため）。ファイル名を変えるか、Channel / Usage を規約に合わせてください。

注意点

  • Specific に共通チャンネル名（_BaseMap や _Metallic など）が入ると、Common の値が黙って上書きされます。値は消えませんが、Common を変えても見た目が変わらなくなります。検証の Warning を見たら Material Editor の「共通チャンネルの重複を削除」で取り除いてください
  • プレビューが真っピンク（マゼンタ）なら、テクスチャデータの ID 参照が切れているか未登録です
  • Shader 未設定のときの既定は URP Lit で、DDrive/Lit ではありません。DDrive/Lit の固有は _OcclusionStrength のみ、DDrive/Unlit は固有なしです
  • 半透明マテリアルのサムネイル / アイコンに穴が開く問題は 2026-09-11 に修正済みですが、それ以前に作った古いアイコン PNG は作り直しが必要です（Tools > D-Drive > Generate > 初期アイコンを生成(未設定の Data のみ) は未設定のものだけが対象）
  • 2026-09-11 より前に作られた aiStandardSurface 由来のマテリアルは Metalness / Roughness / SpecColor / Opacity マップが効きません。FBX を再インポートすれば直ります。Shader が None のままの Maya 由来データも、再インポートで自動設定されます
  • Maya インポート直後にプレビューが灰色（テクスチャ無し）になったら、Material Editor を開き直すか「再生成」を押してください
  • UsedInCanvas / UsedInModels（どこで使われているかの一覧）、Skybox の切替は未実装です
