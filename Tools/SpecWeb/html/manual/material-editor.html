Material Editor の使い方（プレビュー・シェーダー変換）

Material Editor は、マテリアルデータ / テクスチャデータを球のサムネイルで見ながら編集するウィンドウです。値を変えると 0.1 秒ほどでサムネイルが描き直され、開いているシーンにプレビューを置けば実際の照明でも確認できます。

  • Inspector と同じ内容を編集できるうえ、サムネイル・シーン配置・2 つのマテリアルの見比べができます
  • シェーダーを設定すると、そのシェーダー固有のパラメータ（Specific）を既定値で自動登録します
  • 別ウィンドウとして「Material 変換」（シェーダーの乗り換え）と「Material プレビュー」（サムネイルだけのポップアップ）があります

開き方

  1. マテリアルデータを Project で選び、Inspector の一番上のボタンを押す。マテリアルデータには「Material Editor で開く」「プレビューをポップアップ」「シェーダー変換」の 3 つ、テクスチャデータには「Material Editor で開く」だけが出ます
  2. またはメニューバー Tools > D-Drive > Editors > Material（Material Editor）/ Tools > D-Drive > Editors > Material 変換 / Tools > D-Drive > Editors > Material プレビュー。Project で選択中のマテリアルデータがそのまま対象になります

はじめの一歩（マテリアルを作ってシーンで確かめる）

  1. Project の右クリック Create > D-Drive > Material > Material Data（または Asset Browser の「新規」で種別 Material）で作る
  2. Inspector の「Material Editor で開く」を押す。ウィンドウ上部に灰色の球のサムネイルが出ます
  3. 設定の Shader に DDrive/Lit を入れる。Specific に _OcclusionStrength が既定値で自動追加され、ラベルに「固有: 追加 1 …」と出ます
  4. Common の Albedo にテクスチャデータの ID、Metallic / Smoothness を動かしてサムネイルで確認。サムネイルをドラッグすると回転します（横 = 回す、縦 = 傾ける）
  5. 「シーンにプレビューを配置」を押す → 今開いているシーンの SceneView カメラの前に球が置かれ、実際の照明で見えます。Hierarchy に [D-Drive] Material Preview が出ますが、シーンには保存されません
  6. 確認できたら「撤去」。使いたいモデルへの割り当ては Model Editor で行います
サムネイルは「既定ライトのみ」（決まった 2 灯 + 環境光）です。実際のシーンの照明・反射・ポストプロセスでどう見えるかは「シーンにプレビューを配置」で確認してください。

画面の説明（Material Editor）

要素説明
対象 / 🔒編集するマテリアルデータかテクスチャデータ。それ以外を入れても弾かれます。🔒（選択に追従しない）を ON にすると、Project で別のものを選んでも対象が変わりません
サムネイルマテリアルデータのときだけ表示。画像そのものが操作対象で、ドラッグで回転（横 = Y 軸、縦 = 傾き）。傾きは ±80° で止まります。形状が板（Plane）のときは縦ドラッグで傾かず、平面のまま回るだけです。キャプションは「A: 表示名」（比較中は「B: 表示名」も）
「左右」/「切替」比較対象が入っているときだけ出るボタン。ラベルは今のモードで、押すと切り替わります。左右 = 2 分割で並べる / 切替 = 1 枚を A と B で切り替える
「A → B」/「B → A」切替モードのときだけ表示。表示する方を切り替えます（A = 対象、B = 比較対象）
「X 反転」/「Y 反転」横ドラッグの回転方向 / 縦ドラッグの傾き方向を逆にします。好みに合わせて。設定は Material Editor・ポップアップ・変換ウィンドウで共通で、Unity を再起動しても残ります
「ポップアップ」サムネイルを独立したウィンドウ（Material プレビュー）に出します。形状・回転・ライトの設定を引き継ぎます
説明ラベル「サムネイル: 既定ライトのみ(…)」など、今のプレビュー条件。形状が Model のときは「Model 形状はサムネイルに出しません。「シーンにプレビューを配置」で確認してください」
「プレビュー」Foldout下の「プレビューの設定」を参照。既定で開いています
「シーンにプレビューを配置」開いているシーンに選んだ形状を置き、生成した共有 Material を適用します。置くたびに SceneView カメラの前（2〜10 m）へ移動し、SceneView がそこにフレームインします。確認用シーンは開きません（Model Editor などと違い、今のシーンにそのまま置きます）
「再生成」データの変更を共有 Material に反映し直します（比較用も含む）。普段は自動ですが、プレビューが灰色になったときなどに
「撤去」置いたプレビューを消します。ライト回転で動かした Directional Light も元に戻ります
ステータス行「「シーンにプレビューを配置」で確認できます」「プレビューに適用中」「プレビューに適用中(比較対象あり)」など今の状態。「プレビューの生成に失敗しました(ModelData の Prefab を確認してください)」が出たら、プレビュー用モデルの Prefab を確認
Specific 操作行マテリアルデータのときだけ。下の「Specific 操作行」を参照
設定Inspector と同じ項目。内容は マテリアル / テクスチャの設定項目

Specific 操作行

要素説明
「シェーダーから固有を同期」シェーダーの固有プロパティ（共通チャンネルに当たらないもの）を既定値で Specific に追加します。既にある値は保持。Shader を変えたときは自動でも走るので、押すのは「未登録の固有 N 件」と出ているときだけで十分です
「共通チャンネルの重複を削除」Specific に紛れ込んだ共通チャンネル名（_BaseMap や _Metallic など）や描画ステート名を取り除きます。そのままだと Common の値を上書きしてしまいます。重複が 1 件以上あるときだけ表示されます
ラベル「Shader 未設定(既定の Lit で生成)」/「固有 N 件(シェーダーと同期済み)」/「未登録の固有 N 件: _Xxx, _Yyy」/ 末尾の「 / Common を上書きする項目 N 件」。同期直後は「固有: 追加 N / 保持 N / シェーダーに無い N」と内訳が出ます

テクスチャデータを選んだとき

  • サムネイルの代わりに画像プレビューが出て、ステータス行に「640×640 Channel=Albedo」のようにサイズとチャンネルが出ます（画像が無いときは「Texture が未設定です」）
  • Importer の要約ラベル: 「Texture Type: … sRGB: … Mipmap: … 圧縮: … Max Size: …」と、次の行に「規約: <ルール名>」または「規約に該当なし」。Importer が取れない画像は「Importer 情報なし(メモリ上のテクスチャ)」
  • 「命名規約を適用して再インポート」ボタンは、ファイル名規約と今の Importer 設定が食い違っているときだけ表示されます。押すと規約どおりに直して再インポートし、「命名規約 '…' を適用しました」と出ます

Material 変換ウィンドウ（シェーダーの乗り換え）

Inspector の「シェーダー変換」か Tools > D-Drive > Editors > Material 変換 で開きます。共通チャンネル（Albedo / Normal / Mask / Emission / Blend）はそのまま維持し、固有パラメータだけを付け替えます。

要素説明
変換元 MaterialData / 変換先 Shader乗り換えたいデータと、乗り換え先のシェーダー。変換先を選ぶと下に結果が出ます
「変換テーブルを再読み込み」プロジェクト内の Shader Conversion Table（固有の対応表）を集め直します。テーブルを作った・直した後に押します
「見た目の比較(A = 変換前 / B = 変換後)」FoldoutA と B の 2 枚のサムネイル。B はアセットを作る前のメモリ上の変換結果です。「左右」/「切替」、「A → B」/「B → A」、形状（Model は選べません）、「回転」、「ライト」（0〜360）、「X 反転」/「Y 反転」は Material Editor と同じ操作。回転・ライトは A / B 共通、既定ライトのみ。キャプションは「A: 変換前 (DDrive/Lit)」「B: 変換後 (DDrive/Unlit)」のようにシェーダー名付き
サマリ行「<変換元> → <変換先>」と「共通データ(…)はそのまま維持。固有: 対応 N / 維持 N / 破棄 N / 意図的に破棄 N」。末尾の「(変換テーブル使用)」はテーブルが見つかった印、「(この組の変換テーブル無し。N 件の Table を確認)」はテーブルなしで同名維持だけが働いている印
互換表列は「名前 / 型 / 値 / 互換 / 備考」。3 つの節に分かれます（下の「互換表の読み方」）
「新規 MaterialData として作成」変換元は変えずに、同じカテゴリへ変換後のデータを新しく作ります。表示名は「<元の名前> (<シェーダー名>)」。作成後に Project で選択されます。元を残して試したいときはこちら
「この Data を変換(Undo 可)」変換元の Shader と Specific を書き換えます。Ctrl+Z で戻せます。変換元と変換先が同じシェーダーのときは押せません

互換表の読み方

節印
共通チャンネル（MaterialCommon。そのまま引き継ぐ）〇 = 変換先に受け口がある（備考「→ _BaseMap / _MainTex」など）/ × = 変換先に受け口が無く無視される（例: Unlit に Normal や Mask は無い）/ － = 元で未設定（備考「未設定(変換先: …)」「未設定(変換先に受け口無し)」）
固有パラメータ（Specific）→ = テーブルで対応先に写す / = = 同名・同型で維持 / × = 破棄（備考「テーブルで意図的に破棄」または「変換先に無いため破棄」）。何も無ければ「変換元に固有パラメータがありません」
変換先で新しく追加される固有変換元に無く、シェーダーの既定値で登録されるもの（備考「既定値で追加」）。無ければ「変換先シェーダーに追加の固有パラメータはありません」
残したい固有が「×」になるときは、Create > D-Drive > Material > Shader Conversion Table でテーブルを作り、Rules に From（変換元）/ To（変換先）と Mappings（FromProperty → ToProperty。Float / Int は Scale と Offset で値の変換も可。ToProperty を空にすると「意図的に破棄」で警告が出なくなります）を書いて「変換テーブルを再読み込み」。同じ From / To の組は最初の 1 件だけが使われます。

変換元を Inspector で編集したり Ctrl+Z で戻したりすると、A も B も自動で作り直されます。

Material プレビュー（ポップアップ）

サムネイルだけを独立したウィンドウに出したものです。Inspector の「プレビューをポップアップ」、Material Editor の「ポップアップ」、または Tools > D-Drive > Editors > Material プレビュー で開きます。タイトルは対象があると「Material: <表示名>」になります。

  • ツールバー: 対象（ObjectField）と 🔒（選択に追従しない）、形状（Model は選べません）、「回転」、「ライト」（0〜360）、「X 反転」/「Y 反転」
  • 画像はウィンドウいっぱいに出て、ドラッグで回転します。ウィンドウを広げれば大きく見えます
  • ステータス: 「<シェーダー名> <形状> 既定ライトのみ(…)」。Shader 未設定なら「(既定 Lit)」
  • Material Editor を閉じても単独で動き、Inspector での編集・Undo・Material Editor からの変更にすべて追従します。並べて置いて、Inspector で値をいじりながら見るのに便利です

Undo とキーボード

  • 設定の編集は Inspector と同じ仕組みなので、Ctrl+Z / Ctrl+Y がそのまま効きます
  • 「シェーダーから固有を同期」「共通チャンネルの重複を削除」「この Data を変換(Undo 可)」はそれぞれ 1 手で戻せます
  • 値を変えると 0.1 秒間隔で共有 Material が作り直され、サムネイルと置いたプレビューに反映されます。サムネイルの描き直しは最大 30 fps
  • 対象・🔒・形状・比較対象・比較モード・回転 / 傾き / ライト角・ターンテーブルは、スクリプトの再コンパイルをまたいでも保持されます

よくある使い方

やりたいこと操作
2 つのマテリアルを見比べる「プレビュー」の「比較対象」に別のマテリアルデータ → サムネイルが「左右」で 2 分割。「切替」にして「A → B」で同じ位置でパッと切り替えても分かりやすい。実照明で見たいときは「並べて比較」でシーンに 2 体並べる
モデルに貼った状態で見る形状を Model、「プレビュー用モデル」にモデルデータ →「シーンにプレビューを配置」。サムネイルには出ません
UV スクロールが動いているか見るAnims を設定するとサムネイルと SceneView の両方で、再生ボタンを押さなくても（EditMode のまま）動きます
光の当たり方を変えて見る「ライト回転」を動かす。シーンに置いていれば Directional Light も一緒に回り、「撤去」で元に戻ります
Lit から Unlit に乗り換えるInspector の「シェーダー変換」→ 変換先に DDrive/Unlit → 互換表で Normal / Mask / Emission が × になるのを確認 → 見た目の比較で許容できるか判断 → 「新規 MaterialData として作成」か「この Data を変換(Undo 可)」
URP Lit のままのデータを DDrive/Lit にする「シェーダー変換」で変換先に DDrive/Lit。プロパティ名が同じなので固有は同名維持、テーブルは不要
Maya から来たデータの Shader が NoneMaterial Editor で Shader に DDrive/AiStandardSurface か DDrive/Lit を設定（固有は自動同期）。FBX を再インポートしても自動設定されます
テクスチャの読み込み設定が規約とずれているテクスチャデータを Material Editor で開き、「命名規約を適用して再インポート」を押す

注意点

  • サムネイル・ポップアップ・変換ウィンドウの比較はすべて「既定ライトのみ」（決まった 2 灯 + 環境光）です。実際のシーンの照明・反射・ポストプロセス・モデルのスロット適用は「シーンにプレビューを配置」で確認してください
  • 「シーンにプレビューを配置」は確認用シーンを開かず、今開いているシーンに置きます。置いたものは [D-Drive] Material Preview の下にまとまり、シーンには保存されません
  • Model 形状はサムネイルに出ません。ポップアップと変換ウィンドウでは Model を選ぶこと自体できません（選ぼうとすると元に戻ります）
  • 板（Plane）は裏を向かないよう、縦ドラッグで傾きません
  • プレビューが真っピンクならテクスチャデータの ID 参照が切れています。灰色（テクスチャ無し）なら開き直すか「再生成」
  • Specific に共通チャンネル名が入っていると Common の値が黙って上書きされます。「共通チャンネルの重複を削除」ボタンが出ていたら押してください（検証側には修正ボタンがありません）
  • 半透明マテリアルのサムネイル / アイコンに穴が開く問題は 2026-09-11 に修正済みです。それより前に作ったアイコン PNG は作り直しが必要です
