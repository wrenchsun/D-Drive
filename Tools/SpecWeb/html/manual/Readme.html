D-Drive デザイナーマニュアル

このマニュアルは、D-Drive（Designer-Driven Re: IDE Visual Environment、このプロジェクトのアセット管理システム）をデザイナーが使うためのガイドです。プログラムの知識は必要ありません。

D-Drive とは？（30秒で分かる説明)

ゲームで使う音・エフェクトなどの素材を、「ID（番号札）」で管理する仕組みです。現在は効果音・BGM・エフェクト（VFX）・出す位置（Anchor / 配置セット）・モデル・3D アニメーション・2D アニメーション（スプライト）・マテリアル / テクスチャ・Prefab（ゲーム中に出す物）・Canvas（UI 画面）・UI の動き（UI Tween）・ボタン / スライダーの見た目（Skin）・演出（Presentation）・画面の揺れ / コントローラーの振動に対応しています。

  • プログラマーは「この場面でこの番号札の音を鳴らす」とだけ書きます
  • デザイナーのあなたは「その番号札の中身（どんな音か、どのくらいの音量か）」を自由に作り込みます
  • お互いの作業がぶつからないので、後から音を差し替えても、プログラムの修正は不要です
大事な考え方: ファイル名はあなたが決める必要はありません。「表示名（日本語OK）」と「カテゴリ」などを入力すれば、ツールが自動で規則どおりのファイル名を付けてくれます。ファイル名を気にせず、中身づくりに集中してください。
共通の入口: Project で D-Drive のデータ（効果音・BGM・VFX・モデル・アニメーション・Anchor・配置セット・マテリアル・テクスチャ・Prefab・Canvas・Skin・UI Tween・演出・画面の揺れ・振動）を選ぶと、Inspector の一番上に「▶ 〜 Editor で開く」ボタンが出ます。迷ったらこれを押せば、そのデータ用の専用エディタが開きます（マテリアルのように、ボタンが 2〜3 個並ぶものもあります）。多くの専用エディタのツールバーには 「＋ 新規作成」 ボタンもあり、Asset Browser を開かずにその場で新しいデータを作れます（詳しくはAsset Browser の使い方）。
アイコン: 同じ場所に「自動生成」「フォルダから選択」「シーンから作成」「クリア」があります。Prefab や画像を持つデータ（モデル・VFX・Prefab・Canvas・テクスチャ・Skin）とマテリアルは、「自動生成」を押すだけで見た目からアイコンが作られます（作成直後にも自動で試みます）。効果音・BGM・アニメーション・Anchor のように絵の元が無い種類ではこのボタンは押せません。SceneView で良い角度に映してから「シーンから作成」を押すと、シーン全体の写真からドラッグで四角く切り取ってアイコンにできます。画像は Assets/GameData/Icons/<種別>/ に自動で保存され、Inspector に加えて Asset Browser の一覧行・Project ウィンドウのサムネイル（グリッド表示）にも同じ画像が出ます（2026-09-14 から。未設定のアセットは Unity 既定のサムネイルのままです）。
このマニュアルを Unity から開く（2026-09-14 追加）: Unity 画面上部、再生ボタン（▶）のすぐ右にある「マニュアル」ボタンを押すと、このページがブラウザで開きます。横のドロップダウンから他のページも選べます。
ボタンが見当たらないとき: 最初は隠れています。画面上部のツールバーの何もない所を右クリックし、「D-Drive/Manual」にチェックを入れると表示されます（1 回だけでよい）。メニューの Tools → D-Drive → マニュアルを開く からも開けます。

ページ一覧

  • Asset Browser の使い方

    すべての入口になるウィンドウ。素材の一覧・検索・新規作成はここから。まず最初に読んでください。

  • Validation（自動チェック）の使い方

    設定ミス・登録漏れをまとめて見つけて、「修正」ボタンで直す。赤い表示が出たらまずここ。

  • SE（効果音）の設定項目

    効果音データの全パラメータの説明。音量・ピッチ・3D設定・連打防止など。

  • BGM の設定項目

    BGMデータの全パラメータの説明。イントロ→ループ構成・フェードなど。

  • Audio Editor の使い方

    波形を見ながらの音の切り出し（トリミング）、試聴、3Dサウンドの確認。

  • シーンに環境音を置く（SeEmitter）

    滝や焚き火などの「その場所で鳴り続ける音」の配置方法。

  • VFX（エフェクト）の設定項目

    エフェクトデータの全パラメータの説明。寿命・描画・出す位置（Anchor）・公開パラメータ。

  • VFX Editor の使い方

    シーンの中で再生しながら位置・色を調整。Prefab の中で ParticleSystem を編集しながらの確認も。

  • Anchor（出す位置）の作り方

    エフェクト・効果音を「どこに・いつ・どう出すか」をデータにして使い回す。ボーン基準、ランダム、ディレイ、入れ子。

  • 配置セット（複数の場所にまとめて出す）

    格子・円・一列・ランダムのパターンで点を並べ、全点にエフェクト / 効果音をまとめて出す。特定の点だけ変える、入れ子も。

  • モデルの設定と Model Editor

    キャラクター / 物体の Prefab を登録し、確認用シーンで回して見る。マテリアルのスロット、出した瞬間に再生するアニメーション。

  • アニメーション（3D）の設定と Anim Editor

    モデルを動かしながら「何フレーム目で音・エフェクト」を決める。Animator のステートから選んで作る、音の波形を見ながら調整、一時停止、繰り返し設定、ブレンド確認。

  • 2D アニメーション（スプライト）の作成と Anim2D Editor

    スプライトシートを切り分けてコマアニメにする。自動検出、8 方向、コマ間隔の調整（リタイミング）。音・エフェクトは Anim Editor と共通。

  • マテリアル / テクスチャの設定項目

    色・凹凸・金属感・発光などの「表面の質感」と画像の管理。ファイル名のルールで自動設定、Maya / Substance からの受け渡し。

  • Material Editor の使い方（プレビュー・シェーダー変換）

    球や板に貼って回しながら確認、2 つを見比べる、シーンに置く、シェーダーの乗り換え。

  • Prefab データ（ゲーム中に出す物）の設定と Prefab Editor

    弾・ギミック・拾い物などを ID で登録。使い回し（プール）の設定、出現時の音・エフェクト。

  • Canvas（UI 画面）データの設定項目

    メニューやダイアログ 1 画面分の設定。レイヤー、開閉の演出、ボタンを押したら何が起きるか（配線）、パッドのフォーカス移動。

  • Canvas Editor の使い方（ナビゲーション・演出・プレビュー）

    フォーカスのつながりを線で描く、要素ごとの出現 / 常時 / 消滅演出、パッド操作のシミュレーション。

  • ボタン / スライダーの見た目（Skin）と Slider Editor

    通常・ホバー・押下・無効などの状態ごとの色・大きさ・音。スライダーの応答曲線と目盛り（ノッチ）。

  • UI の動き（UI Tween）・プリセットギャラリー・要素演出（ElementFx）

    フェード・スライド・跳ねるなどの動きを作る、59 種類のプリセットから選んで当てる、音量などの標準オプションと直結。

  • 演出（Presentation）の設定項目

    「剣攻撃」のようにアニメ・SE・VFX・カメラ揺れなどをまとめて 1 つの演出にする機能。専用の Presentation Editor でタイムライン編集 + 統合プレビューができます。

  • 画面の揺れ・コントローラーの振動

    画面をガクガク揺らす（カメラシェイク）・パッドをブルブル振動させる（ハプティクス）データの作り方。専用の Shake / Haptics Editor で波形を見ながら調整・実際に揺らして/振動させて確認できます。

  • 仕様書との同期

    企画がスプレッドシートに書いた行を D-Drive の空データに変換する。担当・状態の反映、調整値のコード連携、仕様書リンクも。

  • 用語集

    「アセット」「ピッチ」「Mixer」「Skin」「Tween」など、分からない言葉が出てきたらここ。

はじめの一歩（効果音を1つ登録してみる）

  1. Unity のメニューバーから Tools > D-Drive > Asset Browser を開く
  2. Project ウィンドウから音声ファイル（.wav など）を Asset Browser の上にドラッグ＆ドロップ（ドラッグ＆ドロップで登録できるのは音声ファイルだけです。他の種類は「新規」ボタンから作ります）
  3. 開いたダイアログに「表示名」（例: 剣の斬撃音）と「識別子」（例: SwordSlash ※英語）を入力して「作成」
  4. 一覧に追加された音を選び、下の ▶ 再生 ボタンで試聴

これだけで登録完了です。詳しくは Asset Browser の使い方 へ。エフェクトを「どこに出すか」を決める練習は Anchor（出す位置）の作り方 の「はじめの一歩」へ。

困ったときは

  • ウィンドウが見つからない → メニューバーの Tools > D-Drive の下にすべてまとまっています。専用エディタは Editors、一括処理は Generate、自動チェックは Validation
  • 赤い表示が出ている → 何かの設定が足りていません。マウスを乗せると説明が出ます（各ページの「よくある警告」と Validation の使い方 を参照）
  • ゲームで出てこない・ピンク色になる → 登録漏れの可能性。Validation の「Run All」で「未登録」が出たら「修正」を押します
  • 言葉が分からない → 用語集
