UI の動き(UI Tween)・プリセットギャラリー・要素演出(ElementFx)

最終更新日: 2026-10-13

UI の「出る・消える・ふわふわ揺れる・押したら跳ねる」といった動きを、プログラムを書かずに付けるための 3 つの道具です。

  • プリセットギャラリー: 組み込みの 59 種類の定番演出（出現・常時・消滅・強調）をカードで選び、お気に入りに入れ、シーン上で動かし、Canvas の要素に割り当てる窓口。まずはここから
  • UI Tween Editor: プリセットで足りない凝った動きを、自分でデータ（UI Tween）として作るウィンドウ。トラック 1 本 = 1 行で、時間バーをドラッグして開始と長さを決め、シーン上の実要素で動かして確かめます。Tween（トゥイーン）= 「ある値からある値まで、決めた形で何秒かけて変える」動きのこと
  • 要素演出（ElementFx）: Canvas を開いたとき（Appear）・表示中（Idle）・閉じるとき（Disappear）に、要素ごとにどの動きを使うかの割り当て
ボタンを押した瞬間の演出は Skin の Enter Tween / Enter Preset に指します。このページの演出は「画面（Canvas）の開閉と表示中」のものです。

対象のデータを選んでいない（空の）ときは、ウィンドウの「サンプルを作る」ボタンでサンプルのデータを作って試せます（Assets/GameData/<種別>/Sample/ にカテゴリ Sample で作られます。同じものが既にあれば、作らずそれを選びます）。

UI Tween Editor

開き方

  1. Asset Browser の「新規」ボタンで種別に UiTween を選んで作る（接頭辞 UITWEEN、UiTween フォルダに置かれます）
  2. Project で UI Tween を選び、Inspector の一番上の「▶ UI Tween Editor で開く」
  3. またはメニューバー Tools > D-Drive > Editors > UI Tween
  4. Canvas Editor の ElementFx 行の「✎ Tween Editor」、Skin の Enter Tween の編集ボタンからも開きます。そのときは、その要素が自動で「確認する」の対象に選ばれた状態になります

設定は、やりたいことごとの「カード」に並びます。上の「かんたん / 標準 / 詳細」で表示する欄の量を切り替え（かんたん = 雛形とトラックの一覧だけ）、右上の検索で設定を探せます（トラックの中身〔項目名・イージング・ループなど〕も検索に一致します）。ウィンドウ下の固定バーに ▶ 再生 / ■ 停止 / リピート / 速度 / 変更 N 件 / 自動保存 / 保存 があります。

はじめの一歩（滑り込みながらフェードイン）

  1. UI Tween を新規作成して UI Tween Editor で開く（ヒーローの「＋ 新規」でも作れます）
  2. 「確認する」カードの「確認用シーンに配置」→ 開いているシーンに [D-Drive] UI Tween Preview という Canvas と 200×80 の画像が置かれます（シーンには保存されず、エディタを閉じたとき・別のシーンに移ったときに自動で片付きます）
  3. 「雛形から始める」で SlideFadeInLeft を選び「置き換え」→ トラックの一覧に位置と透明度の 2 行が並びます
  4. 固定バーの「▶ 再生」→ Game / Scene ビューで画像が左から滑り込みながら現れます
  5. 行のバーをドラッグして開始や長さを変え、⚙ で秒数（Motion の Time）や移動量（開始値）を直して、もう一度 ▶ 再生
  6. 気に入ったら、Canvas Editor かプリセットギャラリーで要素の Appear に割り当てます

雛形から始める

出現・消滅・常時・強調の定番プリセット（組み込み 59 種）と、プロジェクトのカタログに登録した演出から選んで、Tracks に入れます。数値はたたき台なので、あとでトラックの行で調整してください。

要素説明
タブ / 検索出現 / 常時 / 消滅 / 強調 / カタログ / ★ お気に入り（全タブからお気に入りだけを集める）。検索欄はプリセット名の部分一致。お気に入りはギャラリーと共通です
プリセットのボタン押すと選択（青）。★ が付いているものはお気に入り。カタログのものは、マウスを乗せると Track の本数が出ます
置き換えいまの Tracks を丸ごと、選んだプリセットに入れ替えます（Ctrl+Z 可）。カタログ側の Tween に Tracks が無いと「カタログの Tween に Tracks がありません」
＋ 追加いまの Tracks を残したまま、選んだプリセットの Track を末尾に足します。スライドイン + フェードインのように、複数のプリセットや手動のトラックを組み合わせたいときに使います。1 つの Tween の Track 上限（8 本）に達すると「Track が上限(8 本)に達しているため追加できません」
☆ お気に入り選んだプリセットをお気に入りに入れる / 外す
ギャラリーを開くプリセットのカード一覧（曲線の形・シーン上での再生・Canvas の要素への適用）を別ウィンドウで開きます。いま編集中の Tween はギャラリーの「編集中の Tween」に入ります
プリセットとして保存いまの Tween を、選んだカタログに名前付きで登録します（同名なら上書き）。登録先カタログ / 元になる UiTweenData / 表示名 / カテゴリ（任意）を入れて「登録する」。登録するとカタログのタブと「雛形」に出ます。未入力だと「カタログ・UiTweenData・表示名を指定してください」
対象の要素が決まっていないときは、仮の 200×80 の大きさを基準に移動量などが計算されます。実物の大きさに合わせたいときは、先に「確認する」で実要素を選んでから置き換え / 追加してください。

トラック

同時に動く項目の一覧です。1 行 = 1 トラックで、1 つの Tween に最大 8 本まで（9 本目以降は再生されず、行と欄の下に警告が出ます）。

要素説明
＋ トラック動かす項目（位置 / 拡縮 / 回転 / 透明度 / 色 / サイズ / 塗り量 / 経路移動 / 回転 X・Y / 色相）を選んで 1 本足します。足したトラックの ⚙ が開きます
絞り込み・件数一覧の上に、検索・すべて / ループ / 1 回だけ・種類（位置 / 拡縮・サイズ / 回転 / 透明度 / 色 / 塗り）のチップ、「14 トラック中 ループ 3」のような件数。20 行を超えると一覧は仮想化されたリスト（ListView）になります
1 行目番号 → 種類のチップ → 項目名 → 時間バー → ▶ ↺ ⚙ ×
2 行目「開始 → 終了 · 長さ · イージング · 遅れ · ループ」の要約（例: 「×0 → ×1 · 0.35 秒 · OutBack · 0.1 秒遅れ」）
時間バーバーの長さ = トラックの長さ、左の点線 = 開始の遅れ、バーの中の線 = イージングの形。バーをドラッグすると開始（Delay）が、右端のつまみをドラッグすると長さ（Motion の Time。「秒」で指定しているとき）が変わります（0.05 秒刻み、Shift で 0.25 秒刻み。ドラッグ 1 回 = Undo 1 回）。ループは 2 周目以降が薄く続き、無限ループは右端に ▶ が付きます。軸は全トラックで共通です
▶そのトラックだけを、「確認する」で選んだ要素で再生します
↺そのトラックを既定値に戻します（項目は残す。Ctrl+Z 可）
⚙その行だけを開いて、すべての欄を出します（下の表）
×そのトラックを削除します（Ctrl+Z 可）

⚙ を開くと出る欄:

欄説明
項目（Property）動かすもの。変えると、開始値 / 終了値の型（位置は 2 つの数、拡縮は 3 つの数、色は色…）も合わせます
動き（Motion）形（イージング / ベジェ / カーブ）+ 秒数 + 繰り返し（下の「Motion の読み方」）
開始の遅れ（Delay）再生開始からこの秒数だけ遅らせて始める
開始値の決め方（From）Current = いまの値から / Absolute = 開始値そのまま / Relative = いまの値 + 開始値 / OffScreen = 画面外から（位置のみ）
画面外の方向（OffScreen）From = OffScreen のときだけ出ます（Left / Right / Top / Bottom）
開始値 / 終了値項目に合わせた入力欄（位置・サイズ = X と Y、拡縮 = X・Y・Z、回転・透明度・塗り・色相 = 数、色 = 色）。開始値は From が Absolute / Relative のときだけ、終了値は From が OffScreen でないとき（経路移動以外）だけ出ます
経路（Path）項目 = 経路移動のときだけ出ます。種類（スプラインの形）と制御点（要素のローカル座標）。「＋点を追加」「−最後の点を削除」。このウィンドウがフォーカス中は、SceneView 上の P0 / P1 … のハンドルをドラッグして経路を描けます（2 点以上で水色の線。Ctrl+Z 可）。ハンドルは「確認する」で選んだ要素が基準です
⧉ 複製 / ↑ 上へ / ↓ 下へ直後に同じトラックを足す / 並びを入れ替える（並びは見た目だけで、再生には影響しません）

全体の長さ

0 = 自動（いちばん遅く終わるトラックまで）。手で入れると、最長トラックより短いときに警告が出ます。

確認する

シーン上の実際の要素（Canvas のパネルやボタンなど）か、確認用シーンの仮画像を対象にして、実際に動かして確かめます。固定バーの「▶ 再生」は Tween 全体を、トラックの「▶」はそのトラックだけを動かします。リピートにすると終わったら自動でもう一度、速度で再生の速さを変えられます。

要素説明
収集元要素を集めたいシーン上のオブジェクト（例: Canvas Editor の「確認用シーン」で出た [D-Drive] Canvas Preview の中身）。Canvas Editor の ElementFx 行の「✎ Tween Editor」から開いたときは自動で入ります
要素を自動収集収集元の下にある RectTransform をすべて一覧にします（ルート自身も「(ルート)」として候補に入ります。同名の兄弟は「Button #2」のように番号が付きます）。パスの表記は CanvasData の ElementPath と同じ形式です
要素収集した中から実際に動かしたいものを選びます。選ぶと即座に対象になります（「プレビュー対象: パス名」と表示）
確認用シーンに配置 / 撤去[D-Drive] UI Tween Preview Canvas と 200×80 の画像を置く / 消す。右クリックで「このシーンに配置」「このシーンに本配置」も選べます。撤去は自分で置いた仮画像だけを消し、収集した実要素には触れません
状態の表示「再生中」「完了(再生前の状態に戻しました)」「プレビュー対象がありません(…)」など
収集元にドラッグできるのはシーン上のオブジェクトだけです（Prefab アセットは不可。「Prefab アセットは再生対象にできません」）。実要素で再生しても、止めたとき・再生し終わったとき・対象を切り替えたとき・ウィンドウを閉じたときに位置・大きさ・拡大率・回転・透明度・色・Fill の量が再生前に戻ります（再生のために自動で付いた CanvasGroup も外れます）。シーンに変更は残らないので Undo も不要です。再生中にもう一度「▶ 再生」を押すと、前の再生を止めて最初からやり直します。

管理情報

表示名・カテゴリ（一覧に出る名前と分類）、説明・タグ・アイコン・担当者・仕様書 URL・変更メモ、動作の取り決め（Flags）、きっかけで鳴らす・出す（イベント）。Id・版数・最終更新者・最終更新日時は読み取り専用です。保存は「保存」ボタン、Ctrl+S、または「自動保存」（編集して 1 秒後）。未保存のまま別の Data へ切り替える・閉じるときは確認が出ます。

設定項目

項目説明
Tracks同時に走るトラックの一覧（1 つの Tween に最大 8 本）。トラック 1 本 = 「どのプロパティを・どんな形で・何秒で・どこからどこまで」
Total Duration全体の長さ。0 = 自動（いちばん遅く終わるトラックに合わせる）。手で入れると、最長トラックとのズレを警告します
Track: Property動かすもの。AnchoredPosition（位置）/ Scale（拡大率）/ Rotation（Z 回転）/ Alpha（透明度。CanvasGroup が無ければ自動で付く）/ Color（画像や文字の色）/ FillAmount（Image の Filled の量）/ SizeDelta（大きさ）/ PathMove（経路に沿って移動）/ RotationX・RotationY（縦 / 横のめくり）/ ColorHue（色相を虹色に巡回）
Track: Motion形 + 秒数 + 繰り返し（下の「Motion の読み方」）
Track: Delay再生開始からこの秒数だけ遅らせて始める
Track: From開始値の決め方。Current = いまの値から / Absolute = From Value そのまま / Relative = いまの値 + From Value / OffScreen = 画面外から（位置のみ）
Track: Off ScreenFrom = OffScreen のときの方向（Left / Right / Top / Bottom）
Track: From Value / To Value開始値 / 終了値。From = OffScreen のときは To Value は無視され、開始前の位置に戻ります
Track: PathProperty = PathMove のときの経路の点（要素のローカル座標）

Motion の読み方

項目説明
ModeConstant = 動かない（即時）/ Parametric = 名前付きのイージングか自由なベジェ / Curve = AnimationCurve で自分で描く
Parametric: Kind / EaseKind = NamedEase なら 31 種のイージング（Ease）から選ぶ。イージング = 「最初ゆっくり後で速く（In）」「最初速く後でゆっくり（Out）」「行き過ぎて戻る（Back）」「弾む（Bounce）」「ぷるんと震える（Elastic）」など動きの緩急の型。Kind = CustomBezier なら CSS と同じ 2 つの制御点で自由に
CurveMode = Curve のときの自分で描いた形
From / ToTween では使いません（トラック側の開始値 / 終了値が実際の値）
Time: Mode / ValueDuration = 何秒で終わるか / Speed = 基準の何倍速か / Rate = 1 秒に何周するか（回転ループなど）。時間バーの右端のつまみで長さを変えられるのは Duration のときだけです
Time: Ignore Time ScaleON でゲーム内のスロー・ポーズの影響を受けない
LoopOnce = 1 回だけ / Loop = 頭から繰り返す / PingPong = 行って戻るを繰り返す
Loop Count繰り返す回数。0 = 無限（Idle 用）。2 なら 2 周で止まる
PingPong の癖: Loop Count が偶数のときは From 側の姿勢で止まります。「揺れて元に戻る」動きを作るときは、開始値を静止した姿勢にしてください。

よくある警告

表示対処
Tracks が空です(再生しても何も起こりません)「雛形から始める」か「＋ トラック」で足す
Tracks が N 本あります。同時に再生されるのは 8 本までで、それ以降は無視されます8 本以内にまとめる（9 本目以降の行にも印が出ます）
Motion.Duration が 0 以下のまま Loop/PingPong に設定されています(進行しない無限ループ)Time の Value を 0 より大きく
Property=PathMove ですが Path の制御点が 2 点未満です「＋点を追加」で 2 点以上に
Property=FillAmount は Image を持つ対象でのみ反映されます情報のみ。当てる要素に Image（Type = Filled）があるか確認
Property=Color は Graphic(Image/Text 等)を持つ対象でのみ反映されます情報のみ。当てる要素が画像か文字か確認
TotalDuration が最長 Track の終了時刻より短く設定されています全体の長さを 0（自動）に戻す
プレビュー対象がありません(…)「確認する」で要素を選ぶか「確認用シーンに配置」

よくある使い方

やりたいこと設定
プリセットを少しだけ変えたい「雛形から始める」→「置き換え」→ 該当トラックのバーをドラッグするか ⚙ で秒数と移動量だけ直す
滑り込みながらフェードイン位置のトラックと透明度のトラックを 2 本並べる（同時に走ります）。SlideFadeInLeft の雛形が最初からその形です
少し遅れて 2 つめの動きを始めたい2 本目のトラックのバーを右へドラッグして開始（Delay）をずらす
跳ねてから戻る、など 1 つの型では書けない動きDelay をずらした 2 本のトラック
アイテムがインベントリへ飛んでいく「＋ トラック」→ 経路移動。SceneView のハンドルで経路を描く
常時ふわふわ（Idle 用）Loop = PingPong、Loop Count = 0
作った動きをチーム全員の選択肢に「雛形から始める」の「プリセットとして保存」

注意点

  • プレビュー用 Canvas [D-Drive] UI Tween Preview はこのエディタ専用です（Button Skin / Slider Skin はそれぞれ別の名前）。「撤去」は自分で置いた仮画像だけを消し、エディタを閉じたとき・別のシーンに移ったときは自動で片付きます。万一画面に消えないプレビューが残ったら Tools > D-Drive > Debug > 確認用プレビューの残骸を掃除
  • 「置き換え」は Tracks を丸ごと入れ替えます（Ctrl+Z で戻せます）。組み合わせたいときは「＋ 追加」を使う
  • 時間バーの曲線は「形」だけです。軸の数字や、途中で止めて見る操作はありません
  • SceneView の経路ハンドルは「確認する」で選んだ要素が基準。対象が無いとハンドルは出ません
  • プリセット参照（UiPresetRef）の Ease Override で CustomBezier を指定しても、まだ効きません

プリセットギャラリー（Preset Gallery）

プリセットをカードで一覧して、曲線の形を見比べ、お気に入りに入れ、シーン上の UI 要素で実際に動かし、Canvas の要素に割り当てるための別ウィンドウです。UI Tween Editor の「雛形から始める」と同じプリセット・同じお気に入りを使います。

開き方

  1. メニューバー Tools > D-Drive > Editors > UI Tween · Preset Gallery
  2. UI Tween Editor のヒーローの「ギャラリー」、または「雛形から始める」の「ギャラリーを開く」（いま編集中の Tween が「編集中の Tween」に入ります）

画面の説明

要素説明
見出し組み込みの種類数・カタログの件数・お気に入りの数と、編集中の Tween。■ 再生を止める（シーン上で再生中のものを止めて元に戻す）、UI Tween Editor で開く
タブ: 出現 / 常時 / 消滅 / 強調 / カタログ組み込みプリセットの 4 分類 + プロジェクト独自の登録分

適用先

要素説明
編集中の Tween「置換」「追加」の先。「独自プリセットとして登録」の元にもなります
CanvasData / 要素 / 適用フェーズどの Canvas の、どの要素（Prefab から集めた要素の一覧。Prefab そのものは「(ルート)」）の、どのタイミング（Appear / Idle / Disappear）に付けるか
選択中のシーン要素のパスを使うHierarchy で選んだオブジェクトから要素パスを入れます。Prefab アセットを選んでいると「シーン上のオブジェクトを選択してください(Prefab アセットは不可)」。埋め込み Canvas の中の要素なら、適用先を子の CanvasData に切り替えます。入ったパスが Prefab の根元からのものと一致するとは限らないので「手動確認してください」と出ます
この設定を他の要素へコピー選んだ要素の Appear / Idle / Disappear の設定を他の要素へ写す。先に「要素へ」で割り当てていないと「選択中の要素の ElementFx 行が見つかりません(…)」

独自プリセットとして登録

登録先カタログ / 元になる UiTweenData（「編集中の Tween」が入ります）/ 表示名 / カテゴリ（任意）を入れて「登録する」。同じ名前なら上書き。未入力だと「カタログ・UiTweenData・表示名を指定してください」。登録するとカタログのタブに出ます。

カタログ（UiPresetCatalog）は「デザイナーが選ぶための一覧」でしかなく、ゲーム実行時には使われません。Create > D-Drive/Ui/Ui Preset Catalog で作ります（ID を持たないので Asset Browser には出ません）。カタログの各行は Name（表示名）/ Tween（実体の UI Tween）/ Category（分類、任意）です。

要素演出（ElementFx: Appear / Idle / Disappear）

Canvas データの ElementEffects に、要素パスごとに「開くとき（Appear）/ 表示中（Idle）/ 閉じるとき（Disappear）」の演出を持たせる仕組みです。プリセットギャラリーの「この要素に適用」か Canvas Editor で設定します。

項目説明
解決順各フェーズについて、UI Tween の Id（Appear / Idle / Disappear）→ プリセット（Appear Preset など）→ レイヤー既定（UiLayerSettings の Default Appear / Default Disappear）の順で最初に見つかったものを使います。Idle にレイヤー既定はありません
開くときAppear Delay の小さい要素から順に Appear が始まり、全部の Appear が終わるまで操作はブロックされます
表示中Idle は Appear が終わった直後から繰り返し、閉じ始めたらその場で止まります
閉じるとき全要素の Disappear と Canvas 自体の閉じ演出（CloseTransition）の両方が終わるまで待ちます

よくある警告

表示対処
Element Path が見つからない（実行時に 1 回だけ警告）その行は飛ばされます。Prefab の階層名とパスを合わせる
Disappear に無限ループの演出（常時タブのものや Loop Count = 0）を入れてはいけません。閉じる処理が終わらず、画面が閉じられなくなります。

標準オプション（音量設定などをスクリプト 0 行で）

Canvas データの Sliders（SliderWire）で、スライダーの Action を SetOption にして Option を選ぶだけで、標準の設定値に直結します。Canvas を開いたときに、いまの設定値でスライダーが自動で初期化されます。値は 0〜1、既定は 1、PlayerPrefs に自動保存されます。

Optionいま効くか説明
MasterVolume効く全体音量
BgmVolume / SeVolume / VoiceVolume値を保持するだけ種類別の音量。音への接続は Phase 5 の予定
ShakeScale / HapticScale値を保持するだけ画面揺れ / 振動の強さ。接続は Phase 6 の予定
UiSpeedScale効くUI 演出全体の速さ（0.01 が下限）
実行中にコンソールへ「[DDrive] OptionStore: Audio バス別音量(…)は Phase 5 で実装予定のため、値は保持のみです」と 1 回出ますが、仕様なので気にしなくて構いません。スライダー側の作り方は Slider Editor のページを参照。
