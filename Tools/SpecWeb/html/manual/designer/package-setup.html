パッケージを導入する / 更新する

最終更新日: 2026-09-20

このページは骨子です。 D-Drive は「別のプロジェクトへ簡単に持ち込めるパッケージ」として配布できるように準備を進めています（2026-09-20 時点はセットアップウィザードまで実装済み）。導入・更新の手順を実際にプロジェクトに沿って書き切るページは、消費側ドキュメント一式（README・エージェント向け手順）と合わせて後日完成させます。ここでは今できることの機能説明だけを紹介します。

セットアップウィザードとは

D-Drive を新しいプロジェクトに持ち込んだとき（または D-Drive を更新した後）に、必要な設定が揃っているかをまとめて確認し、足りないものをボタン 1 つで直すための画面です。プログラマー・テクニカルアーティストがプロジェクトの立ち上げ時に使うことを想定していますが、デザイナーが「なぜエフェクトが出ないのか」を確認するときにも使えます。

開き方

  1. Unity のメニューバーから Tools > D-Drive > Setup > セットアップウィザード を開く

確認できること（上から順に）

  1. 依存パッケージ: D-Drive が必要とする外部パッケージ（UniTask・R3 など）がプロジェクトに入っているかを確認し、足りなければ「追加」ボタンで導入する
  2. ProjectSettings: レンダーパイプライン（URP）・入力方式（Input System）・API 互換レベルが D-Drive の前提と合っているかを確認する（自動では変更しない項目もあります）
  3. 置き場所: D-Drive が作るデータ（GameData フォルダ等）をどこに置くか選べる（既定のまま/1 つの親フォルダの下にまとめる/個別に指定、の 3 通り）
  4. 既定フォルダ・設定の生成: 最初に必要なフォルダや設定ファイルをまとめて作る
  5. Addressables 同期: アセット管理の仕組み（Addressables）が初期化されているかを確認する
  6. 起動オブジェクト: ゲームを実際に動かすために必要な「起動オブジェクト」をシーンに置く
  7. テストを有効化する: D-Drive 自身のテストをこのプロジェクトで実行できるようにするかどうか（既定は OFF）
  8. エージェント向けスキル: AI エージェント（Claude Code 等）が D-Drive を正しく使うための手引きを、このプロジェクトの設定にコピーする
  9. 完了チェック: 上のすべての状態を一覧表示し、Validation（自動チェック）もあわせて実行できる

更新する

D-Drive のバージョンが上がったら（Packages/manifest.json のタグを新しくしたら）、Tools > D-Drive > Update > 更新ウィンドウ を開きます。

  1. 版と CHANGELOG: 「現在の版」「前回適用した版」と、その間に何が変わったか（CHANGELOG の該当箇所）を表示します。「破壊あり」の変更が含まれる場合は警告が出るので、先に移行ガイドを確認してください
  2. マイグレーション（プレビュー）: 更新に伴ってデータの形式を直す必要がある件数を確認できます（この時点ではまだ何も変更しません）
  3. 更新を適用: ボタン 1 つで「データの形式を直す → ID/調整値の定数を作り直す → アセット管理の登録を揃える → 自動チェックを実行する」を順番に実行します。途中で失敗したらそこで止まり、それより後の手順は実行されません(前回適用した版も更新されません)
  4. テストを有効化する / エージェント向けスキルを更新: セットアップウィザードと同じ項目をここからも操作できます

更新後も、念のため セットアップウィザードの「完了チェック」を確認することをおすすめします（更新のたびに新しい設定項目が増えることがあります）。
