VFX（エフェクト）の設定項目

VFX データ（VfxData）は「どのエフェクトを・どこに・どのくらいの時間出すか」をまとめたものです。中身の見た目（粒の飛び方や色）は Unity の ParticleSystem を持つ Prefab 側で作り、VFX データはそれを「どう使うか」を決めます。

作り方

  1. Asset Browser の「新規」ボタンで種別に Vfx (VfxData) を選び、表示名（日本語 OK）とカテゴリ・識別子（英語）を入力
  2. 作られたデータの Prefab に、エフェクトの Prefab を設定（Prefab の見た目からアイコンが自動で作られます。Inspector の「自動生成」で作り直せます）
  3. VFX Editor で再生しながら位置・寿命・色を調整

ファイルは Assets/GameData/Vfx/カテゴリ/VFX_カテゴリ_識別子.asset に自動で置かれます。ファイル名を自分で付ける必要はありません。

Prefab

項目説明
Prefab再生する実体。ParticleSystem の Prefab（VFX Graph でも可）。未設定だと Error。
Prefab のマテリアルが古い（Built-in 用）シェーダーだと、このプロジェクト（URP）では透明になって見えません。「検証」に赤く出ます。Tools > D-Drive > Generate > デフォルトパーティクルマテリアルを生成 で作った URP 用マテリアルに差し替えてください。

Lifetime（寿命）

項目説明
Life Modeいつ消えるか。
OneShot: 粒子が全部消えたら自動で終わる（斬撃・ヒットなど 1 回きりのもの）。
Loop: 止める指示があるまで出続ける（オーラ・炎など）。
Duration: 下の Duration 秒で強制的に終わる。
DurationLife Mode = Duration のときの継続秒数。ParticleSystem を持たない Prefab（VFX Graph など）では OneShot でもこの秒数で終了します。
Fade Out Sec「止める」指示が来たとき、新しい粒子を出すのをやめてから実際に消えるまでの待ち秒数。出ている粒子が自然に消えるのを待つための時間です。0 だと即座に消えます。10 秒を超えると Warning。

Render（描画）

項目説明
RenderWorld3D: 通常のシーン内に出す。
UIOverlay: UI（メニュー画面など）の上に重ねて出す。専用カメラで合成されます。
Render Layer（レイヤー）出したエフェクトに付ける Unity のレイヤー。通常は Default のまま。UIOverlay のときは VfxUI レイヤーを選びます（Tools > D-Drive > Generate > VFX UI レイヤー/カメラを設定 で用意されます）。
Light Layer Mask（ライトレイヤー）どのライトの影響を受けるか。通常は Default のまま。「Nothing」にすると Prefab 側の設定をそのまま使います。

Anchor（アタッチ位置）

Anchor Id: Anchor データを指定すると、そちらが優先され、下の埋め込み項目は無視されます。ランダム・ディレイ・確率・入れ子を使いたい場合は Anchor データ側で設定します。

「エフェクトをどこに出すか」の定義です。効果音（SE）の 3D 設定と同じ仕組みで、用語も共通です。調整は VFX Editor の Anchor 欄 でスライダーや SceneView のドラッグを使うのが簡単です。

項目説明
Space基準の決め方。
World: 固定座標（Local Offset がそのままワールド座標）。
BoneName: キャラクターのボーン名で探す（例: RightHand）。
NamedObject: オブジェクト名で探す（例: Anchor_Muzzle）。
ContextTarget: プログラムが渡してきたオブジェクトそのもの。
PathBoneName / NamedObject のときに探す名前。VFX Editor の「一覧から選択」で選ぶと確実です。
Local Offset基準からの位置のずれ（メートル）。X=右、Y=上、Z=前。
Local Euler基準からの向きのずれ（度）。
Local Scale大きさの倍率。(0,0,0) は 1 扱い（古いデータとの互換のため）。
Follow Rotation（回転追従）ON: 基準が回転するとエフェクトも一緒に回る。OFF: 向きは固定。
Detach On Stop（親消滅後も残す）ON: 基準のキャラクターが消えてもエフェクトはその場に残って最後まで再生。OFF: 一緒に消える。

AnchorPoint / AnchorRig（シーンに置く目印）

ボーンが無いオブジェクトや、「ボーンから少しずらした場所」を SceneView で直接決めたいときは、目印（AnchorPoint）をシーンや Prefab に置いて、その名前を Path に指定します。

  1. Tools > D-Drive > Generate > Anchor プレハブを生成 → Assets/GameData/Prefabs/Anchors/AnchorRig.prefab ができる
  2. キャラクター Prefab の子に AnchorRig を置き、その下の AnchorPoint を SceneView でドラッグして位置決め。名前は Anchor_RightHand のように Anchor_ で始めるのがおすすめ
  3. VFX Editor の「一覧から選択」に ★ Anchor_RightHand のように ★ 付きで出るので選ぶ

AnchorPoint には次の項目があり、そこに出すすべてのエフェクト・効果音に追加で効きます。

項目説明
Spawn Offsetこの目印から更にずらす位置。
Position Jitter Radius出す位置をこの半径（メートル）の球の中でランダムに散らす。0 で無効。
Euler Jitter向きを ± この角度の範囲でランダムに変える。(0,0,0) で無効。
Scale Range大きさの倍率をこの範囲（最小, 最大）でランダムに変える。両方 1 で無効。エフェクトのみ。
Gizmo ColorSceneView に表示される目印の色。
同じキャラクターの中で AnchorPoint の名前を重複させないでください（最初に見つかったものが使われます）。

Parameters（公開パラメータ）

「このエフェクトの色は場面ごとに変えたい」といった項目に名前を付けて公開しておくと、プログラムから名前で変更できます。VFX Editor で再生中に変えて確認できます。

項目説明
Label表示名（例: MainColor、Size）。プログラマーはこの名前で指定します。
Type値の種類。Float（小数）/ Int（整数）/ Color（色）/ Vector / Texture / Curve / Gradient。
Target Propertyマテリアルのプロパティ名（例: _BaseColor）。Prefab のマテリアルに無い名前だと Error。
Default既定値。VFX Editor のパラメータ欄で変えた値はここに保存されます。
Anim任意。時間とともに値を変化させたい場合の形（カーブ）と速さ。

Events（イベント）

エフェクトの出現・ループ・消滅に合わせて効果音などを鳴らす設定です。Trigger（OnSpawn / OnLoop / OnDestroy など）と Action（鳴らすアセットなど）を指定します。各行の Repeat（繰り返し）は「毎周回 / 1 回 / 再生中は維持」で、「1 回」「再生中は維持」は OnSpawn や OnLoop のような時刻以外のタイミングでも再生ごとに 1 回だけ発火します（用語集: 繰り返し）。

よくある警告

表示対処
Prefab が未設定(または Missing)ですPrefab を設定する。Missing の場合は Prefab が削除・移動されています。
マテリアル '…' のシェーダーは Built-in 用です上の「Prefab」の枠内を参照。
Params '…' の TargetProperty が存在しませんプロパティ名を確認する。
Render=UIOverlay ですが Domain=Game3D ですUI 用なのに用途が 3D になっています。プログラマーに確認。
FadeOutSec が 10 秒を超えています入力ミスでないか確認。
