SE（効果音）の設定項目

Asset Browser で SE を選ぶと、Unity 右側の Inspector（インスペクター）に設定項目が表示されます。ここではそのすべての項目を説明します。各項目はエディタ上でマウスを乗せても説明（ツールチップ）が出ます。

音を聞きながら調整したいときは Audio Editor を開いたまま作業するのがおすすめです。

Clips（クリップ）まわり

項目説明
Clips実際に再生される音声ファイル。複数入れると、鳴らすたびに違う音を選べます（足音のバリエーションなどに便利）。どう選ぶかは下の Select Mode で決めます。
Sources「音の切り出し（トリミング）」用の元データ置き場。ここに元ファイルを入れて切り出し範囲を指定し、「トリミングを適用」すると Clips に切り出し済みの音が入ります。元ファイルは一切変更されないので、何度でもやり直せます。詳しくは Audio Editor のトリミング へ。
Start Offset Sec再生を何秒目から始めるか。「頭の無音をスキップしたい」ときに手軽に使えます（0 = 先頭から）。
Select ModeClips が複数あるときの選び方。
Random: 毎回ランダム（足音など自然なばらつきに）
RoundRobin: 順番に1つずつ（1→2→3→1→…）
First: 常に先頭の1つだけ
Mixer音の出力先グループ。通常はサウンド担当が指定したもの（SE 用グループなど）を設定します。未設定だと警告が出ます。→ 用語集: Mixer
Volume基準の音量（0〜1）。1 が元のファイルどおりの大きさ。
Pitch Range再生するたびに音の高さをランダムに揺らす範囲。X が最小、Y が最大。両方 1 のままなら揺らしなし。例: (0.95, 1.05) にすると毎回わずかに高さが変わり、連続で鳴っても機械っぽさが減ります。
Loopチェックすると鳴りっぱなしになります（環境音向け）。通常の効果音はオフ。

3D（立体音響）の設定

「音源が遠いと小さく聞こえる」「右にあると右から聞こえる」という立体的な鳴らし方の設定です。

項目説明
Spatialこの音を 3D で鳴らすかどうかの大元のスイッチ。
None: 2D 再生。どこで鳴らしても同じ聞こえ方（UI 音・システム音向け）
Anchor: キャラの手元など「何かにくっつけて」鳴らす
At Position: プログラムが指定した座標で鳴らす
None のままだと下の距離設定はすべて無効です。Audio Editor の 3D 確認パッドにも「無効」と理由が表示されます。
AnchorSpatial=Anchor のときの「くっつけ先」の指定。Path にボーン名（例: RightHand）を書くとそのボーンに追従します。Local Offset でくっつけ先からのズレを指定。
Detach On Stop にチェックすると、くっつけ先が消えても鳴り終わりまでその場に残ります（爆発音などに）。
Min Distanceこの距離（メートル）までは最大音量のまま。近づいてもこれ以上大きくなりません。
Max Distanceこの距離を超えると聞こえなくなります。Min より大きい値にしてください（逆だとエラー表示）。
Rolloff距離と音量の減り方をカーブで細かく指定したい場合だけ設定（空でOK。空なら標準の減り方）。
Spread音の「広がり」。0 = 一点から鳴る（方向がはっきり）、180 = 全方向から鳴る（方向感なし）。BGM 的な環境音は大きめが自然です。
Doppler Enabled救急車が通り過ぎるときの「ピーポー」の音程変化（ドップラー効果）を有効にするか。通常はオフ推奨。

制御（鳴らしすぎ防止）

項目説明
Max Concurrent同じ音を同時に鳴らせる数の上限。超えると一番古いものが止まります。連打される攻撃音などで音が団子にならないための設定。
Cooldown Sec一度鳴ってから次に鳴れるまでの最短時間（秒）。0.03 なら 1 秒間に最大 33 回まで。連打対策。

共通項目（すべてのアセットにあるもの）

項目説明
Idシステムが自動で付ける管理番号。絶対に手で変更しないでください。
Display Name一覧・検索で使われる表示名。日本語OK、いつでも変更可。
Descriptionメモ欄。用途などを自由に書けます。
Category / Tags整理・検索用の分類。
IconInspector に出る小さな画像。効果音は絵の元が無いので「自動生成」は使えません。必要なら「フォルダから選択」で画像を指定します。
Version / Author / Updated At更新履歴。保存すると版数・更新者（Windows のユーザー名）・更新日時が自動で記録されます（手入力不要）。詳しくは Asset Browser の使い方の「バージョン表示」。
Flagsポーズ中に止まるか等の細かい挙動設定。迷ったら初期値のままでOK。変更が必要な場面ではプログラマーから指示があります。
Events「この音が鳴り始めた時（OnSpawn）に別の何かを起こす」等の連携設定。各行の Repeat（繰り返し）は「毎周回（EveryLoop）/ 1 回（Once）/ 再生中は維持（KeepWhilePlaying）」で、「1 回」「再生中は維持」は再生ごとに 1 回だけ発火します（用語集: 繰り返し）。普段は使いません。

よくある警告と直し方

警告意味と直し方
Clip が未設定Clips が空です。音声ファイルを設定してください。
Mixer が未割当出力先グループが未設定。サウンド担当指定のグループを設定。
MaxDistance が MinDistance 以下Max は Min より大きく。
Volume が 0音量 0 のため鳴りません。意図的でなければ上げてください。
StartOffsetSec がクリップ長以上開始位置が音の長さを超えていて無音になります。
