モデルの設定と Model Editor

最終更新日: 2026-10-13

モデルデータ（ModelData）は「このキャラクター / 物体の Prefab を、どのマテリアル・どのアニメーションで出すか」をまとめたものです。プログラマーは Models.Spawn(MODELID.Player, 位置, 向き) と書くだけで、Prefab の差し替え・マテリアルの入れ替え・最初に再生するアニメーションはデータ側で決められます。

開き方

  1. Asset Browser の「新規」ボタンで種別に Model (ModelData) を選んで作る（表示名は日本語 OK）。Prefab のドラッグ＆ドロップでは作れません（ドラッグ＆ドロップで登録できるのは音声ファイルだけです）
  2. モデルデータを Project で選び、Inspector の一番上の「Model Editor で開く」を押す
  3. またはメニューバー Tools > D-Drive > Editors > Model
Model Editor を先に開いてしまった場合は、画面上部の「＋ 新規」ボタンでも Asset Browser を開かずにその場でモデルデータを作れます（作成後は自動でそのデータが対象になります。詳しくはAsset Browser の使い方）。

画面の見方

  • かんたん / 標準 / 詳細: 出す欄の量を切り替えます（かんたん = Prefab だけ、標準 = よく使う欄まで、詳細 = すべて）。右上の検索ボックスで、欄の名前・説明、スロットの Renderer 名・Material 名から探せます
  • ヒーロー: ◀ ▶ で別のモデルデータへ切り替え（名前の欄で検索もできます）。「確認用シーン」「Prefab で開く」「Project」「＋ 新規」「🔒 固定」
  • 固定バー: ▶ 再生 / ■ 停止 / リピート / 速度（×1.0 に吸着）/ 変更の件数 / 自動保存 / 保存（Ctrl+S でも保存できます）。▶ は「モデルを置いて Default Animation を流す」です
  • 各欄の左の色の帯と「↺」は、既定値と違うことと、既定へ戻すことを表します。エラー・警告は該当する欄の下に出ます
見た目はウィンドウの中ではなく SceneView で確認します（VFX Editor / Anim Editor と同じ）。SceneView を好きな角度・大きさにして見てください。

見た目（Prefab）

項目説明
Prefab出す Prefab。未設定は Error。設定すると Prefab の見た目からアイコンが自動で作られます（Inspector の「自動生成」で作り直せます）
モデルの情報Prefab を調べた結果です（読み取り専用）。Renderer の数（Skinned / Mesh）・Material スロットの数・BlendShape（表情）の数・Animator の有無・Prefab に付いた IModelInstanceListener（出現・返却の節目で通知を受ける部品）

Material スロット

Renderer ごとに「どのマテリアルを貼るか」を決めます。スロットが多いモデルでも見通せるよう、1 スロット = 1 行で並びます。ゲーム実行時（Spawn）には、ここで選んだマテリアルに差し替わります。

操作説明
Slot 自動収集Prefab の Renderer を走査して一覧を作り、Renderer が使っている Material から作られた MaterialData を割り当てます。すでに割り当て済みのスロットは変更しません
元ファイル再読み込みPrefab の元になった FBX や Material からマテリアルデータを作り直してから、スロットに結び付けます（FBX を差し替えたあとに使います。マテリアルデータの固有の調整は保たれます）
配置中のモデルに反映シーンに置いたモデルに、スロットのマテリアルをゲームと同じ経路で適用して、見た目を確かめます（モデルを置いていないときは押せません）
マテリアルの選び箱行の MaterialData 欄に、別のマテリアルデータをドラッグするか、右の ◎ で選びます。空にすると未割り当てに戻ります
開くその行のマテリアルを Material Editor で開きます（色・つや・固有の調整）
↺Prefab の Renderer が使っている Material から、対応するマテリアルデータを割り当て直します（対応するものが無いときは何も変えません）
絞り込み一覧の上の検索（Renderer 名・Material 名）と、すべて / 割当済み / 未割当 / Skinned / Mesh / ほか / 見つからないのボタン。件数（「24 スロット中 割当済み 21」）が出ます。20 行を超えると一覧の中でスクロールします

行のチップが見つからないのときは、その Renderer が Prefab から無くなっています（階層の名前を変えた・消した）。「Slot 自動収集」をやり直してください。

「元ファイル再読み込み」と知らないシェーダー

元の Material のシェーダーが D-Drive の標準シェーダー（DDrive/Lit・Unlit）に対応づけられないもの（独自のトゥーンシェーダーなど）のとき、確認のダイアログが1 回だけ出ます（Material ごとには出ません。見つかったシェーダー名と件数が表示されます）。

選択肢結果
元のシェーダーのまま保つそのシェーダーでマテリアルデータを作ります（同じ名前のプロパティの値は固有欄に引き継がれます）。すでにシェーダーが入っているマテリアルデータのシェーダーは変えません
DDrive/Lit に変換DDrive/Lit のマテリアルデータにします
キャンセル（何もしない）マテリアルデータもスロットも何も変更せず中断します

毎回聞かれたくないときは、Create > D-Drive > Material > Maya Import Profile で作った Profile の「Unknown Shader Policy」を変えます。KeepSource は確認なしで元のシェーダーを保ち、ConvertToLit は確認なしで DDrive/Lit に変換します（既定の Ask は上の確認を出します）。モデルを取り込んだときの自動生成のように確認を出せない場面では、Ask のときは DDrive/Lit に変換します。

アニメーションと Avatar

項目説明
最初に流すアニメ（Default Animation）任意。出した瞬間に再生するアニメーションデータ。右の「Anim Editor で開く」で、そのアニメの中身（クリップ・ステート・イベント）を Anim Editor で調整できます
Avatar（Humanoid）Humanoid のときの Avatar。Animator があるのに Avatar が無いと Error です。Cutscene で Humanoid のアニメを使うモデルには、この欄に Humanoid の Avatar が必要です
Avatar の情報このデータの Avatar と、Prefab の Animator が持つ Avatar を見比べた結果です（読み取り専用）。「Cutscene の Humanoid アニメ: 使えます / 使えません」も出ます。Animator 側に Humanoid の Avatar があるのにこの欄が空のときは、「Animator の Avatar を入れる」ボタンが出ます

描画

項目説明
描画のレイヤー番号（Render Layer）出したときの描画のレイヤー
ライトレイヤー（Light Layer Mask）どのライトの影響を受けるか（用語集）。0 は「Prefab の Renderer の設定をそのまま使う」で、上書きしません。既定は 1（Default）
LOD の閾値の上書き（Lod）LOD の切替距離。Prefab に LODGroup があるときだけ効きます（詳細モード）

確認する

要素説明
確認用シーン確認用シーン（VFX / Anim と共通）を開いて、対象を原点に配置します。無ければ自動で作られます（Hierarchy に [D-Drive] Anim Preview が出ますが、シーンには保存されません）。右クリックで、いま開いているシーンへの配置・本配置を選べます
今のシーンに配置 / 撤去開いているシーン（またはプレハブモード）の原点に対象を置く / 消す。撤去は並べて確認の分も消します。置いたモデルは Hierarchy で選択された状態になります
Prefab で開くモデルの Prefab をプレハブモードで開きます。Renderer やマテリアルをその場で編集して Ctrl+S
ターンテーブル「自動で回す」を ON にすると、置いたモデルを Y 軸で回します（速さは度/秒、マイナスで逆回転）。プレハブモードの実体は回しません
並べて確認別のモデルデータを最大 4 つ選び、「配置」で対象の隣に 2m 間隔で並べます（サイズ感や色味の比較に）。「撤去」で個別に消せます
固定バーの ▶モデルを置いて Default Animation を流します（置いてあれば最初から流し直し）。Default Animation が未設定のときは、その旨が出ます

管理情報

項目説明
表示名 / カテゴリ / 説明 / タグ / アイコン / 担当者 / 仕様書 URL / 変更メモAsset Browser での表示名・フォルダ分け・検索用のメモなど。Id / Version / 最終更新者 / 最終更新日時はツールが自動で付けます（手で編集しないでください）
動作の取り決め / イベントPool・ポーズ・ネット配送などの共通設定と、出現・終了の節目で鳴らすもの（詳細モード）

よくある警告

表示対処
Prefab が未設定(または Missing)ですPrefab を設定する
Animator がありますが Avatar が未設定ですAvatar の欄に Avatar を入れる（「Animator の Avatar を入れる」が出ていれば 1 回で入ります。静的なモデルなら Animator を外す）
Slots[0] の RendererPath '…' が Prefab 内で見つかりませんPrefab の階層が変わっています。「Slot 自動収集」をやり直す
Slots[0] に Material が未割当ですそのスロットにマテリアルを入れる（Prefab のマテリアルのままで良ければそのままでも動きます）
マテリアル '…' のシェーダーは Built-in 用ですURP 用のシェーダーに差し替える（Scene / Game でピンクや透明になります）

これらは該当する欄の下に出るほか、Tools > D-Drive > Validation > Run All でも一覧に出ます（Validation の使い方）。
