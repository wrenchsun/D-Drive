モデルの設定と Model Editor

モデルデータ（ModelData）は「このキャラクター / 物体の Prefab を、どのマテリアル・どのアニメーションで出すか」をまとめたものです。プログラマーは Models.Spawn(MODELID.Player, 位置, 向き) と書くだけで、Prefab の差し替え・マテリアルの入れ替え・最初に再生するアニメーションはデータ側で決められます。

開き方

  1. Asset Browser の「新規」ボタンで種別に Model (ModelData) を選んで作る（表示名は日本語 OK）。Prefab のドラッグ＆ドロップでは作れません（ドラッグ＆ドロップで登録できるのは音声ファイルだけです）
  2. モデルデータを Project で選び、Inspector の一番上の「▶ Model Editor で開く」を押す
  3. またはメニューバー Tools > D-Drive > Editors > Model
Model Editor を先に開いてしまった場合は、ツールバーの「＋ 新規作成」ボタンでも Asset Browser を開かずにその場でモデルデータを作れます（作成後は自動でそのデータが対象になります。詳しくはAsset Browser の使い方）。

はじめの一歩（キャラクターを登録して確認する）

  1. モデルデータを作り、設定の Prefab にキャラクターの Prefab を入れる
  2. Model Editor のツールバー「確認用シーンを開く」→ ライト・カメラ・床の揃ったシーンが開き、モデルが原点に置かれます（Hierarchy に [D-Drive] Anim Preview が出ますが、シーンには保存されません）
  3. 「ターンテーブル自動回転」を ON → SceneView でぐるっと回して見た目を確認
  4. 「Slot 自動収集」→ Prefab の中の Renderer が一覧になり、マテリアルを ID で差し替えられる準備ができます
  5. 「Default Animation」に待機モーションのアニメーションデータを入れて「▶ 配置して DefaultAnimation を再生」→ 出した瞬間からそのモーションで動きます
見た目はウィンドウの中ではなく SceneView で確認します（VFX Editor / Anim Editor と同じ）。SceneView を好きな角度・大きさにして見てください。

ツールバー

ボタン説明
🔒 対象を固定Project で別のモデルデータを選んでも対象を切り替えない
確認用シーンを開く確認用シーン（VFX / Anim と共通）を開いて、対象を原点に配置します。無ければ自動で作られます
Prefab を開くモデルの Prefab をプレハブモードで開きます。Renderer やマテリアルをその場で編集して Ctrl+S
Project で表示対象のモデルデータを Project でハイライト

画面の説明

要素説明
▶ シーンに配置 / ■ 撤去開いているシーン（またはプレハブモード）の原点に対象を置く / 消す。置いたモデルは Hierarchy で選択された状態になります
ターンテーブル自動回転置いたモデルを Y 軸で回します（速度は度/秒、マイナスで逆回転）。プレハブモードの実体は回しません
複数モデル並列表示最大 4 体を対象の隣に 2m 間隔で並べます。サイズ感や色味の比較に。「配置」/「撤去」で個別に
Material スロット「Slot 自動収集」で Prefab の Renderer を走査して一覧化。各スロットにマテリアルの ID を入れます。ゲーム実行時（Spawn）にはそのマテリアルに差し替わり、配置中のモデルにも「配置中のモデルに反映」で同じ経路で適用して見た目を確かめられます
Default Animation出した瞬間に再生するアニメーションデータ。「▶ 配置して DefaultAnimation を再生」で確認、細かい調整は Anim Editor で

設定項目

項目説明
Prefab出す Prefab。未設定は Error。設定すると Prefab の見た目からアイコンが自動で作られます（Inspector の「自動生成」で作り直せます）
SlotsRenderer のパス / スロット番号 / マテリアル ID の組。「Slot 自動収集」で作り、ID だけ選びます。手で Renderer のパスを書く必要はありません
Default Animation任意。Spawn 直後に自動再生するアニメーションデータ
AvatarHumanoid のときの Avatar（情報用）
Render Layer / Light Layer Mask出したときのレイヤーと、どのライトの影響を受けるか（用語集）
LodLOD の切替距離。Prefab に LODGroup があるときだけ効きます

よくある警告

表示対処
Prefab が未設定(または Missing)ですPrefab を設定する
Animator がありますが Avatar が未設定ですPrefab の Animator に Avatar を割り当てる（静的なモデルなら Animator を外す）
Slots[0] の RendererPath '…' が Prefab 内で見つかりませんPrefab の階層が変わっています。「Slot 自動収集」をやり直す
Slots[0] に Material が未割当ですそのスロットに マテリアルの ID を入れる（Prefab のマテリアルのままで良ければそのままでも動きます）
マテリアル '…' のシェーダーは Built-in 用ですURP 用のシェーダーに差し替える（Scene / Game でピンクや透明になります）

これらは Tools > D-Drive > Validation > Run All でも一覧に出ます（Validation の使い方）。
