アニメーション（3D）の設定と Anim Editor

アニメーションデータ（AnimData）は「この Clip を、このステートで、いつ効果音・エフェクトを出しながら再生するか」をまとめたものです。基本の動き（待機・歩き）は Animator Controller に持たせ、攻撃・被弾などのワンショットを D-Drive のアニメーションデータで再生します。

  • Clip に Unity の AnimationEvent を埋め込む必要はありません。「15 フレーム目で斬撃音」のようなイベントはデータ側に持ち、Clip を差し替えても消えません
  • Anim Editor でモデルを動かしながらイベントの位置を決め、効果音・エフェクトも同時に確認できます

開き方

  1. Asset Browser の「新規」ボタンで種別に Anim を選んで作る（表示名は日本語 OK）
  2. アニメーションデータを Project で選び、Inspector の一番上の「▶ Anim Editor で開く」を押す（効果音・VFX・モデル・Anchor も同じ場所に「〜で開く」があります）
  3. またはメニューバー Tools > D-Drive > Editors > Animation (3D)。Project でアニメーションデータを選ぶと自動で入ります
Anim Editor のツールバーの「＋ 新規作成」ボタンからも、Asset Browser を開かずにその場でアニメーションデータを作れます（詳しくはAsset Browser の使い方）。

はじめの一歩（攻撃モーションに斬撃音を付ける）

  1. アニメーションデータを作り、設定の Clip に攻撃の Clip、State Name に Controller 上のステート名（Clip と同じ名前なら空でも可）を入れる
  2. Anim Editor の「確認用モデル」にキャラクターの ModelData を入れ、「確認用シーンを開く」→ シーンにモデルが置かれる
  3. ▶ 再生 → SceneView でモデルが攻撃モーションで動く。タイムラインの白い線が進む
  4. タイムラインをクリックして再生ヘッドを 15 フレーム目あたりに置き、「SE / VFX イベント」の「＋ 現在位置に SE」→ 行のドロップダウンで斬撃の SE を選ぶ
  5. ▶ 再生 → 15 フレーム目で音が鳴り、「イベントログ」に出る。タイミングを直したいときはタイムラインの橙色のマーカーをドラッグ（またはフレームの数字を直す）
  6. 同じ要領で「＋ 現在位置に VFX」でエフェクトを選ぶと、シーン上のモデルの位置にエフェクトが出ます（エフェクト側の Anchor がボーン指定なら、そのボーンから）
プログラマーは Anim.Play(ANIMID.Attack01, animator) と書くだけです。音やエフェクトのタイミングはデータ側で何度でも直せます。

シーン上で確認する

アニメーションは開いているシーンやプレハブモードのモデルがその場で動き、SceneView で確認します（ウィンドウ内の小さなプレビューはありません）。動かす相手（「シーン上の Animator(対象)」）は自動で決まります。

  1. 「確認用モデル」にキャラクターの ModelData を入れる
  2. ツールバーの「確認用シーンを開く」（ライト・カメラ・床の揃ったシーン。VFX と共通）→ モデルがシーンの原点に置かれ、対象に入ります。Hierarchy に [D-Drive] Anim Preview が出ますが、シーンには保存されません
  3. ▶ 再生 → SceneView でモデルが動きます。効果音・VFX のイベントもシーン内で鳴り、出ます

モデルの Prefab の中で動かす: ツールバーの「モデル Prefab を開く」でプレハブモードに入ると、その Prefab のモデルが自動で対象になります。BlendShape や IK の見え方を Prefab を編集しながら確認できます。■ 停止してもポーズはそのまま残るので、止めた絵を見ながら Prefab を直せます。Prefab でもシーンでも、保存（Ctrl+S）の直前に自動で再生前のポーズへ戻してから保存するので、再生中の姿勢が Prefab やシーンに入ることはありません。「↺ ポーズを戻す」でいつでも元に戻せます。

対象に 2D アニメーション（Anim2DData）を入れたときは、3D の「確認用モデル」は使われず、2D 用のプレビュー物（[D-Drive] Anim2D Preview）がシーンに置かれます。イベント編集やタイムラインの操作はこのページのとおりです。

シーンに置いてある自分のキャラクターを動かしたい場合は、Hierarchy でそのキャラクターを選んで「選択から取得」を押します。「↺ ポーズを戻す」か対象の切り替えで元のポーズに戻ります。

音とエフェクトを付ける（イベント一覧）

「SE / VFX イベント」に、音とエフェクトを付けるための道具がまとまっています。

  1. タイムラインをクリックして、鳴らしたい位置に白い線（再生ヘッド）を置く
  2. 「＋ 現在位置に SE」（または VFX / 配置セット）を押す → 行が増える
  3. 行のドロップダウンで音・エフェクトを選ぶ。「▶」でその音だけ試聴できます
  4. フレームの数字を直すか、タイムラインの橙色のマーカーをドラッグして位置を調整（Trigger が Time＝秒指定の行には「= F12」のようにフレーム換算も出ます）。SE は波形が重なって表示されるので、どこまで鳴るかが分かります
  5. 「繰り返し」を決める: 毎周回 = ループするたびに出す（足音など）/ 1 回 = 再生ごとに 1 回 / 再生中は維持 = 1 回出してモーションが終わるまで付いていき、終わると消える（ダッシュの土煙など、ループするエフェクト向け）。「1 回」「再生中は維持」は OnSpawn や OnLoop のような時刻以外のタイミングにも効き、タイムラインで再生ヘッドを戻してももう一度は出ません
  6. 「↗」でその音・エフェクトの専用エディタが開きます（中身を直したいとき）
▶ で最初から再生し直すときと ■ 停止のときは、前に出した音・エフェクトは消えます。
Animator から選ぶ: 「Animator から選択(ステートを選ぶと AnimData を探す / 作る)」でモデルの Controller にあるステート（Idle / Attack …）を選ぶと、そのアニメーションデータに自動で切り替わります。まだ無ければ「このクリップの AnimData を作成(ID 発行・カタログ・Addressables 登録)」を押すだけで作られます。方向違いのクリップにも同じ音を付けたいときは「同じステートの他クリップの AnimData へ一括コピー(無ければ作成)」。

ブレンドを確認する

「ブレンド確認」を開くと 3 つの道具があります。どれもモデルを動かして見るだけで、データは変わりません。

道具使い方見えるもの
遷移シーケンスSteps の ＋ で次に再生したいアニメーションを並べ、Step ごとに CrossFade 秒と「前のモーションのどこで切り替えるか（SwitchAt、0.5 = 半分、1 = 終わってから）」を決めて「▶ シーケンスを再生」。ループを ON にすると繰り返します攻撃 1 → 攻撃 2 → 構え直し、のようなつながりが自然か。CrossFade が短すぎてカクつかないか
レイヤー同時再生「一緒に再生する Anim」に上半身用（Layer が 1 のアニメーションデータ）を入れて「▶ 対象と一緒に再生」。Controller のレイヤーごとにスライダーが出るので、動かしながら見ます走りながら手を振る、などの重ね合わせ。AvatarMask（上半身だけ等）が効いているか
Blend Tree パラメータ横軸・縦軸に Controller のパラメータ（Speed、Direction など）を選び、パッドをドラッグ。1 つずつならスライダーで歩き↔走り、前後左右の混ざり方。境目で足が滑らないか
アニメーションデータの「Layer」欄が、どのレイヤーで再生されるかを決めます。同じ Layer のものを重ねると前のモーションが止まる（中断）ので、上半身用は Layer を 1 にしてください。

設定項目

項目説明
Clip再生するアニメーションクリップ。長さとフレームレートはイベントの位置と終了判定に使います。未設定は Error
State Name / LayerAnimator Controller 上のステート名とレイヤー。空なら Clip の名前を使います。Controller に無い名前だと検証に Error（再生自体は止まらず、イベントだけ動きます）
LoopON で周回し続ける（止める指示があるまで）。周回ごとに OnLoop イベントが出て、Frame/Time のイベントも毎周出ます
Default Cross Fade前のモーションから切り替わるときの混ざり秒数。0.1 くらいが自然
Mask上半身だけ、などのマスク（情報用。実際の適用は Controller のレイヤー設定）
Ik手足の IK を使うかとウェイトのカーブ。IK の目標位置はプログラム側で設定します
Blend Shapes表情など。Shape Name（モデル情報に出ている名前）と、時間（0〜1）→ ウェイト（0〜100）のカーブ
EventsTrigger: Frame（Clip の何フレーム目）/ Time（何秒）/ OnSpawn（再生開始）/ OnLoop（周回）/ OnDisable（止まった・中断された）/ OnDestroy（最後まで再生した）。Action = PlayAsset で Target に SE / VFX / 配置セットを入れると、そのタイミングで出ます。Repeat（繰り返し）: EveryLoop = 毎周回 / Once = 1 回 / KeepWhilePlaying = 再生中は維持（上の「音とエフェクトを付ける」参照）。普段は「SE / VFX イベント」の一覧から編集すれば十分です

よくある使い方

やりたいこと設定
攻撃の当たるフレームで音とエフェクトEvents に Frame=当たるフレーム、PlayAsset、Target=SE の行と Target=VFX の行を 1 つずつ
足音（歩きループ）Loop ON。Frame=左足着地 と Frame=右足着地 の 2 行に足音 SE。周回ごとに鳴ります
モーションの最後に構え直しの音Trigger=OnDestroy に SE（最後まで再生したときだけ鳴る。途中で別のモーションに切り替わったときは鳴らない）
叫び顔（表情）Blend Shapes に ShapeName と、0→100→0 のカーブ
ダッシュ中ずっと出る土煙Loop ON のダッシュモーションに、Loop の VFX を「再生中は維持」で 1 行。1 回出て走っている間付いていき、モーションが終わると消えます
方向違いの 4 クリップに同じ音1 つに付けてから「同じステートの他クリップの AnimData へ一括コピー」

よくある警告

表示対処
Clip が未設定(または Missing)ですClip を設定する
Frame イベント(…)が Clip 長(… フレーム)を超えていますマーカーが赤になっています。Clip の長さより手前にドラッグ（Clip の最後のフレームちょうどは OK です）
StateName '…'(Layer 0) が対象モデルの Controller にありませんController のステート名を確認して合わせる。空にすれば Clip 名が使われます
BlendShape '…' が対象モデルにありませんモデル情報に出ている名前から選び直す
Loop=false ですが OnLoop イベントがありますループしないので鳴りません。Loop を ON にするか行を消す
