（旧）Tuning ウィンドウの使い方

最終更新日: 2026-10-13

このページは、メニュー Tools > D-Drive > Archive > Tuning（調整値） から開く旧デザインの Tuning ウィンドウの説明です。通常は新デザインの Tuning Editor を見てください。

Unity 側の「Tuning ウィンドウ」

Unity を開けるメンバーは、発注ツールの代わりに Unity のメニュー「Tools > D-Drive > Editors > Tuning（調整値）」からも同じ数値を編集できます。キーは Player / Match のような接頭辞ごとにカテゴリ分けされて左側に一覧表示され、右側で選んだカテゴリのキーだけを編集します（float/int はスライダー、bool はトグル、enum はドロップダウン、string はテキスト欄。単位と説明も横に表示されます）。表形式の調整値は「Tables」から同じ画面でセルの値を編集できます（列・行の追加削除は発注ツール側で行います）。編集した値は保存すると即座にアセットに反映され、Play Mode 中に変更した場合はツールバーの「Play 中に再読込」を押すと起動時に値をキャッシュしている機能にも新しい値が届きます。
