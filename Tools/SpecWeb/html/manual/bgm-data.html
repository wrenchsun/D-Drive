BGM の設定項目

BGM データ（BgmData）の設定項目の説明です。BGM は SE と違い、「イントロ→ループ」の2部構成と曲の切り替え（クロスフェード）に対応しています。

Clips（曲データ）

項目説明
Intro曲の導入部分（任意）。設定すると「Intro を1回再生 → Loop Body を繰り返し」という構成になります。導入のない曲は空のままでOK。
注意: イントロが再生されるのは「無音の状態から曲を開始した時」だけです。別の曲からの切り替え（クロスフェード）ではイントロは飛ばされ、ループ部分から始まります。
Loop Body繰り返し再生される曲の本体。必須。
Loop Start Sec / Loop End SecLoop Body の中の一部分だけを繰り返したい場合に、その範囲を秒で指定。両方 0 のままなら曲全体をループします。Audio Editor なら波形を見ながらドラッグで設定できます。
Mixer出力先グループ（BGM 用グループを設定）。→ 用語集: Mixer
Volume基準音量（0〜1）。

Fade（フェード）

曲の切り替わりを滑らかにする設定です。

項目説明
Fade Inこの曲に切り替わってくるときの音量の上がり方。「何秒かけて」「どんなカーブで」上がるかを指定できます（初期値: 0.5 秒で直線的に）。
Fade Outこの曲が止まる・別の曲に切り替わるときの音量の下がり方（初期値: 1 秒）。
Fade In / Fade Out の編集欄は「モード」を選ぶ形式です。
定数: 使いません（フェードでは実質無効）/ 曲線: 定番の変化カーブから選ぶ（おすすめ。Linear=直線、OutQuad=最初速く後ゆっくり等）/ カーブ: 自分でカーブを描く
「Time Mode: Duration」の「Value」がフェードにかかる秒数です。

Beat（ビート同期・上級者向け）

項目説明
Bpm曲のテンポ（1分あたりの拍数）。曲に合わせた演出を作る際に使われます。分からなければ空(0)でOK。

共通項目

Id / Display Name / Category などの共通項目は SE のページの「共通項目」と同じです。

よくある警告と直し方

警告意味と直し方
LoopBody が未設定曲本体がありません。必ず設定してください。
LoopEnd ≤ LoopStartループ範囲の終わりが始まりより前になっています。
Mixer が未割当出力先グループを設定してください。
