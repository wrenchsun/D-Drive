Anchor（出す位置）の作り方

Anchor は「エフェクトや効果音をどこに・いつ・どう出すか」だけを決めるデータです。「何を出すか」は持ちません。1 つ作っておけば、いくつもの VFX / SE から同じ位置設定を使い回せます。

  • キャラクターの右手・銃口・頭上など、ボーンやオブジェクトの名前を基準にした位置
  • 位置・向き・大きさのランダムなばらつき
  • 少し遅れて出す（生成ディレイ）、たまにしか出ない（生成確率）
  • Anchor の中に Anchor を置く入れ子（右手 → 銃口 → 銃口の火花、のように親子でずらす）
以前からある VFX / SE データの中の「Anchor」欄（埋め込み）はそのまま使えます。Anchor データを作って VFX / SE の「Anchor アセット」欄に入れると、そちらが優先されます。

開き方

  1. メニューバー Tools > D-Drive > Editors > Anchor（Anchor Editor）
  2. または VFX Editor の Anchor 欄「AnchorEditor で開く」、SE データの Inspector の「AnchorEditor で開く」
  3. Anchor データそのものを Project で選んだときは、Inspector 最上部の「▶ Anchor Editor で開く」（Anchor は絵の元が無いので、アイコンの「自動生成」は使えません）

はじめの一歩（5 分でできる練習）

「キャラクターの右手にエフェクトを出す位置」を作って、実際に出してみる流れです。

  1. VFX Editor か Anchor Editor のツールバー「確認用シーンを開く」で確認用シーンを開く
  2. Tools > D-Drive > Generate > Anchor プレハブを生成 でできた AnchorRig を、Project から Hierarchy へドラッグして置く（キャラクターがいる場合はその子に置き、中の Anchor_Main を右手あたりまで動かす）
  3. Hierarchy で AnchorRig を選んだまま Tools > D-Drive > Generate > 選択した AnchorRig から Anchor を一括生成。Anchor データが 1 つでき、Anchor Editor に入ります
  4. Anchor Editor の「スポーン先」に Hierarchy の AnchorRig（キャラクターの子に置いたならキャラクター）を入れる。基準の表示が「✓」になることを確認
  5. 「試し出し」の「確認用 VFX」に好きな VFX データを入れて ▶。SceneView の黄色い円の位置にエフェクトが出ます。円をドラッグして位置を変えると、次の ▶ から反映されます
  6. 使いたい VFX を VFX Editor で開き、Anchor 欄の「Anchor アセット」に今作った Anchor を選ぶ。これで、その VFX はプログラムから呼ばれたときもこの位置に出ます
効果音も同じです。SE データの Inspector で Spatial を Anchor にし、Anchor Id に同じ Anchor を選べば、エフェクトと音が同じ位置から出ます。

作り方（3 通り）

方法手順向いている場面
新規作成Asset Browser の「新規」ボタンで種別に Anchor を選ぶ。Anchor Editor でスポーン先（キャラクター）を指定し、「一覧から選択」でボーンを選んで位置を調整ゼロから作る
Hierarchy の Transform から作るシーンでボーンの下に空のオブジェクトを置いて位置を決め、それを選択したまま Anchor Editor の「選択した Transform から作成」（または Tools > D-Drive > Generate > 選択した Transform から Anchor を作成）。親のボーン名と、そこからのずれが自動で入ります。作った後、その空オブジェクトは消して構いません既存のボーンやモデルの階層をそのまま使いたい
AnchorRig から一括で作るAnchorRig（AnchorPoint の集まり）を選択して「AnchorRig から一括生成」。AnchorPoint 1 つにつき Anchor データが 1 つでき、AnchorPoint の親子関係はそのまま Anchor の入れ子になります。ランダム設定も写されますSceneView でドラッグして決めた目印をデータ化したい

VFX / SE の埋め込み Anchor から作るには、VFX Editor の「埋め込みをアセット化」（SE は Inspector の「埋め込み Anchor をアセット化」）を押します。埋め込みの値は残り、Anchor アセット欄に新しいデータが入ります。

Anchor Editor の画面

検証入れ子の循環、親が見つからない、Path が空、などの問題を表示

設定項目

項目説明
Parent親の Anchor。入れておくと「親で決まった位置」を基準に、この Anchor のオフセットを積みます。空ならルート
Space / Pathルートだけで有効。基準の決め方と探す名前（VFX の Anchor と同じ）。子では無視されます（親から引き継ぐ）
Local Offset / Local Euler / Local Scale基準からの位置のずれ（m）・向き（度）・大きさの倍率
Follow Rotation / Detach On Stopルートだけで有効。回転に追従するか／基準が消えた後も残すか
Position Jitter Radius出す位置をこの半径の球の中でランダムに散らす。0 で無効
Euler Jitter向きを ± この角度の範囲でランダムに変える
Scale Range大きさの倍率をこの範囲（最小, 最大）でランダムに。効果音には関係ありません
Delay Sec / Delay Jitter Sec出すまでの待ち秒数と、そこに足すランダム秒数。入れ子では親子の値が足し合わされます
Spawn Chance出す確率（0〜1）。0.3 なら 3 割の確率で出ます。入れ子では掛け合わされます。0 だと出ません（検証に注意が出ます）

VFX / SE から使う

  1. VFX Editor の Anchor 欄「Anchor アセット」（SE は Inspector の Anchor Id）で作った Anchor を選ぶ
  2. 埋め込みの Anchor 欄は畳まれ、以後は Anchor Editor 側で位置を調整します
  3. 再生して確認。プログラム側は今までどおり ID だけで呼び出せます（場面ごとに別の Anchor を指定して呼ぶこともできます）

よくある使い方

やりたいこと設定
右手の斬撃エフェクトを、少し手前にずらして出すスポーン先にキャラクター、「一覧から選択」で右手のボーン（または ★Anchor_RightHand）→ SceneView のハンドルで手前にドラッグ。回転にも追従させるなら Follow Rotation を ON
ヒット時の火花を毎回少し違う場所・向きで出すPosition Jitter Radius = 0.2〜0.5、Euler Jitter = (0, 180, 0)。▶ を連打してばらつきを確認
爆発の後、少し遅れて煙を出す煙用の Anchor を作り Delay Sec = 0.3。爆発用と煙用で別の Anchor にすると、それぞれ位置も変えられます
たまにしか出ないキラッとした演出Spawn Chance = 0.2（5 回に 1 回）
銃口 → 銃口の先のマズルフラッシュ、のように親子で位置を決める銃口の Anchor を作り、もう 1 つ Anchor を作って Parent に銃口を指定、Local Offset で前方へ。銃口の位置を直せば先の Anchor も一緒に動きます
同じ位置設定をいくつもの VFX / SE で使うAnchor を 1 つ作り、各 VFX の「Anchor アセット」・各 SE の「Anchor Id」で同じものを選ぶ
すでに VFX の中で調整した埋め込み Anchor を使い回したいVFX Editor の「埋め込みをアセット化」

確認のしかた（チェックリスト）

  • Anchor Editor の基準の表示が「✓ '…'」になっている（「⚠」ならスポーン先か Path を見直す）
  • 試し出しの ▶ で、SceneView の円の位置に出る
  • ばらつき・ディレイ・確率は ▶ を何度か押して体感で確認。基準の表示の末尾に「生成: 1s 後・確率 25%」のように合計が出ます
  • 「検証」に赤（Error）が無い
  • VFX / SE 側に設定したら、VFX Editor / Audio Editor でも一度再生して位置を確認

よくある警告

表示対処
Parent が登録されていません親に指定した Anchor が削除されています。Parent を選び直す
Parent が循環しています親をたどると自分に戻る設定になっています。どれかの Parent を外す
Space=BoneName/NamedObject ですが Path が未設定です「一覧から選択」でボーンを選ぶ
子 Anchor では Space/Path は無視されます子に基準を設定しても効きません。ルート側で設定する
SpawnChance が 0 のため何も生成されません意図した設定なら Description に理由を書く。そうでなければ 1 に戻す
AnchorId が設定されているため、埋め込みの Anchor は無視されますVFX / SE 側の埋め込み Anchor に値が残っています。問題はありませんが、混乱するなら埋め込みを既定値に戻す
