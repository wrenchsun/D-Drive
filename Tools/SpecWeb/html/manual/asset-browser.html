Asset Browser の使い方

Asset Browser は D-Drive の入口になるウィンドウです。登録済みの素材（アセット）を一覧で見たり、検索したり、新しく登録したりできます。

開き方

  1. Unity 画面の一番上のメニューバーを見る
  2. Tools をクリック → D-Drive → Asset Browser をクリック

画面の見かた

場所説明
検索欄（左上）文字を入れると、その場で一覧が絞り込まれます。日本語の表示名でも検索できます（例:「斬撃」と入れると「剣の斬撃音」がヒット）。カテゴリ・タグ・説明文も検索対象です。
種別メニュー（検索欄の右）「All」のままなら全部表示。「Se」を選ぶと効果音だけ、「Bgm」を選ぶと BGM だけに絞れます。種別は Se / Bgm / Vfx / Anim / Anim2D / Material / Texture / Canvas / Prefab / Model / Anchor / AnchorGroup / ControlSkin（ボタン・スライダーの Skin）/ UiTween など。「Presentation」「Shake」「Haptics」はまだ中身が無いので選んでも 0 件です。
「新規」ボタン新しいアセットを登録するダイアログを開きます（下で説明）。
「更新」ボタン一覧を最新の状態に読み直します。（普段は自動で更新されるので、表示がおかしいと感じた時だけ押せばOK）
「未使用...」ボタン（2026-09-14 追加）どこからも使われていないアセットの一覧を開きます。詳しくは下の「使用箇所を調べる / 使っていないアセットを片付ける / 安全に削除する」を参照。
一覧登録済みのアセットが並びます。クリックすると右の Inspector に詳細が表示されます。Ctrl/Shift クリックで複数選択できます（2026-09-14 から。「削除...」で複数まとめて削除対象にできます）。ダブルクリック（または選んで Enter キー）すると、そのアセットの専用エディタが開いて対象になります（2026-09-14 追加。専用エディタが無い種類のアセットは、これまでどおり Project ウィンドウの実ファイルがハイライトされるだけです）。右クリックすると「エディターで開く」（専用エディタが1つに決まらない種類は候補が並びます）・「使用箇所を表示」「依存ツリーを表示」「アーカイブする」「削除...」のメニューが出ます（2026-09-14 追加。「削除...」は専用ウィンドウが開きます。詳しくは下の節を参照）。
プレビューバー（一番下）選択中の音をその場で試聴できます。▶再生 / ■停止 / ループ / 速度。音以外（VFX やモデルなど）を選んでいるときは押せません。
件数表示（一覧の下）「12 / 48 件」のように「いま表示している件数 / 全件数」が出ます。検索や種別で絞っているときの目安に。
更新者・更新日時の列（2026-09-15 追加）カテゴリの右に、最後に保存した人と保存した日時が出ます（Inspector の「バージョン表示」と同じ値）。並べ替えはまだできません。
一覧の行の先頭にもアイコン画像が出ます（Inspector で設定したものと同じ）。アイコン未設定のアセットは Unity の既定サムネイルが出ます。アイコンの作り方は Inspector を参照してください。
バージョン表示（2026-09-15 追加）: アセットを保存すると、Inspector の「エディターで開く」ボタンの下に「v12 ・ 名前 ・ 2026-09-15 14:03」のように版数・更新者・更新日時が自動で入ります（版数は保存ごとに 1 ずつ増え、更新者は Windows のユーザー名、日時は保存した瞬間です。手で書き換える必要はありません）。変更の内容をメモしたい場合は、その下の「ChangeNote」に自由に書き込めます（自動では消えません）。過去のバージョンの一覧は出ません（履歴は Git 側で管理しています）。

検索の詳しい仕様

検索欄は1文字打つたびにその場で絞り込まれます（Enter キーを押す必要はありません）。

検索でヒットする項目

入力した文字は、そのアセットの以下の項目のうちどれか1つにでも含まれていればヒットします（大文字・小文字は区別しません）。

項目説明
表示名「剣の斬撃音」のような、人が入力した名前
ファイル名・保存場所ツールが自動生成したファイル名(例: SE_Player_SwordSlash)や、保存されているフォルダのパス
カテゴリ登録時に入力した分類
説明文Inspector の「Description」に書いた内容
作成者Inspector の「Author」（2026-09-15 から、保存すると自動で最後に保存した人の名前になります。手入力は不要です）
タグInspector の「Tags」に登録した各キーワード
例: 表示名が「剣の斬撃音」なら「斬撃」と打つだけでヒットします。ファイル名やカテゴリで検索したい時も、同じ検索欄にそのまま打ち込めば大丈夫です。

種別メニューとの組み合わせ

種別メニュー（All/Se/Bgm/…）を絞った状態で検索すると、「その種別に該当する」かつ「検索文字にヒットする」ものだけが表示されます。両方の条件を同時に満たす必要があります。

できないこと（現状の制限）

  • ID(管理番号)そのものを打ち込んでの検索はできません(表示名・ファイル名・カテゴリ・説明・作成者・タグのみが対象)
  • 「これを含み、あれは含まない」といった複雑な絞り込み条件は使えません。1つの言葉での単純な部分一致のみです
  • タイプミスを自動で補正する機能はありません。文字が完全に一致している部分だけがヒットします

新しいアセットを登録する

方法1: 音声ファイルをドラッグ＆ドロップ（効果音だけ）

  1. Project ウィンドウにある音声ファイル（.wav / .mp3 / .ogg）を、Asset Browser のウィンドウの上へドラッグ＆ドロップ
  2. 登録ダイアログが開くので、下の表の項目を入力
  3. 「作成」を押す
ドラッグ＆ドロップで作れるのは効果音（Se）だけです。Prefab・画像・マテリアルなどを落としても何も起きません。それ以外の種類はすべて「新規」ボタンから作ります。

方法2: 「新規」ボタン（効果音以外はこちら）

ファイルを後から設定したい場合や、効果音以外の種類はこちら。開くダイアログは同じで、「種別」で作るものを選びます。

「仕様書から選ぶ」（2026-09-14 追加）: アセット発注ツールと同期している場合、ダイアログの一番上に「仕様書から選ぶ」という一覧が出ます。企画が発注ツールに登録した発注のうち、まだ D-Drive 側で作られていないものだけが並びます。検索欄で表示名や識別子を絞り込めます。
一覧から行を選ぶと、種別・カテゴリ・識別子・表示名・備考・仕様リンクが自動で入力され、「選択中の行: ○○」という表示と「解除」ボタンが出ます。あとは「作成」を押すだけで、名前を1文字も打たずにアセットが作れます。作成すると、その行は一覧から消えます（もう一度同じものを間違って作ってしまう心配がありません）。
選んだ後で識別子欄を手で書き換えると、行の選択は自動で解除されます（表示名・カテゴリなどをそのまま流用しつつ、識別子だけ別物にしたい場合の事故防止です）。手動で選択を外したいときは「解除」ボタンを押してください。
一覧が出ない・古そうなときは「仕様書を再取得」ボタンで最新の状態にできます。仕様書の URL がまだ設定されていない場合は、この一覧自体が出ません（案内文だけ表示されます）。

方法3: SourceAssets フォルダに置くだけ（自動生成、2026-09-14 追加）

Asset Browser を開かずに、決められたフォルダにファイルを置くだけで下記 9 種類の Data が自動的にできます（数秒後に Console にログが出ます）。

置く場所置くファイルできる Data
Assets/SourceAssets/Se/<カテゴリ>/.wav / .mp3 / .oggSeData
Assets/SourceAssets/Bgm/<カテゴリ>/.wav / .mp3 / .oggBgmData
Assets/SourceAssets/Texture/<カテゴリ>/.png / .jpg / .tga 等TextureData
Assets/SourceAssets/Model/<カテゴリ>/.fbxModelData
Assets/SourceAssets/Anim/<カテゴリ>/.anim / .fbxAnimData
Assets/SourceAssets/Anim2D/<カテゴリ>/.anim / .fbxAnim2DData
Assets/SourceAssets/Prefab/<カテゴリ>/.prefabPrefabData
Assets/SourceAssets/Canvas/<カテゴリ>/.prefabCanvasData
Assets/SourceAssets/Vfx/<カテゴリ>/.prefabVfxData
<カテゴリ> のフォルダ名がそのまま Data の「カテゴリ」になり、ファイル名がそのまま識別子(英語 PascalCase になっていない場合は自動で整形)になります。例えば Assets/SourceAssets/Se/Player/Slash.wav を置くと、カテゴリ「Player」・識別子「Slash」の SE_Player_Slash ができます。表示名は後から Inspector で日本語に変えられます。
SourceAssets の直下や、上の表にある種別名(Se/Bgm/Texture/Model/Anim/Anim2D/Prefab/Canvas/Vfx)以外のフォルダに置いても反応しません。「1階層目」が種別フォルダである必要があります(大文字・小文字も一致させてください)。例えば Assets/SourceAssets/Slash.wav(直下)や Assets/SourceAssets/Check/Se/Slash.wav(種別フォルダの上に別フォルダがある)は無視されます。置き方を間違えた場合は Console に案内の警告ログが出ます。フォルダが用意されていない場合は Tools > D-Drive > Generate > SourceAssets の既定フォルダを作成 で作れます。
元ファイルを削除しても Data は消えません。音や見た目が「未設定(または Missing)」の警告付きで残るだけです（Validation の一覧に出ます）。うっかりファイルを消してしまっても、AssetBrowser 側のデータは安全です。逆に言うと、Data を完全に消したいときはこの方法では消えないので、通常のアセット削除手順を使ってください。
また、同じファイルを再インポートしても Data が二重にできることはありません。
この機能で作られた Data は、ファイルへの参照（Clip / Texture / Prefab のいずれか）以外の項目は初期値のままです。細かい調整（3D 設定・Layer・Params 等）は作られた後に Asset Browser や各専用エディタで行ってください。

方法4: 各専用エディタの「＋ 新規作成」ボタン（2026-09-14 追加）

Audio Editor・VFX Editor・Canvas Editor・UI Tween Editor など、各専用エディタのツールバー（上部）にも同じ「＋ 新規作成」ボタンがあります。Asset Browser を開かずに、いま作業しているエディタからその場で新しいアセットを作れます。

  1. 専用エディタを開く（Tools > D-Drive > Editors > …）
  2. ツールバーの「＋ 新規作成」を押す
  3. ダイアログが開く。種別はそのエディタで扱える種類だけに絞られています（例: Audio Editor なら Se か Bgm の 2 択、他のほとんどのエディタは 1 種類に固定）
  4. 表示名・カテゴリ・識別子を入力して「作成」
作成が終わると、ダイアログが閉じてそのままいま開いているエディタの対象がこの新しいアセットに切り替わります。作った直後から続けて調整を始められます。

ダイアログの入力項目

項目入力するもの例
種別作りたいアセットの種類。効果音なら「Se (SeData)」、BGM なら「Bgm (BgmData)」。ほかに Vfx / Anim / Anim2D / Material / Texture / Canvas / Prefab / Model / Anchor / AnchorGroup / UiTween があり、ボタン用とスライダー用の Skin は「ControlSkin (ButtonSkinData)」「ControlSkin (SliderSkinData)」の 2 行に分かれています。Se (SeData)
表示名日本語でOK。一覧や検索で使われる名前。後から変えても大丈夫。剣の斬撃音
カテゴリ整理用の分類。空欄でもOK。Player
識別子英語で、先頭大文字・スペースなし。プログラマーがコードから呼ぶときの名前になります。迷ったら英単語をつなげて各単語の頭を大文字に。SwordSlash
備考空欄でもOK。「仕様書から選ぶ」で行を選ぶと自動で入りますが、手入力もできます。3段階で音程を変える
仕様リンク空欄でもOK。アセット発注ツールの発注ページへのリンクなど。設定すると Inspector に「仕様書を開く」ボタンが出ます。（発注ページのURL）
ファイル名と保存フォルダは自動で付きます。上の例なら SE_Player_SwordSlash というファイルが Assets/GameData/Audio/SE/Player/ フォルダに自動で作られ、管理台帳への登録もすべてツールがやります。ダイアログの下に「生成先」がプレビュー表示されるので確認できます。
カテゴリを英語で入れておくと（例: Player、Enemy/Attack のように / で階層も可）、カテゴリごとのフォルダに自動で仕分けられるので、Project ウィンドウから直接探すときも見つけやすくなります。

NG: sword_slash / 剣斬撃 / 1Slash → OK: SwordSlash

試聴する（プレビューバー）

  1. 一覧で音を1つクリックして選ぶ
  2. 下のプレビューバーの ▶ 再生 を押す（ゲームを実行しなくても鳴ります）
  3. 「ループ」にチェックを入れて再生すると繰り返し再生（データ自体は変更されません）
  4. 「速度」スライダーで再生スピードを変えて聞き比べ（0.1倍〜2倍）

もっと細かく確認したい場合（波形を見る・3D の聞こえ方を確かめる等）は Audio Editor を使います。

使用箇所を調べる / 使っていないアセットを片付ける / 安全に削除する（2026-09-14 追加）

アセットは他のアセットやシーンから「ID」で参照されます。見た目だけでは「これ、どこかで使われているんだっけ？」が分からないので、D-Drive が自動で調べてくれます。

使用箇所を調べる

  1. 一覧の行を右クリック →「使用箇所を表示」
  2. そのアセットを使っている場所（アセット・シーン）が一覧で出ます
  3. 一覧の行をダブルクリックすると、その場所へジャンプします。
    • アセット（データ）や Prefab の場合: Project ウィンドウでその項目が選ばれてハイライトされます
    • シーンの場合: 「開きますか？」の確認が出ます（今のシーンに保存していない変更があれば、先に保存するか聞かれます）。開くと該当のオブジェクトが選ばれます

「どこからも参照されていません（未使用）」と出たら、そのアセットは今のところ誰にも使われていません。

依存ツリーを見る

右クリック →「依存ツリーを表示」で、選んだアセットがさらに何を使っているかをツリー（木構造）で確認できます。例えば Prefab がマテリアルを使い、マテリアルがテクスチャを使い…という連なりが一目で分かります。

A → B → A のようにぐるっと参照が輪になっている（循環）場合は、輪になった箇所で表示が止まり、色を変えて示します（無限にツリーが伸び続けることはありません）。ID が削除済みなどで見つからない参照先も赤字で表示されます。

使っていないアセットをまとめて片付ける（未使用検出 + 一括アーカイブ）

  1. ツールバーの「未使用...」ボタンを押す
  2. どこからも参照されていないアセットが一覧で出ます
  3. 片付けたいものにチェックを入れる（「全選択」「選択解除」ボタンあり）
  4. 「選択項目を一括Archive」を押す
「Archive（アーカイブ）」は削除ではありません。「もう使っていない印」を付けるだけで、ファイルはそのまま残ります。実際に消すかどうかは後で改めて判断できます（一覧の行をダブルクリックすれば、いつでもそのアセットを選んで確認できます）。

安全に削除する（2026-09-14 更新: 削除の確認画面を Unreal Engine 風に一新）

本当に消してよいアセットは、一覧の行を右クリック →「削除...」から削除できます（複数選択して右クリックすれば、まとめて削除対象にできます）。以前は小さな確認ダイアログでしたが、今は専用の「アセットを削除」ウィンドウが開き、依存関係と削除後にどうなるかが一目でわかるようになりました。

① 分析画面（何が消えて、何に影響するか）

  1. 削除するアセット一覧: アイコン・種別・名前・ID・パスが並びます。ここに、生成された ID 定数がコードから使われているかもしれない場合は警告が出ます（削除する前に一度プログラマーに確認してください。完全な保証はできない簡易チェックです）
  2. このアセットを使っている場所（参照元）: Data・Prefab・Scene に分けて一覧が出ます。「ジャンプ」ボタンでその場所へ移動できます。削除対象どうしの参照（まとめて消すなら問題ない参照）は別枠で表示されるので、身構える必要はありません
  3. このアセットが使っているもの（依存先）: このアセットを消すとどこからも使われなくなる依存先にはチェックボックスが付き、チェックを入れると一緒に削除できます（既定はチェックなし。他でも使われている依存先はチェックできません）

② 削除方法を選ぶ

参照元が1つもない場合はそのまま「削除する」だけで済みますが、参照が残っている場合は次の4つから選びます。

  • 参照を差し替えてから削除: 同じ種別の別のアセットを置き換え先として選ぶと、参照元の Data・Prefab の中身を自動で書き換えてから削除します。Scene 内の参照だけは自動で書き換えません（開いているシーンを勝手に保存しないための仕組みです）。Scene から参照が残っている間は削除せず、「アーカイブ済み」の印だけ付けて保留します
  • 強制削除: 参照を残したまま削除します。「参照が残ることを理解した」チェックを入れないと実行できません。実行時にはその参照が Placeholder（空の代役）になり、Validation でエラーとして検出されます
  • アーカイブのみ: 削除せず「もう使っていない印」だけ付けます
  • キャンセル: 何もせずウィンドウを閉じます（アーカイブの印も付きません）
参照の差し替えは、Data と Prefab では戻せる範囲が違います。Data 側の書き換えは通常の操作と同じく Ctrl+Z で戻せますが、Prefab 側の書き換えは Ctrl+Z では戻せません。差し替えを間違えたと思ったら、もう一度「参照を差し替え」を実行して元の ID に戻してください。

③ 結果画面（削除した後どうするか）

「実行」を押すと、同じウィンドウがそのまま結果画面に切り替わります。

  • 削除したアセットは管理台帳（カタログ）・Addressables への登録・アイコン画像がまとめて片付き、アセット本体とアイコンはOS のゴミ箱（Windows なら「ごみ箱」）に移動します
  • 元に戻す手順: ごみ箱からファイルを復元したら、画面に出ている「Addressables 登録を同期」ボタンを押し、カタログへの再登録と Validation の確認を行ってください（自動では戻りません）
  • コードで使っている ID 定数: 「生成された ID 定数 '...' を参照しているコードが見つかりました」という警告とファイル名・行番号が並び、クリックするとそのコードがエディタで開きます。「ID 定数を再生成」ボタンも用意されています
  • 差し替えた参照の一覧、Scene 参照が残っていて手動で直す必要があるもの（ジャンプボタン付き）もここに出ます
削除の確認画面（分析画面・結果画面の両方）に「生成された ID 定数 '...' を参照しているコードが見つかりました」という注意が出ることがあります。これはプログラマーのコードがまだこの ID を使っているかもしれないという警告です（完全ではない簡易チェックなので、出ない場合でも絶対安全とは限りません）。この注意が出たら、削除する前に一度プログラマーに確認してください。この警告は削除を止めません（分析画面で見た時点で自分でキャンセルする必要があります）。
「一緒に削除」でチェックした依存先は、さらにその先が使っているものまでは自動で片付きません。孫にあたる依存先まで片付けたい場合は、削除が終わってからもう一度「未使用...」やこの削除の手順を実行してください。

読み込みを速くする（Preload リスト、2026-09-14 追加）

シーンを開いたとき、そのシーンで使う音・エフェクトなどを先読み（Preload）しておくと、実際に鳴らす・出す瞬間の一瞬の遅れが減ります。これはプログラマー / レベル担当が行う作業ですが、デザイナーが意識しておくとよい点をまとめます。

  • シーンで使う ID の一覧（ScenePreloadList、Assets/GameData/Preload/）は、Tools > D-Drive > Generate > Preload リストを再集計(現在のシーン)（または「ビルド設定の全シーン」）で自動的に集計されます。デザイナーが手で ID を書き足すことはありません
  • 新しく Anchor・SeEmitter・配置セットなどをシーンに置いた（新しい ID 参照を増やした）ときは、誰かがこの再集計メニューを実行し直す必要があります。置いただけでは古いシーンの Preload リストには反映されません（保存時に自動では再集計されない設計です）
  • ビルド時には自動で全シーン分が再集計されるため、通常のビルドでは意識しなくても最新の状態になります。エディタで確認しているときに「ロードが速くならない」と感じたら、上記メニューを実行し忘れていないかを確認してください
  • ロード画面（進捗バー）はまだ確認用の最小実装（SceneLoadingScreen）です。デザイナー向けの本格的な Canvas ベースのロード画面は今後の別チケットで用意される予定です

よくある質問

  • Q. 表示名を変えたい → 一覧で選んで Inspector の「Display Name」を書き換えれば OK です。
  • Q. 間違えて作ってしまった → 右クリック →「使用箇所を表示」でまだどこにも使われていないことを確認してから、「削除...」で削除してください。参照が残っている場合、削除ウィンドウでは既定で「アーカイブのみ」に誘導されます（「強制削除」を選べば消せますが、参照が残ったままになるので通常は避けてください）。迷ったらチームのリーダーに相談してください。
  • Q. 一覧に出てこない → 「更新」ボタンを押してみてください。種別フィルタが絞られたままになっていないかも確認。
  • Q. 「使用箇所を表示」や「削除」を押しても何も反応がない / 「依存関係グラフが未構築です」と出る → Tools → D-Drive → Generate → 依存関係グラフを再構築 を一度実行してください（プロジェクトを最初に開いた直後などは索引が空のことがあります）。
