D-Drive プログラマーマニュアル

このマニュアルは、D-Drive（Designer-Driven Re: IDE Visual Environment、このプロジェクトのアセット管理システム）を使ってゲームコードを書くプログラマー向けのガイドです。エディタの操作手順（Asset Browser の使い方、専用エディタでの調整、アイコン生成など）は扱いません。それらは デザイナーマニュアルを読んでいる前提で進めます。

D-Drive とは？（プログラマー視点で30秒）

音・エフェクト・モデル・UI 画面・演出などのゲームアセットを、ID（生成された定数）だけで扱える仕組みです。

  • プログラマーは「このタイミングでこの ID を再生する」という 1 行だけを書きます（例: Audio.PlaySe(SEID.PlayerSlash)）
  • ID の中身（音そのもの、エフェクトの見た目、UI の配線）はデザイナーが専用エディタで作り込みます
  • ID が未登録でも警告ログ + Placeholder（無音・マゼンタの球など）で動き続けるため、アセットが 1 つも無い状態でもゲームロジックを完成させられます（実装: Data / Instance / Handle の分離）
  • 中身の差し替えはデザイナー側の作業だけで完結し、コードの再修正は不要です
デザイナーマニュアルとの読み分け: 「このパラメータは何をするか」「エディタのこのボタンは何か」を知りたいときは デザイナーマニュアル。「このクラス・メソッドをどう呼べばよいか」「ID や asmdef はどう構成されているか」を知りたいときは、このプログラマーマニュアルを使ってください。
